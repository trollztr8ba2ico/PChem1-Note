왜 "시간"이 갑자기 등장하는가?

🎯 핵심 동기 지금까지 푼 Ĥψ = Eψ는 "원자가 혼자 있을 때의 에너지 준위"를 묻는 질문이었다. 스펙트럼은 빛이 들어와서 전자 상태가 바뀌는 현상 — 즉 시간이 흐르는 이야기다.
🎵 비유 — 악기 줄: 혼자 있는 기타 줄은 그냥 정지 상태(시간독립). 손가락으로 퉁기면(빛이 들어오면) 줄이 진동하기 시작한다(시간의존). 스펙트럼은 "어떤 진동수로 퉁길 때 줄이 가장 잘 울리는가"를 측정하는 것.
시간독립 Schrödinger시간의존 Schrödinger
방정식\( \hat{H}\psi = E\psi \)\( i\hbar\frac{d\Psi}{dt} = \hat{H}\Psi \)
묻는 질문에너지 준위가 뭐야?상태가 어떻게 변해가?
해의 특징시간 없음, 정적\(\Psi(t) = \Psi(0)e^{-iEt/\hbar}\)
쓰이는 상황원자 구조 계산빛과의 상호작용, 전이

시간의존 해 유도

에너지 고유상태일 때 시간의존 방정식은 1계 ODE로 단순화된다.

$$i\hbar\frac{d\Psi}{dt} = E\Psi \;\Longrightarrow\; \frac{d\Psi}{\Psi} = -\frac{iE}{\hbar}dt$$ $$\boxed{\Psi(t) = \Psi(0)\,e^{-iEt/\hbar}}$$
⚠️ 핵심 포인트 \(|e^{-iEt/\hbar}|^2 = 1\) — 위상 인자는 확률 분포를 바꾸지 않는다.
→ 에너지 고유상태는 정상상태(stationary state): 혼자 있는 원자는 아무리 시간이 지나도 상태가 안 바뀐다. 당연!

빛이 들어오면 — 교란 해밀토니안

① 빛 = 진동하는 전기장

$$\mathbf{E}(t) = \mathbf{E}_0\,e^{i\omega t}$$

참고 실제 전기장은 실수 \(\mathbf{E}_0\cos\omega t\)이나, 계산 편의상 복소수 형태를 쓰고 나중에 실수부를 취한다.

② 쌍극자 모멘트 μ

$$\boldsymbol{\mu} = \sum_i e_i\mathbf{r}_i$$
🧲 전하(eᵢ)와 위치(rᵢ)의 가중합. HCl처럼 전자가 한쪽으로 쏠리면 μ ≠ 0. 전하 분포의 "무게중심" 같은 것.

③ 빛-분자 상호작용 에너지

$$\hat{V}(t) = \boldsymbol{\mu}\cdot\mathbf{E}_0\,e^{i\omega t}$$ $$\hat{H}' = \hat{H} + \hat{V}(t)$$
❗ 왜 중요한가 \(\hat{V}(t)\)가 추가되면 Ψₐ, Ψ_b는 더 이상 \(\hat{H}'\)의 고유함수가 아니다!
\(\hat{H}'\Psi_a = E_a\Psi_a + \hat{V}\Psi_a\) — \(\hat{V}\Psi_a\)가 Ψₐ에 비례하지 않으므로 고유함수 조건 깨짐.
→ 상태가 시간에 따라 변할 수 있다 = 전이가 가능해진다.

C_a(t), C_b(t) 미분방정식 유도

빛이 없을 때 일반해 \(\Psi(t) = c_a\Psi_ae^{-iE_at/\hbar} + c_b\Psi_be^{-iE_bt/\hbar}\)에서, 빛이 들어오면 상수 \(c_{a,b}\)가 시간 함수 \(C_{a,b}(t)\)로 바뀐다. (variation of parameters)

$$\Psi(t) = C_a(t)\Psi_a\,e^{-iE_at/\hbar} + C_b(t)\Psi_b\,e^{-iE_bt/\hbar}$$

이를 \(i\hbar\frac{d\Psi}{dt} = \hat{H}'\Psi\)에 대입하면, Ĥ 텀이 양변에서 상쇄되어 순수하게 \(\hat{V}\) 때문에 생기는 변화만 남는다:

$$i\hbar\!\left\{\Psi_a e^{-iE_at/\hbar}\frac{dC_a}{dt} + \Psi_b e^{-iE_bt/\hbar}\frac{dC_b}{dt}\right\} = \hat{V}(t)\!\left\{C_a\Psi_a e^{-iE_at/\hbar} + C_b\Psi_b e^{-iE_bt/\hbar}\right\}$$

여기에 \(\Psi_a^*e^{+iE_at/\hbar}\)를 곱하고 공간 적분하면 (직교 정규성 \(\int\Psi_a^*\Psi_b\,d\tau = \delta_{ab}\) 적용):

$$i\hbar\frac{dC_a}{dt} = \langle\Psi_a|\hat{V}|\Psi_b\rangle C_b\,e^{-i(E_b-E_a)t/\hbar}$$ $$i\hbar\frac{dC_b}{dt} = \langle\Psi_b|\hat{V}|\Psi_a\rangle C_a\,e^{-i(E_a-E_b)t/\hbar}$$
⚠️ 왜 ⟨Ψₐ|V̂|Ψₐ⟩ = 0인가 \(\hat{V} \propto \boldsymbol{\mu} \propto x\) (홀수 함수). \(|\Psi_a|^2\)는 짝수 함수.
홀수 × 짝수 = 홀수 → 전체 공간 적분 = 0.
물리적 의미: 진동 전기장이 전자를 좌우로 밀었다 당겼다 → 평균 0.

전이 확률 공식 — |C_b(t)|²

초기조건 \(C_a(0)=1,\; |C_b(0)|^2=0\) + 약한 빛(E₀ 작음) → \(C_a(t)\approx 1\) 상수로 취급 가능. 그러면 dC_b/dt를 직접 적분할 수 있다:

$$\boxed{|C_b(t)|^2 = \frac{|\langle\Psi_b|\boldsymbol{\mu}|\Psi_a\rangle|^2 |\mathbf{E}_0|^2 t^2}{2\hbar^2}\cdot\frac{\sin^2\!\left[\frac{1}{2}\!\left(\frac{E_b-E_a}{\hbar}-\omega\right)t\right]}{\left[\frac{1}{2}\!\left(\frac{E_b-E_a}{\hbar}-\omega\right)t\right]^2}}$$
✅ 이 공식에서 읽는 것 전이 확률 \(|C_b(t)|^2\)는 두 인자의 곱이다.
인자 ① \(|\langle\Psi_b|\boldsymbol{\mu}|\Psi_a\rangle|^2\) → 전이 쌍극자 모멘트 (선택규칙의 근원)
인자 ② \(\text{sinc}^2\) 함수 → 공명 조건 (Bohr 진동수 조건)

sinc² 함수와 Bohr 조건

🎸 공명 비유: 그네를 밀 때 그네의 고유 주기에 맞춰 밀어야만 진폭이 커진다. 아무 타이밍에나 밀면 오히려 방해가 돼서 평균이 0이 된다. sinc² 함수가 바로 이 "공명 창문"을 수식화한 것.
$$\frac{E_b-E_a}{\hbar} = \omega \;\Longrightarrow\; \boxed{\Delta E = \hbar\omega}$$

이때 \(\text{sinc}^2\)의 인자가 0 → 함수값 최대(1). 공명 조건이 맞을 때만 \(|C_b(t)|^2\)가 시간에 비례해 증가. 조금이라도 ω가 다르면 지수가 빠르게 진동해서 평균 0 → 전이 안 일어남.

전이 쌍극자 모멘트의 물리적 해석

$$\mu_{fi} = \int\Psi_b^*\,\hat{\boldsymbol{\mu}}\,\Psi_a\,d\tau = \langle\Psi_b|\hat{\boldsymbol{\mu}}|\Psi_a\rangle$$

해석 ① — 빛이 분자를 distort

\(\hat{\boldsymbol{\mu}}\Psi_a\): 빛이 상태 a를 뒤흔든 결과물.
이게 상태 b와 얼마나 닮았냐 = 전이 확률.

해석 ② — 유도 쌍극자

빛이 양자계에 유도한 쌍극자. 이 유도 쌍극자가 다시 빛과 \(\hat{V}=\boldsymbol{\mu}\cdot\mathbf{E}_0e^{i\omega t}\)로 상호작용.

해석 ③ — 전하 재분포

전이 시 전하 재분포가 쌍극자적(dipolar)이어야만 빛과 커플링됨.

해석 ④ — non-orthogonality

\(\hat{\boldsymbol{\mu}}\)가 Ψₐ에 작용 → Ψ_b와 비직교하게 만들어야 전이 가능. 직교성 유지 = 전이 금지.

📐 핵심 수식 \(\int\Psi_b^*\Psi_a\,d\tau = 0\) (직교성, 항상) — 그런데
\(\int\Psi_b^*(\hat{\boldsymbol{\mu}}\Psi_a)\,d\tau \neq 0\) 가 되어야 전이 가능.
μ̂가 Ψₐ의 모양을 바꿔서 Ψ_b와 겹치게 해준다.

수소원자 선택규칙 유도

전이 쌍극자 모멘트 \(\mu_{fi} = -e\int\psi_f^*\,\mathbf{r}\,\psi_i\,d\tau\)를 구체적으로 계산하자. z 성분부터:

$$\mu_{z,fi} = -e\int\psi_f^*\,z\,\psi_i\,d\tau$$

핵심 치환: z = r cosθ = r(4π/3)^{1/2} Y_{1,0}

🔮 왜 Y_{1,0}으로 바꾸냐: 수소 파동함수가 ψ = R(r)·Y(θ,φ)로 분리되어 있잖아. z도 r × Y의 형태로 바꾸면 적분을 "반지름 적분 × 각도 적분"으로 깔끔하게 쪼갤 수 있다. 마치 파이를 가로로 잘라서 따로 계산하는 것처럼.
$$\int\psi_f^*z\,\psi_i\,d\tau = \left(\frac{4\pi}{3}\right)^{1/2}\!\underbrace{\int_0^\infty R_{n_f,l_f}^*\,r^3\,R_{n_i,l_i}\,dr}_{\text{radial 적분}}\times\underbrace{\int_0^{2\pi}\!\!\int_0^\pi Y_{l_f,m_{l,f}}^*\,Y_{1,0}\,Y_{l_i,m_{l,i}}\sin\theta\,d\theta\,d\phi}_{\text{angular 적분}}$$

Angular 적분 → 선택규칙

선택규칙을 결정하는 건 angular 적분이다. 삼중 구면조화함수 적분의 결과:

$$\int Y_{l_f,m_{l,f}}^*\,Y_{1,0}\,Y_{l_i,m_{l,i}}\,d\Omega = \delta_{l_f,\,l_i\pm 1}\cdot\delta_{m_{l,f},\,m_{l,i}}$$
🎹 비유 — 피아노 음: 구면조화함수 Y_{l,m}들은 "구면 위의 음계"라고 생각해봐. 특정 음계끼리만 공명하듯, Y₁,₀이 끼어들면 l을 ±1만큼 바꾸는 음계끼리만 0이 아닌 적분값이 나온다. Y₁,₀의 "l=1" 정보가 각운동량 변화량을 1로 고정시키는 것.

x, y 성분은 Y_{1,±1}을 포함하므로 \(\Delta m_l = \pm 1\) 조건 추가. 세 방향 종합하면:

✅ 수소원자 선택규칙 $$\boxed{\Delta l = \pm 1} \qquad \boxed{\Delta m_l = 0,\,\pm 1}$$
규칙조건물리적 근원
Δl = ±1\(l_f = l_i\pm 1\)z는 Y₁,₀, x/y는 Y₁,±₁ → l을 ±1 바꿈
Δm_l = 0, ±1z → Δm_l=0, x/y → Δm_l=±1, 종합하면 0,±1

각운동량 보존과 선택규칙의 연결

💡 깊은 이해 광자는 스핀 s=1 → 각운동량 ℏ를 갖는다.
전이 시 전체 각운동량 보존 → \(\Delta(l\cdot\hbar) = \pm\hbar\) → Δl = ±1
수식에서는 z = rY₁,₀ 치환에서 나타남: Y₁,₀의 l=1이 광자의 각운동량 1을 반영.

따라서 ν = |ΔE|/h는 필요조건이지 충분조건이 아니다. Δl = ±1도 동시에 만족해야 한다.

왜 ΔS = 0 선택규칙이 생기나

전이 쌍극자 모멘트 \(\mu_{fi} = \int\psi_f^*\hat{\boldsymbol{\mu}}\psi_i\,d\tau\)에서 파동함수를 공간×스핀으로 분리하면:

$$\mu_{fi} = \underbrace{\int\phi_f^*\hat{\boldsymbol{\mu}}\phi_i\,d\tau}_{\text{공간 적분}}\times\underbrace{\int\sigma_f^*\sigma_i\,d\sigma}_{\text{스핀 적분}}$$

μ̂는 위치 연산자라 스핀에 작용하지 않는다. Singlet(S=0)과 Triplet(S=1) 스핀함수는 직교:

$$\int\sigma_{S=0}^*\sigma_{S=1}\,d\sigma = 0 \;\Longrightarrow\; \mu_{fi} = 0$$
❗ ΔS = 0 선택규칙 Singlet ↔ Triplet 전이는 μ̂가 스핀을 못 건드리기 때문에 금지된다.

Spin-Orbit Coupling (SOC) — 도입 동기

🌀 비유 — 전자 입장에서 보기: 전자가 핵 주위를 돈다고 생각해봐. 근데 전자 입장에서 보면 핵이 전자 주위를 도는 것처럼 보여. 움직이는 양전하(핵) = 전류 = 자기장 발생. 이 자기장이 전자의 스핀 자석과 상호작용 → 에너지 추가!
$$E_{\text{interaction}} \propto -\boldsymbol{\mu}\cdot\mathbf{B} \propto \mathbf{s}\cdot\mathbf{l}$$

스핀과 궤도 각운동량이 에너지적으로 결합됨. 이게 Spin-Orbit Coupling (SOC).

s·l 을 양자역학적으로 계산

정의 전체 각운동량 \(\mathbf{j} = \mathbf{l} + \mathbf{s}\)로부터:

$$\mathbf{j}\cdot\mathbf{j} = (\mathbf{l}+\mathbf{s})^2 = l^2 + s^2 + 2\mathbf{s}\cdot\mathbf{l}$$ $$\mathbf{s}\cdot\mathbf{l} = \frac{1}{2}\{j^2 - l^2 - s^2\}$$

양자 대응 각운동량 연산자의 고유값 \(j^2 \to j(j+1)\hbar^2\):

$$\boxed{\mathbf{s}\cdot\mathbf{l} = \frac{\hbar^2}{2}\{j(j+1) - l(l+1) - s(s+1)\}}$$
📐 기하학적 직관: j, l, s를 벡터 삼각형의 세 변이라고 생각해봐. 코사인 법칙으로 두 벡터의 내적을 구하는 것과 같은 구조야: \(\mathbf{s}\cdot\mathbf{l} = \frac{1}{2}(|\mathbf{j}|^2 - |\mathbf{l}|^2 - |\mathbf{s}|^2)\).

에너지 준위 분리

$$E_{l,s,j} = \frac{1}{2}hc\tilde{A}\{j(j+1) - l(l+1) - s(s+1)\}$$

여기서 \(\tilde{A}\) (cm⁻¹)는 spin-orbit coupling constant.

각운동량 덧셈 — Clebsch-Gordan 규칙

$$L = l_1+l_2,\; l_1+l_2-1,\; \ldots,\; |l_1-l_2|$$ $$S = s_1+s_2,\; s_1+s_2-1,\; \ldots,\; |s_1-s_2|$$ $$J = L+S,\; L+S-1,\; \ldots,\; |L-S|$$
🧭 벡터 덧셈 비유: l₁=2, l₂=1인 두 화살표를 더할 때, 같은 방향이면 L=3(최대), 반대 방향이면 L=1(최소). 중간 방향들도 가능한데, 양자화 때문에 정수 단계로만 존재. 그래서 L=3, 2, 1 세 가지.

Q3 풀이 — p³과 f¹d¹의 L

p³의 L = ?
전자 3개, 각각 l=1. 두 개씩 더해가자.

전자 1+2: L₁₂ = 2, 1, 0
L₁₂=2 + l=1: L = 3, 2, 1
L₁₂=1 + l=1: L = 2, 1, 0
L₁₂=0 + l=1: L = 1

이론상 L = 0, 1, 2, 3. 그러나 Pauli 원리 적용 후 실제 허용 term: ⁴S (L=0), ²D (L=2), ²P (L=1)
f¹d¹의 L = ?
f: l₁=3, d: l₂=2. 서로 다른 오비탈이므로 Pauli 제한 없음.

$$L = 3+2,\, 3+1,\, 3+0,\, 3-1,\, |3-2| = 5, 4, 3, 2, 1$$ → H, G, F, D, P 다섯 가지

Q4 풀이 — 전자 3개의 S

세 전자의 총 스핀 S = ?
각 전자: s=1/2.

전자 1+2: S₁₂ = 1 (triplet) 또는 0 (singlet)

S₁₂=1에 전자 3 (s=1/2) 추가:
S = 1+1/2 = 3/2 또는 S = 1-1/2 = 1/2

S₁₂=0에 전자 3 추가:
S = 0+1/2 = 1/2

결과: S = 3/2 (quartet, 2S+1=4) 또는 S = 1/2 (doublet, 2S+1=2)

전자 배치 p² (예: 탄소 2p²)

Singlet/Triplet 스핀 함수

기호식S대칭이름

형광 vs 인광

빛 흡수: S₀(singlet 바닥) → S*(singlet 들뜬) ← 빠름, ΔS=0 허용
↓ internal conversion (진동 완화, 열방출)
S* 낮은 진동 준위
↓ ISC (Intersystem Crossing) — SOC 덕분에 가능!
T (triplet 들뜬) 상태에 갇힘
↓ T → S₀ 매우 느린 전이 (ΔS=±1, 약허용)
인광(Phosphorescence) 방출 — 잔광!
🌙 어두운 데서 빛나는 스티커 비유:
형광 = 불 끄자마자 즉시 사라짐 (나노초). S*→S₀, ΔS=0이라 빠름.
인광 = 불 꺼도 수 초~분간 빛남. T→S₀, ΔS=±1이라 "금지된 전이"인데 SOC 덕에 아주 느리게나마 일어남. 금지라서 오래 걸리고, 오래 걸리니까 잔광이 긴 역설적 상황!

형광 (Fluorescence)

경로: S* → S₀
ΔS = 0 (허용)
속도: 나노초
빛 끄면: 즉시 소멸

인광 (Phosphorescence)

경로: T → S₀
ΔS = ±1 (금지, SOC로 약허용)
속도: 밀리초~초
빛 끄면: 잔광 남음

💡 ISC가 가능한 이유 — SOC의 역할 Spin-Orbit Coupling이 강하면 순수한 Singlet/Triplet 상태가 섞인다. 즉 T 상태에 Singlet 성분이 조금 혼입되고, S* 상태에 Triplet 성분이 혼입됨.
→ 완전 금지가 아니라 약하게 허용된 전이 가능 (SOC가 강한 무거운 원소일수록 ISC 잘 일어남)

Q1 유도형

⟨Ψₐ|V̂|Ψₐ⟩ = 0임을 대칭성을 이용해 논하시오.

풀이 보기
\(\hat{V} \propto \boldsymbol{\mu} \propto x\) (홀수 함수). \(|\Psi_a|^2\)는 확률밀도로 짝수 함수.

홀수 함수의 전체 공간 적분 = 0 (대칭 소거).
물리적 의미: 진동 전기장이 같은 상태 내에서 평균 일을 하지 못함.

Q5 설명형

형광(fluorescence)과 인광(phosphorescence)의 차이를 선택규칙, 수명, spin-orbit coupling의 역할을 포함하여 설명하시오.

풀이 보기
형광: S*→S₀, ΔS=0 허용 전이, 나노초 수명.
인광: T→S₀, ΔS=±1 금지 전이이나 SOC가 Singlet/Triplet을 혼합시켜 약하게 허용.

무거운 원소(Rb, Cs)는 Ã ∝ Z⁴라 SOC 강 → ISC 효율 높음.
Q6 설명형

Bohr 진동수 조건 ΔE = hν가 필요조건이지 충분조건이 아닌 이유를 설명하고, 빛 흡수를 위한 충분조건을 제시하시오.
