01

열용량 — Dulong-Petit → Einstein/Debye

고전 → 양자
고전역학 — Dulong-Petit

고체 원자 = 3D 조화진동자. Equipartition theorem: 자유도 하나당 kT/2.

3방향 × (운동에너지 + 퍼텐셜에너지) = 3 × 2 × kT/2 = 3kT

U = 3RT    Cᵥ = dU/dT = 3R ≈ 24.9 J/mol/K

온도에 완전히 독립적. 근데 저온에서 실험값은 0으로 수렴 → 고전역학 실패.

Einstein/Debye — 양자화 적용

흑체복사와 동일한 논리: 진동 에너지가 hν 단위로만 존재.

⟨E⟩ = hν / (e^(hν/kT) − 1)

고온 극한 (kT >> hν):

e^x ≈ 1+x → ⟨E⟩ → kT → Cᵥ → 3R ✓

저온 극한 (kT << hν):

⟨E⟩ → 0 → Cᵥ → 0 ✓ (실험 일치)

Einstein: 모든 원자 같은 ν 가정. Debye: ν 분포 고려 → 실험과 더 잘 맞음.

02

Bohr 모델 — 수소 스펙트럼 설명

양자화 증거
출발: Rydberg 공식 (경험식)
ν = R(1/n₁² − 1/n₂²)    R = 3.29×10¹⁵ Hz

n₁=1: Lyman (UV) / n₁=2: Balmer (가시광선) / n₁=3: Paschen (IR)

왜 이런 식이 나오는지 몰랐음 → Bohr가 설명.

가정 1 — 원형 궤도: 원심력 = Coulomb 인력
mₑv²/r = Ze²/4πε₀r²

양변 정리: mₑv² = Ze²/4πε₀r → ½mₑv² = Ze²/8πε₀r

퍼텐셜에너지: V = −Ze²/4πε₀r (반대 전하 인력 → 음수)

E = ½mₑv² + V = Ze²/8πε₀r − Ze²/4πε₀r = −Ze²/8πε₀r

전체 에너지가 음수 = 전자가 핵에 속박된 상태.

가정 2 — 각운동량 양자화
L = mₑvr = nħ    (n = 1, 2, 3, ...)

물리적 근거: 전자를 파동으로 보면 원형 궤도에서 정상파 조건 nλ = 2πr.

λ = h/mₑv 대입 → n(h/mₑv) = 2πr → mₑvr = nħ

n이 정수가 아니면 파동이 자기간섭으로 소멸 → 정수만 허용.

유도 Step — rₙ, Eₙ
1

L = nħ에서: mₑv = nħ/r → mₑ²v² = n²ħ²/r²

가정 1에서: mₑ²v² = mₑZe²/4πε₀r

2

두 식 같다고 놓으면: n²ħ²/r² = mₑZe²/4πε₀r

rₙ = 4πε₀n²ħ²/mₑZe² = (a₀/Z)n²    a₀ = 0.529Å
3

rₙ을 E = −Ze²/8πε₀r에 대입:

Eₙ = −mₑZ²e⁴/8ε₀²h²n² = −Rₕ Z²/n²    Rₕ = 13.6 eV
4

n₂ → n₁ 전이: ΔE = hν → Bohr 진동수 조건 적용:

ν = (Rₕ/h)(1/n₁² − 1/n₂²) = R(1/n₁² − 1/n₂²) ✓

Rydberg 경험식이 이론으로 완벽히 유도됨.

핵심 결과
물리량식의미
rₙ(a₀/Z)n²n² 비례. n 클수록 궤도 급격히 커짐
Eₙ−RₕZ²/n²n² 반비례. n=1이 가장 낮은 바닥상태
a₀0.529Å수소 바닥상태(n=1) 궤도 반지름
Rₕ13.6 eV수소 이온화 에너지
03

광전효과 — 빛의 입자성

Einstein 1905
고전역학 예측 vs 실험

고전 예측:

빛 세기 강하면 전자 더 빠르게 튀어나와야 함.

실험 결과:

진동수가 문턱값 이상일 때만 전자 나옴. 세기 무관.

Einstein 해석

빛 = 광자. 광자 하나가 전자 하나를 1대1로 때림.

금속에서 전자를 떼는 데 필요한 최소 에너지 = 일함수 Φ.

Eₖ = ½mₑv² = hν − Φ

hν < Φ이면 Eₖ < 0 → 전자 안 나옴. 진동수가 관건인 이유.

그래프 기울기 = h (보편 상수). x절편 = Φ/h (금속마다 다름).

04

de Broglie 관계식 — 물질의 파동성

파동-입자 이중성
핵심 아이디어

Einstein이 빛의 파동-입자 이중성 보임 → de Broglie: "전자도 파동 아닐까?"

λ = h/p = h/mv

모든 물질 입자가 파장을 가짐. p 크면(빠르면) λ 짧음.

Davisson-Germer 실험 — 증명

전자빔을 Ni 결정에 쏘면 회절 패턴 관찰. 파동만 회절함 → 전자가 파동임을 직접 증명.

Q5. 테니스공 파장 계산

m = 57g = 0.057 kg, v = 80 km/h = 22.2 m/s

p = mv = 0.057 × 22.2 = 1.265 kg·m/s

λ = h/p = 6.626×10⁻³⁴ / 1.265 = 5.24×10⁻³⁴ m

원자 크기(10⁻¹⁰m)보다 10²⁴배 작음 → 거시적 물체 파동성은 측정 불가. 일상에서 못 느끼는 이유.

Bohr 모델과 연결

nλ = 2πr에 λ = h/mₑv 대입 → L = nħ 자연스럽게 유도.

Bohr가 가정으로 넣었던 각운동량 양자화가 de Broglie 파동성으로 설명됨.
