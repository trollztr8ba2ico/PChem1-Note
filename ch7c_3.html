Q2  — Vitality Operator · Eigenfunction 판별

문제

다음 중 vitality operator의 eigenfunction은?
살아있는 고양이: vitality = +1  /  죽은 고양이: vitality = −1

(A) \(\dfrac{1}{\sqrt{2}}|\text{alive}\rangle + \dfrac{1}{\sqrt{2}}|\text{dead}\rangle\) (B) \(|\text{alive}\rangle\) (C) \(|\text{dead}\rangle\)
판별 기준 — Eigenfunction 정의
\(\hat{V}\psi = \omega\psi \quad \text{(연산자 작용 후 상수배로 돌아오면 eigenfunction)}\)

결과 함수가 입력 함수와 형태가 같으면 eigenfunction. 형태가 바뀌면 superposition.

Vitality Operator 작용 규칙

\(\hat{V}|\text{alive}\rangle = +1\cdot|\text{alive}\rangle \qquad \hat{V}|\text{dead}\rangle = -1\cdot|\text{dead}\rangle\)

각 후보 검토

후보 A — Superposition
\(\hat{V}\!\left(\tfrac{1}{\sqrt{2}}|\text{alive}\rangle + \tfrac{1}{\sqrt{2}}|\text{dead}\rangle\right) = \tfrac{1}{\sqrt{2}}(+1)|\text{alive}\rangle + \tfrac{1}{\sqrt{2}}(-1)|\text{dead}\rangle = \tfrac{1}{\sqrt{2}}|\text{alive}\rangle \mathbf{-} \tfrac{1}{\sqrt{2}}|\text{dead}\rangle\)

결과 ≠ λ × 입력 함수  →  ✗ Not eigenfunction

→ 상자 열기 전 슈뢰딩거의 고양이. 삶도 죽음도 확정되지 않은 상태.

후보 B — |alive⟩
\(\hat{V}|\text{alive}\rangle = (+1)\cdot|\text{alive}\rangle = +1\cdot\psi_B\)

✓ Eigenfunction  — eigenvalue = +1 (살아있음이 확정)

후보 C — |dead⟩
\(\hat{V}|\text{dead}\rangle = (-1)\cdot|\text{dead}\rangle = -1\cdot\psi_C\)

✓ Eigenfunction  — eigenvalue = −1 (죽음이 확정)

정답 & 해석
후보Eigenfunction?Eigenvalue물리적 의미
(A) Superposition✗없음관찰 전 — 삶/죽음 미확정
(B) |alive⟩✓+1상자 열었더니 살아있음
(C) |dead⟩✓−1상자 열었더니 죽어있음

핵심: Eigenfunction = 측정 결과가 이미 확정된 상태 (classical-like). Superposition = 측정 전 미결정 상태.

Q3  — Construction of Operators · 자유입자 선운동량

문제

자유입자의 파동함수가 아래와 같을 때 선운동량을 구하라.

\(\psi(x) = Ae^{ikx} + Be^{-ikx}\)

(a) B = 0   (b) A = 0

도구 — 운동량 연산자
\(\hat{p}_x = \frac{\hbar}{i}\frac{d}{dx}\)

만약 \(\hat{p}_x\psi = p\cdot\psi\) 형태로 떨어지면 → eigenfunction, 운동량이 확정값 \(p\)

계산

Case (a)  B = 0

\(\psi = Ae^{ikx}\)

\(\hat{p}_x\psi = \frac{\hbar}{i}\frac{d}{dx}(Ae^{ikx})\) \(= \frac{\hbar}{i}(ik)(Ae^{ikx})\) \(= \frac{ik\hbar}{i}\cdot Ae^{ikx}\) \(= \boldsymbol{+\hbar k}\cdot\psi\)

✓ Eigenfunction

운동량 \(p = +\hbar k\)

→ +x 방향 진행파

Case (b)  A = 0

\(\psi = Be^{-ikx}\)

\(\hat{p}_x\psi = \frac{\hbar}{i}\frac{d}{dx}(Be^{-ikx})\) \(= \frac{\hbar}{i}(-ik)(Be^{-ikx})\) \(= \frac{-ik\hbar}{i}\cdot Be^{-ikx}\) \(= \boldsymbol{-\hbar k}\cdot\psi\)

✓ Eigenfunction

운동량 \(p = -\hbar k\)

→ −x 방향 진행파

A ≠ 0, B ≠ 0 이면?

Superposition → 운동량 미확정
\(\hat{p}_x(Ae^{ikx}+Be^{-ikx}) = +\hbar k\cdot Ae^{ikx} - \hbar k\cdot Be^{-ikx}\)

결과가 원래 ψ의 상수배가 아님 → Not eigenfunction

→ \(+\hbar k\) 방향과 \(-\hbar k\) 방향의 superposition: 운동량 불확정

→ cos/sin으로 쓰면 더 명확: \(\cos(kx) = \tfrac{1}{2}(e^{ikx}+e^{-ikx})\) → 두 방향 혼합 → 정재파(standing wave)

정리
파동함수Eigenfunction?운동량물리 의미
\(e^{ikx}\) (B=0)✓\(+\hbar k\)+x 진행파
\(e^{-ikx}\) (A=0)✓\(-\hbar k\)−x 진행파
\(Ae^{ikx}+Be^{-ikx}\)✗불확정두 방향 superposition

핵심: 복소지수 \(e^{\pm ikx}\)는 순수 진행파 = 운동량 확정. cos/sin은 superposition = 운동량 불확정. de Broglie \(p=\hbar k\)의 연산자 버전!

Orthogonality Example  — sin x & sin 2x

상황

운동에너지 연산자 \(\hat{E}_k = -\dfrac{\hbar^2}{2m_e}\dfrac{d^2}{dx^2}\)의 두 eigenfunction:

\(\psi_1 = \sin x, \qquad \psi_2 = \sin 2x\)

직교성 확인: \(\displaystyle\int_0^{2\pi}\sin(2x)\sin(x)\,dx = 0\)

Step 1 — 둘 다 진짜 eigenfunction인지 확인

sin x
\(\hat{E}_k\sin x = -\frac{\hbar^2}{2m_e}\frac{d^2\sin x}{dx^2} = -\frac{\hbar^2}{2m_e}(-\sin x) = \frac{\hbar^2}{2m_e}\sin x\)

Eigenvalue: \(\omega_1 = \dfrac{\hbar^2}{2m_e}\)

sin 2x
\(\hat{E}_k\sin 2x = -\frac{\hbar^2}{2m_e}\frac{d^2\sin 2x}{dx^2} = -\frac{\hbar^2}{2m_e}(-4\sin 2x) = \frac{4\hbar^2}{2m_e}\sin 2x = \frac{2\hbar^2}{m_e}\sin 2x\)

Eigenvalue: \(\omega_2 = \dfrac{4\hbar^2}{2m_e}\)

이론 예측 (먼저)

\(\omega_1 \neq \omega_2\) → Hermitian operator의 서로 다른 eigenvalue를 갖는 eigenfunction들은 반드시 직교 (이미 증명된 정리). 적분은 이걸 직접 확인하는 과정.

Step 2 — 직접 적분으로 확인

삼각함수 곱 → 합차 공식
\(\sin(2x)\sin(x) = \frac{1}{2}[\cos(2x-x) - \cos(2x+x)] = \frac{1}{2}[\cos x - \cos 3x]\)
적분 실행
\(\int_0^{2\pi}\sin(2x)\sin(x)\,dx = \frac{1}{2}\int_0^{2\pi}[\cos x - \cos 3x]\,dx\) \(= \frac{1}{2}\left[\frac{\sin x}{1} - \frac{\sin 3x}{3}\right]_0^{2\pi}\) \(= \frac{1}{2}\Bigl[(0-0)-(0-0)\Bigr] = \mathbf{0}\) ✓

정수 배수의 삼각함수를 완전 주기 [0, 2π] 위에서 적분하면 항상 0

직관 — 그래프로 보기

물리적 직관

슬라이드 그래프의 초록 영역: sin(2x)×sin(x)의 양수/음수 부분이 면적이 정확히 상쇄

→ 마치 서로 수직인 벡터의 내적이 0인 것처럼 — 두 함수가 함수 공간에서 서로 다른 "방향"을 차지

→ sin x, sin 2x, sin 3x … = Fourier 급수의 직교 기저가 되는 이유가 여기 있음

왜 직교성이 중요한가?

superposition \(\psi = \sum_k c_k\psi_k\)에서 계수 추출:

\(c_m = \int\psi_m^*\,\psi\,d\tau\)

직교성이 없으면 양변에 \(\psi_m^*\) 곱해도 다른 항들이 살아남아 \(c_m\)을 유일하게 결정 불가 → 확률 계산 불가 → 양자역학 붕괴

구면 극좌표 이론  — Laplacian · Legendrian · s/p/d 오비탈

수소원자 계산 전에 알아야 할 이론. 이게 s오비탈 vs p·d오비탈 풀이를 갈라놓는다.

1

좌표 변환 & 부피 요소

\(x = r\sin\theta\cos\phi, \quad y = r\sin\theta\sin\phi, \quad z = r\cos\theta\)
\(d\tau = r^2\sin\theta\,dr\,d\theta\,d\phi \quad \left(\,r\!\in[0,\infty),\;\theta\!\in[0,\pi],\;\phi\!\in[0,2\pi]\,\right)\)

\(r^2\): 반지름 클수록 껍질 부피 ↑   \(\sin\theta\): 극(θ=0,π)에서 부피 → 0으로 보정

각도 전체 적분: \(\displaystyle\int_0^\pi\sin\theta\,d\theta\int_0^{2\pi}d\phi = 2 \times 2\pi = 4\pi\)

2

라플라시안 ∇² — 구면좌표 표현

\(\nabla^2 = \underbrace{\frac{1}{r^2}\frac{\partial}{\partial r}\!\left(r^2\frac{\partial}{\partial r}\right)}_{\text{radial part}} + \underbrace{\frac{1}{r^2}\!\left[\frac{1}{\sin\theta}\frac{\partial}{\partial\theta}\!\left(\sin\theta\frac{\partial}{\partial\theta}\right) + \frac{1}{\sin^2\!\theta}\frac{\partial^2}{\partial\phi^2}\right]}_{\text{angular part} = \Lambda^2/r^2}\)

라플라시안 = 반지름 부분 + 각도 부분. 각도 부분만 따로 Legendrian \(\Lambda^2\)으로 정의.

3

Legendrian Λ²  (각도 연산자)

Legendrian 정의
\(\Lambda^2 = \frac{1}{\sin\theta}\frac{\partial}{\partial\theta}\!\left(\sin\theta\frac{\partial}{\partial\theta}\right) + \frac{1}{\sin^2\!\theta}\frac{\partial^2}{\partial\phi^2}\)

이걸 쓰면 라플라시안이 깔끔해짐:

\(\nabla^2 = \frac{1}{r^2}\frac{\partial}{\partial r}\!\left(r^2\frac{\partial}{\partial r}\right) + \frac{\Lambda^2}{r^2}\)
4

각운동량 연산자 L̂² 와의 관계

\(\hat{L}^2 = -\hbar^2\Lambda^2 \qquad \Longrightarrow \qquad \nabla^2 = \frac{1}{r^2}\frac{\partial}{\partial r}\!\left(r^2\frac{\partial}{\partial r}\right) - \frac{\hat{L}^2}{\hbar^2 r^2}\)

구면조화함수(spherical harmonics) \(Y_l^m(\theta,\phi)\)는 \(\hat{L}^2\)의 eigenfunction:

\(\hat{L}^2 Y_l^m(\theta,\phi) = \hbar^2 l(l+1)\,Y_l^m(\theta,\phi)\)
5

s / p / d 오비탈의 결정적 차이 — 각도 항 있냐 없냐

s 오비탈

l = 0

\(\hat{L}^2\psi = 0\)

θ, φ 의존성 없음

구면 대칭. 각도 적분 = 4π로 분리됨

p 오비탈

l = 1

\(\hat{L}^2\psi = 2\hbar^2\psi\)

\(Y_1^m(\theta,\phi)\) 포함

각도 적분 별도 계산 필요
(\(\cos\theta, \sin\theta e^{\pm i\phi}\) 등)

d 오비탈

l = 2

\(\hat{L}^2\psi = 6\hbar^2\psi\)

\(Y_2^m(\theta,\phi)\) 포함

더 복잡한 각도 함수.
적분에 추가 항 등장

왜 이게 풀이 방법을 바꾸나?

expectation value 계산 \(\langle r^2\rangle = \int|\psi|^2 r^2\,d\tau\)에서:

\(\langle r^2\rangle = \int_0^\infty\!\int_0^\pi\!\int_0^{2\pi} |\psi|^2\,r^2 \cdot r^2\sin\theta\,dr\,d\theta\,d\phi\)

s 오비탈 (각도 의존 없음):

\(= \int_0^\infty R(r)^2 r^4\,dr \;\cdot\; \underbrace{\int_0^\pi\sin\theta\,d\theta\int_0^{2\pi}d\phi}_{= 4\pi} \quad \leftarrow\text{ 반지름·각도 완전 분리}\)

p, d 오비탈 (각도 의존 있음):

\(|\psi|^2 = |R_{nl}(r)|^2\cdot|Y_l^m(\theta,\phi)|^2\) \(\Rightarrow \int|Y_l^m|^2\sin\theta\,d\theta\,d\phi \text{ 별도 계산 필요}\)

→ \(Y_l^m\)은 정규화되어 있어서 \(\int|Y_l^m|^2\,d\Omega = 1\)이지만, 적분 대상 자체가 바뀌면 별도 처리.

수소 1s 예제는 s 오비탈이라 각도 적분이 4π로 깔끔하게 분리된다!

Q3  — Expectation Value · ⟨r²⟩^(1/2) 수소 1s

문제

수소원자 1s 전자의 root-mean-square 거리 \(\langle r^2\rangle^{1/2}\)를 구하라.

\(\psi(r) = \left[\frac{1}{\pi a_0^3}\right]^{1/2}e^{-r/a_0}\)

θ, φ 없음 → s 오비탈 (l=0) → 각도 적분 4π로 분리 가능!

Expectation Value 공식
\(\langle r^2\rangle = \int\psi^*\,\hat{r}^2\,\psi\,d\tau = \int|\psi|^2\,r^2\,d\tau\)

\(\hat{r}^2\)는 그냥 곱하기 연산자 (위치 연산자): \(\hat{r}^2\,\psi = r^2\,\psi\)

Step 1 — 적분 세팅 & 분리

\(\langle r^2\rangle = \int_0^\infty\!\int_0^\pi\!\int_0^{2\pi} \frac{1}{\pi a_0^3}e^{-2r/a_0}\cdot r^2\cdot r^2\sin\theta\,dr\,d\theta\,d\phi\)

s 오비탈 → r 부분과 각도 부분 완전 분리:

\(= \frac{1}{\pi a_0^3}\int_0^\infty r^4 e^{-2r/a_0}\,dr \cdot \underbrace{\int_0^\pi\sin\theta\,d\theta}_{=\,2} \cdot \underbrace{\int_0^{2\pi}d\phi}_{=\,2\pi}\)

Step 2 — 각도 적분 처리

\(2 \times 2\pi = 4\pi\)
\(\langle r^2\rangle = \frac{1}{\pi a_0^3}\cdot 4\pi\cdot\int_0^\infty r^4 e^{-2r/a_0}\,dr = \frac{4}{a_0^3}\int_0^\infty r^4 e^{-2r/a_0}\,dr\)

Step 3 — 감마함수로 반지름 적분

감마함수 공식
\(\int_0^\infty r^n e^{-r/a}\,dr = n!\cdot a^{n+1}\)

우리 적분: \(n = 4\),  \(e^{-2r/a_0} = e^{-r/(a_0/2)}\) 이므로 \(a = a_0/2\)

감마함수 적용
\(\int_0^\infty r^4 e^{-2r/a_0}\,dr = 4!\cdot\left(\frac{a_0}{2}\right)^5 = 24\cdot\frac{a_0^5}{32} = \frac{3a_0^5}{4}\)

Step 4 — 최종 계산

\(\langle r^2\rangle = \frac{4}{a_0^3}\cdot\frac{3a_0^5}{4} = 3a_0^2\)
최종 답
\(\langle r^2\rangle^{1/2} = \sqrt{3}\,a_0 \approx 1.73\,a_0\)

\(a_0 = 52.9\;\text{pm}\)  →  RMS 거리 ≈ 91.6 pm

참고: 1s 오비탈의 평균 거리 \(\langle r\rangle = \frac{3}{2}a_0 = 1.5\,a_0\)

RMS \((\sqrt{3}\,a_0)\) > 평균 \((1.5\,a_0)\) — 파동함수의 꼬리(tail)가 큰 r까지 뻗어 있어서 제곱 평균이 더 커짐

전체 계산 흐름 요약

1
\(\langle r^2\rangle = \int\psi^*\,r^2\,\psi\,d\tau\) 세팅  — r² is just multiply
2
\(d\tau = r^2\sin\theta\,dr\,d\theta\,d\phi\) 삽입 → \(r^4 e^{-2r/a_0}\) 등장
3
s 오비탈: θ, φ 없음 → 각도 분리 → \(\int\sin\theta\,d\theta\int d\phi = 4\pi\)
4
\(\langle r^2\rangle = \dfrac{4}{a_0^3}\int_0^\infty r^4 e^{-2r/a_0}\,dr\)
5
감마함수: \(n=4,\; a = a_0/2\)  →  \(4!\cdot(a_0/2)^5 = 24\cdot a_0^5/32 = 3a_0^5/4\)
6
\(\langle r^2\rangle = 3a_0^2\)  →  RMS = \(\sqrt{3}\,a_0\)

12.  \(\psi(x) = \cos(kx)\)는 \(\hat{p}_x\)의 eigenfunction인가? 계산으로 판별하고 아닌 경우 물리적 의미를 설명하라.
