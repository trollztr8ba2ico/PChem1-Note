흑체복사 & Planck Distribution 완전 정리

Rayleigh-Jeans → UV 파탄 → Planck 해결까지

00

모드(Mode)란 무엇인가?

개념 정의

모드 = 경계조건을 만족하는 독립적인 정상파 하나. n=1, 2, 3...마다 하나씩 존재.

각 모드는 고유한 파장 λₙ = 2L/n과 진동수 νₙ = cn/2L을 가져.

흑체 안에서 빛은 이 모드들의 집합으로 이루어져 있고, 각 모드가 에너지를 독립적으로 저장하고 방출해.

PIB에서 n번째 에너지 준위 = 흑체에서 n번째 모드. 완전히 같은 논리.

01

사고실험 세팅 — 경계조건

슬라이드 11
조건

두 거울(x=0, x=L) 사이에 EM파 갇힘. 금속 표면에서 자유전자가 전기장 상쇄 → E=0.

E(0) = 0, E(L) = 0 → 파동함수: sin 형태

sin(kL) = 0 → kL = nπ → nλ = 2L

λₙ = 2L/n    νₙ = cn/2L    δν = c/2L (진동수 간격)

PIB와 완전히 동일한 논리. 경계조건 → sin → 허용 파장 이산화.

02

Rayleigh-Jeans Distribution 유도

고전역학
Step 1 — g₁D(ν)dν: 1D 모드 밀도

ν~ν+dν 사이 모드 수 = 두 구간 차이:

(ν+dν)/δν − ν/δν = dν/δν = 2L/c × dν

÷L (단위 길이당 보편 밀도), ×1 (sin 반대방향 무시, 교수님 방식):

g₁D(ν)dν = 2/c × dν

이 단계에서 계산하는 것: 진동수 구간 ν~ν+dν에 존재하는 1D 정상파 모드의 수.

Step 2 — g₃D(ν)dν: 3D 모드 밀도

x, y, z 방향 독립 → 확률 독립사건 → 곱:

(2/c)³ dνₓdνᵧdν_z = 8/c³ dνₓdνᵧdν_z

구면좌표 변환: ν²=νₓ²+νᵧ²+ν_z² → 구 껍질 부피 4πν²dν

유효 영역 (nₓ,nᵧ,n_z 모두 양수) → ×1/8, 편광 방향 2가지 → ×2:

g₃D(ν)dν = 8π/c³ × ν²dν

이 단계에서 계산하는 것: 3D 공간에서 진동수 구간 ν~ν+dν에 존재하는 모든 모드의 수.

Step 3 — g(ν) → g(λ) 변환

ν = c/λ 대입. dν = c/λ² × dλ 도 변환 필수:

g(λ)dλ = 8π/λ⁴ × dλ

이 단계에서 계산하는 것: 파장 기준으로 λ~λ+dλ 구간의 모드 수. 실험 스펙트럼과 비교하기 위해 λ 기준으로 바꿈.

Step 4 — ⟨E(λ,T)⟩ = kT (Boltzmann, 고전)

에너지 연속 가정 → Boltzmann 분포로 적분:

⟨E⟩ = ∫₀^∞ E · (1/kT) exp(−E/kT) dE = kT

equipartition theorem: 모든 모드가 파장 무관하게 균등하게 kT씩 보유.

이 단계에서 계산하는 것: 온도 T에서 모드 하나가 평균적으로 가지는 에너지.

Step 5 — Rayleigh-Jeans 완성
ρ(λ,T) = ⟨E⟩ × g(λ) = kT × 8π/λ⁴ = 8πkT/λ⁴

λ→0에서 λ⁴→0 → ρ→∞ → UV 파탄(Ultraviolet Catastrophe)

실험값이랑 단파장에서 완전히 불일치. 고전역학의 한계.

03

Planck Distribution 유도

양자역학 탄생

핵심 가정: E = nhν (n = 0, 1, 2, ...) — 에너지가 hν 단위로만 존재.

Step 1 — p(n) 구하기

n번째 모드에 있을 확률:

p(n) = exp(−nhν/kT) / Σₙ exp(−nhν/kT)

핵심 성질: f(x+y) = f(x)·f(y) → exp 함수. 에너지 높을수록 확률 지수적 감소.

Step 2 — ⟨E⟩ 계산 (등비급수 + 미분 트릭)
⟨E⟩ = Σ nhν · exp(−nhν/kT) / Σ exp(−nhν/kT)

x = exp(−hν/kT) 치환:

분모: Σxⁿ = 1/(1−x)   (등비급수)
분자: hν·Σnxⁿ = hν · x/(1−x)²   (분모를 x로 미분)

두 수열의 관계: Σnxⁿ은 Σxⁿ을 x로 미분한 것!

⟨E⟩ = hν · x/(1−x) = hν / (e^(hν/kT) − 1)

이 단계에서 계산하는 것: 에너지가 이산적일 때 진동수 ν인 모드의 평균 에너지.

Step 3 — Planck Distribution 완성

ν = c/λ 대입 후 g(λ) 곱하기:

ρ(λ,T) = 8πhc / λ⁵(e^(hc/λkT) − 1)

λ⁵이 나오는 이유: g(λ)의 λ⁴ + ⟨E⟩의 hc/λ에서 λ 하나 더 → λ⁵

04

극한 조건 검증

자기 일관성 증명
단파장 λ→0 (UV 파탄 해결)

hc/λkT → ∞

e^∞ → ∞ → 분모 폭발

→ ρ → 0

발산하지 않고 꺾임. UV 파탄 해결.

장파장 λ→∞ (Rayleigh-Jeans 수렴)

hc/λkT → 0

Taylor 전개: e^x ≈ 1+x

e^(hc/λkT) − 1 ≈ hc/λkT

→ ρ ≈ 8πkT/λ⁴ ✓

05

예제 — 2000K 용광로

실전 계산
Q1. 왜 주황색으로 보이나?

Planck 그래프에서 2000K 피크 ≈ 1.45μm → 적외선 영역.

가시광선(0.42~0.70μm)에는 곡선의 꼬리만 걸침.

그 꼬리에서 700nm(빨강) 쪽이 450nm(파랑)보다 훨씬 높음 → 빨강/주황만 유의미하게 방출 → 주황색.

Q2. ρ(450nm) / ρ(700nm) at T=2000K

비율이므로 8πhc 약분. hc/kT = 7189nm.

hc/λkT:   λ=700 → 10.27    λ=450 → 15.98
e^10.27−1 ≈ 28,964    e^15.98−1 ≈ 8,718,000
(700/450)⁵ ≈ 9.12
ρ(450)/ρ(700) = 9.12 × 28,964 / 8,718,000 ≈ 0.030

450nm 에너지는 700nm의 약 3%. 파란빛이 거의 안 나오는 이유.
