왜 수소원자부터 시작하나?

📌 Hydrogenic Atom 정의

전자가 딱 1개인 원자/이온. H, He²⁺, Li²⁺, O⁷⁺ 같은 것들.

핵심은 이거야 — 이 계는 Schrödinger 방정식을 근사 없이 정확하게(exactly) 풀 수 있어. 다전자 원자는 전자끼리 반발이 있어서 exact solution이 없는데, 수소꼴은 핵-전자 딱 두 입자라서 가능.

출발점은 실험이었어

1800년대 말, 수소 방전관에서 빛을 쪼개면 연속 스펙트럼이 아니라 딱 정해진 파장의 선들만 나왔어. Balmer가 1885년에 경험식으로 맞췄는데, 왜 그런지는 아무도 몰랐지. Bohr가 1913년에 "전자가 특정 궤도만 돈다"고 가정해서 값을 맞췄지만 그건 그냥 가정이었어.

🎯 이 챕터의 목표

Schrödinger 방정식을 풀어서, 가정 없이 순수하게 에너지 준위와 스펙트럼을 유도해내는 것. Bohr가 가정했던 것들이 수학에서 자연스럽게 튀어나오게 만드는 거야.

Hydrogen Spectrum — 실험 배경

수소 방전관 실험으로 얻은 스펙트럼. 연속이 아니라 선 스펙트럼이고, Rydberg 공식으로 정리돼:

$$\tilde{\nu} = \tilde{R}_H \left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right) \qquad \tilde{R}_H = 109{,}677 \text{ cm}^{-1}$$

편하게 \(T_n = \tilde{R}_H / n^2\) 로 정의하면:

$$\tilde{\nu} = T_1 - T_2, \quad \nu = cT_1 - cT_2, \quad \Delta E = hcT_1 - hcT_2$$

수소원자를 정확히 풀면 Bohr가 "가정"했던 것들이 전부 수학에서 강제로 튀어나와. 그게 이 챕터 전체의 핵심이야.

Potential Energy & Hamiltonian

쿨롱 퍼텐셜

두 전하 q₁, q₂가 거리 r 떨어져 있을 때 힘과 퍼텐셜:

$$F = \frac{q_1 q_2}{4\pi\varepsilon_0 r^2}, \qquad V = \frac{q_1 q_2}{4\pi\varepsilon_0 r}$$

핵 전하 Ze, 전자 전하 −e 대입하면:

$$V(r) = -\frac{Ze^2}{4\pi\varepsilon_0 r}$$
⚠️ 부호 주의

음수야! 인력이니까 당연히 V < 0. 전자가 핵 가까이 있을수록(r 작을수록) V가 더 음수가 돼 → 더 낮은 에너지 → 더 안정.

Hamiltonian 전체

전자 운동에너지 + 핵 운동에너지 + 쿨롱 퍼텐셜:

$$\hat{H} = -\frac{\hbar^2}{2m_e}\nabla_e^2 - \frac{\hbar^2}{2m_N}\nabla_N^2 - \frac{Ze^2}{4\pi\varepsilon_0 r}$$

Reduced Mass — 두 입자 → 한 입자로

📌 왜 환산질량이 필요하냐?

전자와 핵 두 입자의 운동에너지를 질량중심(CM) 운동 + 상대 운동으로 분리하면:

$$\frac{p_1^2}{2m_1} + \frac{p_2^2}{2m_2} = \frac{1}{2}m\left(\frac{dX}{dt}\right)^2 + \frac{1}{2}\mu\left(\frac{dx}{dt}\right)^2$$

왼쪽은 두 입자 각각, 오른쪽은 CM 운동 + 상대 운동으로 분리된 거야. CM 운동은 그냥 자유입자라 무시 가능 → 상대 운동 하나만 남아!

$$\frac{1}{\mu} = \frac{1}{m_e} + \frac{1}{m_N} \quad \Rightarrow \quad \mu = \frac{m_e m_N}{m_e + m_N}$$

핵이 전자보다 훨씬 무거우니까 (m_N ≫ m_e):

$$\frac{1}{\mu} \approx \frac{1}{m_e} \quad \Rightarrow \quad \mu \approx m_e$$
🔗 7E·7F와의 연결

환산질량은 7E(조화진동자 이원자분자)와 7F(회전운동 이원자분자)에서 이미 썼던 거야. 거기선 핵-핵 두 입자계였고, 여기선 전자-핵 두 입자계인 것만 달라. 논리는 완전히 동일!

최종 Schrödinger 방정식

변수분리 후 CM 운동 제거하면 수소꼴 원자의 Schrödinger 방정식이 남아:

$$-\frac{\hbar^2}{2\mu}\nabla^2\psi - \frac{Ze^2}{4\pi\varepsilon_0 r}\psi = E\psi$$
✅ E의 의미

여기서 E는 핵 위치가 고정된 상태에서의 상대 좌표 에너지야. 실질적으로 전자의 에너지.

각도와 Radial 운동 분리

V(r)이 r에만 의존 (centrosymmetric) → 변수분리 가능!

$$\psi(r,\theta,\phi) = R(r) \cdot Y(\theta,\phi)$$

구면좌표 Laplacian 대입

$$\nabla^2 = \frac{\partial^2}{\partial r^2} + \frac{2}{r}\frac{\partial}{\partial r} + \frac{1}{r^2}\Lambda^2$$

대입 후 r²/RY 를 곱해서 정리하면:

$$-\frac{\hbar^2}{2\mu R}\left(r^2\frac{d^2R}{dr^2} + 2r\frac{dR}{dr}\right) + Vr^2 - \frac{\hbar^2}{2\mu Y}\Lambda^2 Y = Er^2$$

7F에서 이미 구한 결과 Λ²Y = −l(l+1)Y 를 대입하면 θ,φ가 사라져!

u(r) = rR(r) 치환

📌 왜 이 치환을 하냐?

r에 대한 방정식에서 r²d²R/dr² + 2r·dR/dr 이 복잡하게 얽혀있어. u = rR로 놓으면 이게 r·d²u/dr²로 깔끔하게 정리돼 → 1D Schrödinger 방정식 형태로 단순화!

$$-\frac{\hbar^2}{2\mu}\frac{d^2u}{dr^2} + V_{\text{eff}}\, u = Eu$$
🔢 유효 퍼텐셜
$$V_{\text{eff}}(r) = -\frac{Ze^2}{4\pi\varepsilon_0 r} + \frac{l(l+1)\hbar^2}{2\mu r^2}$$

쿨롱 인력(음수) + 원심력 항(양수) 두 개로 구성.

원심력 항이 왜 생기나?

고전역학에서 먼저

원운동하는 물체의 총 에너지를 동경 방향 + 접선 방향으로 분리하면:

$$E = \frac{1}{2}\mu\dot{r}^2 + \frac{J^2}{2\mu r^2} + V(r) = \frac{1}{2}\mu\dot{r}^2 + V_{\text{eff}}(r)$$

J²/2μr² 항은 사실 접선 운동에너지인데, r만의 방정식으로 만들기 위해 퍼텐셜 쪽으로 넘긴 것이야. "원심력 항"이라고 부르는 이유는 r을 키우는 방향으로 작용하기 때문.

QM에서는 J² → l(l+1)ℏ²

7F에서 배운 것: l²ψ = l(l+1)ℏ² · ψ. 그래서:

$$\frac{J^2}{2\mu r^2} \xrightarrow{\text{QM}} \frac{l(l+1)\hbar^2}{2\mu r^2}$$

V_eff 그래프 해석

l = 0 (s 오비탈)

원심력 항 = 0

V_eff = 쿨롱 항만

r→0 으로 갈수록 −∞까지 내려감

전자가 핵 바로 옆까지 접근 가능 → ψ(0) ≠ 0

l ≠ 0 (p, d, ...)

원심력 항이 r→0 에서 +∞로 발산

r=0 근처에 장벽 생김

전자가 핵에 아예 못 가까이 감 → ψ(0) = 0

행성이 태양으로 안 떨어지는 것과 같은 원리!

🔗 7F 회전운동과의 연결

Sphere 문제에서 Λ²Y = −l(l+1)Y 라는 고유값 방정식이 나왔잖아. 그게 여기서 그대로 쓰여서 각도 방정식을 날려버리는 거야. 7F를 끝냈기 때문에 8장의 절반은 이미 풀린 셈이야!

Radial Wavefunction 풀기

최종 형태 — 세 부분의 곱

$$R_{n,l}(r) = N_{n,l} \cdot \rho^l \cdot L_{n-l-1}^{2l+1}(\rho) \cdot e^{-\rho/2}$$
$$\rho = \frac{2Zr}{na}, \quad a = \frac{m_e}{\mu}a_0 \approx a_0, \quad a_0 = \frac{4\pi\varepsilon_0\hbar^2}{m_e e^2} = 52.9 \text{ pm}$$

a₀ = Bohr 반지름. n마다 ρ 정의가 달라지니까 항상 n 대입 확인!

① ρˡ — 핵 근처 거동 (r→0)

l=0이면 ρ⁰=1 → 핵에서 유한값 (s 오비탈이 핵에서 0 안 됨)

l≥1이면 r=0에서 0 → 원심력 장벽 반영 (p,d,...는 핵 근처에서 0)

② L — 연관 라게르 다항식 (Laguerre Polynomial)

HO에서 Hermite 다항식이 나왔던 것처럼, 여기선 Laguerre 다항식이 나와. 둘 다 급수해가 발산하지 않도록 급수를 절단(truncate)해서 생기는 다항식이야. 구조가 완전히 같아!

$$L_n^{(\alpha)}(x) = \frac{x^{-\alpha}e^x}{n!}\frac{d^n}{dx^n}\left(e^{-x}x^{n+\alpha}\right)$$

다항식 차수 = n−l−1 = radial node 수

③ e^{−ρ/2} — 원거리 감쇠 (r→∞)

r이 커질수록 지수적으로 감쇠 → ψ가 무한대에서 0으로 수렴 (물리적 경계조건 충족)

n이 왜 양자수가 되냐 — 급수 절단

⚡ 핵심 메커니즘 — HO와 완전히 동일한 구조!

동경 방정식을 급수해로 풀면 r→∞에서 발산할 수 있어. 발산하지 않으려면 급수가 반드시 유한 항에서 끊겨야(truncate) 해.

절단 조건: n−l−1 ≥ 0 → n ≥ l+1

→ n은 양의 정수 (1, 2, 3, ...)

→ 주어진 n에서 l = 0, 1, ..., n−1

HO에서 "v가 정수여야 급수 절단" ↔ 여기서 "n이 정수여야 급수 절단" — 완전히 같은 논리!

에너지 양자화

$$E_n = -\frac{\mu e^4}{32\pi^2\varepsilon_0^2\hbar^2} \cdot \frac{Z^2}{n^2} = -\frac{hcZ^2\tilde{R}_N}{n^2}$$
$$\tilde{R}_N = \frac{\mu}{m_e}\tilde{R}_\infty, \qquad \tilde{R}_\infty = \frac{m_e e^4}{8\varepsilon_0^2 h^3 c}$$

수소(Z=1, n=1)에서 E₁ = −13.6 eV

📌 E=0 기준점의 의미

전자와 핵이 무한히 멀리 떨어져서 정지해 있는 상태를 E=0으로 정의했어. Bound state는 그보다 에너지가 낮아서(E<0) 스스로 탈출 못해. 이온화 에너지 I = hcR̃_H = 13.6 eV를 줘야 탈출 가능.

연속 영역(E≥0)에서 자유전자는 양쪽 경계조건을 동시에 만족시킬 필요가 없어서 에너지가 연속이 돼. 양자화는 "묶힌 상태"의 특징이야.

Shell과 Subshell — 어떻게 나오냐?

🔑 Shell이 인위적 분류가 아닌 이유

E_n = −hcZ²R̃_N/n² — 에너지가 n만으로 결정되고 l, m_l에 무관해 (수소 특유!). 그래서 n이 같은 오비탈들의 에너지가 전부 같아. 에너지가 같은 오비탈들이 자연스럽게 묶인 게 Shell이야.

n²-fold 縮退 유도

주어진 n에서 l=0,1,...,n−1이고, 각 l마다 m_l이 (2l+1)개:

$$\sum_{l=0}^{n-1}(2l+1) = 1 + 3 + 5 + \cdots + (2n-1) = n^2$$
⚠️ n²-fold 縮退는 수소 특유!

E_n이 l에 무관하게 n만으로 결정되기 때문. 다전자 원자에서는 l에 따라 에너지가 달라져서 이 추가 縮退가 깨져. 3s < 3p < 3d 순서가 되는 거야.

Ionization Energy

$$I = hc\tilde{R}_H\left(\frac{1}{n_1^2} - \frac{1}{\infty^2}\right) = hc\tilde{R}_H = 13.6 \text{ eV}$$

n₁=1, n₂=∞로 놓은 거야. ν̃를 1/n²에 대해 플롯하면 y절편에서 I/hcn₁²을 읽을 수 있고, 기울기 = −R̃_H. 실험 스펙트럼 선 위치만 측정해도 이온화 에너지와 Rydberg 상수를 동시에 얻는 거야!

s Orbital — n=1, l=0, m_l=0

1s 파동함수 만들기

표에서 R_{1,0}과 Y_{0,0} 곱하면:

$$\psi_{1s} = R_{1,0} \times Y_{0,0} = 2\left(\frac{Z}{a}\right)^{3/2}e^{-\rho/2} \times \left(\frac{1}{4\pi}\right)^{1/2}$$

ρ = 2Zr/na = 2r/a (n=1, Z=1) 대입하면:

$$\psi_{1s} = \left(\frac{1}{\pi a^3}\right)^{1/2} e^{-r/a}$$
📌 왜 구형(sphere)인가?

ψ에 θ, φ가 아예 없어. Y_{0,0} = (1/4π)^{1/2} = 상수이기 때문이야. 방향에 무관하게 r만의 함수 → 어느 방향으로 잘라도 같은 모양 → 완전한 구형 대칭.

오비탈 표현 방법 두 가지

|ψ|² 표현

전자 밀도를 음영으로 나타냄. 핵 근처일수록 진함. 연속적인 확률밀도를 표현.

Boundary Surface 표현

전자를 90% 확률로 발견할 수 있는 공간의 경계면. 우리가 흔히 보는 오비탈 그림이 이거야.

에너지와 파동함수 모양 — 왜 그 모양이냐?

ψ가 핵 가까이 집중되면: 퍼텐셜에너지 낮음 BUT 곡률 커 → 운동에너지 높음 (7B: 곡률 ∝ 운동에너지)

ψ가 멀리 퍼지면: 운동에너지 낮음 BUT 퍼텐셜에너지 높음

바닥 상태 1s = 두 에너지 합이 최소가 되는 절충점!

Radial Distribution Function P(r)

왜 P(r) = r²R(r)²인가?

📌 직관부터

우리가 알고 싶은 건 "핵에서 거리 r인 구각 전체에서 전자를 찾을 확률"이야. 특정 방향이 아니라 거리만!

구각의 부피 = 4πr²dr. s 오비탈처럼 각도 의존성 없으면: P(r)dr = |ψ|² × 4πr²dr

일반적으로는 θ,φ로 적분해야 하는데, Y 정규화 조건 ∫|Y|²sinθ dθ dφ = 1 이니까 각도 부분이 사라져서:

$$P(r) = r^2 R(r)^2$$
⚡ P(r)의 물리적 해석 3가지

P(0) = 0 — r=0에서 r²=0. 핵 위치의 |ψ|²는 0이 아니지만, 구각의 부피가 0이라서 찾을 확률이 0.

P(∞) = 0 — e^{−ρ/2} 지수 감쇠가 r²을 이겨서 0으로 수렴.

중간에 최대값 존재 — r²의 증가 vs e^{−ρ/2}의 감소가 균형 잡히는 점.

1s의 최대값 r* 구하기

$$P(r) = \frac{4Z^3}{a_0^3} r^2 e^{-2Zr/a_0}$$
$$\frac{dP}{dr} = 0 \implies 2r - \frac{2Zr^2}{a_0} = 0 \implies r^* = \frac{a_0}{Z}$$

수소(Z=1)에서 r* = a₀ = 52.9 pm — Bohr 반지름!

✅ Bohr 모델과의 연결

Bohr가 "전자가 이 궤도를 돈다"고 가정했던 그 반지름이, QM에서는 "전자를 가장 찾기 쉬운 거리"로 자연스럽게 유도돼. 가정이 결론이 된 거야!

⟨r⟩ 계산 — 2s 평균 반지름

기댓값 정의 + 구면좌표 부피요소:

$$\langle r \rangle = \int_0^\infty \int_0^\pi \int_0^{2\pi} \psi^* r \psi \cdot r^2\sin\theta\, dr\, d\theta\, d\phi$$

Y 정규화 → 각도 적분 = 1 → r 적분만 남음:

$$\langle r \rangle_{2s} = \int_0^\infty r^3 R_{2,0}^2\, dr$$

R_{2,0} = (1/8^{1/2})(Z/a)^{3/2}(2−ρ)e^{−ρ/2}, ρ=Zr/a 치환 후:

$$\langle r \rangle = \frac{a}{8Z}\int_0^\infty \rho^3(2-\rho)^2 e^{-\rho}\,d\rho$$

(2−ρ)² = 4−4ρ+ρ² 전개 후 ∫₀^∞ ρⁿe^{−ρ}dρ = n! 적용:

$$4\times 3! - 4\times 4! + 5! = 24 - 96 + 120 = 48$$
$$\langle r \rangle_{2s} = \frac{a}{8Z} \times 48 = \frac{6a}{Z}$$
🔢 Γ함수/계승 공식

\(\displaystyle\int_0^\infty \rho^n e^{-\rho}\,d\rho = n!\) — 부분적분을 n번 반복하면 유도 가능. 시험에서 줄 수도 있고 아닐 수도 있으니 유도 흐름 이해해두기!

Radial node 계산 (2s)

R_{2,0} ∝ (2−ρ)e^{−ρ/2}. e^{−ρ/2}≠0이니까:

$$2 - \rho = 0 \implies \rho = 2 \implies r = \frac{na}{Z} = 2a_0 \text{ (수소)}$$

Radial node 개수: n−l−1 = 2−0−1 = 1개 ✓

p Orbital — n=2, l=1, m_l=0, ±1

m_l=0: ψ_{2p_z}

$$\psi_{2,1,0} = R_{2,1}(r)\,Y_{1,0}(\theta,\phi) = \frac{1}{4(2\pi)^{1/2}}\left(\frac{Z}{a_0}\right)^{5/2} r\cos\theta\, e^{-Zr/2a_0}$$

r cosθ = z (구면좌표 → 직교좌표) 이니까:

$$\psi_{2p_z} = z \cdot f(r)$$

z에 비례 → z축 방향 아령 모양. θ=0(z축)에서 최대, θ=90°(xy평면)에서 0 → xy평면이 nodal plane.

m_l=±1: 복소수 문제 등장

$$\psi_{2,1,\pm1} \propto r\sin\theta\, e^{\pm i\phi}\, e^{-Zr/2a_0}$$

e^{±iφ}가 있어서 복소수 파동함수야. |ψ|²은 실수로 나오지만 ψ 자체가 복소수면 "어느 방향을 향하는지" 시각화하기 불편해.

Linear Combination — 왜 쓰냐?

📌 정당화 — 필기 핵심 논리

ψ₁, ψ₂가 같은 에너지 E의 고유함수이면:

$$\hat{H}(c_1\psi_1 + c_2\psi_2) = c_1 E\psi_1 + c_2 E\psi_2 = E(c_1\psi_1 + c_2\psi_2)$$

→ 선형결합도 같은 E의 고유함수! 에너지 안 바뀌어.

ψ_{2,1,+1}과 ψ_{2,1,−1}이 둘 다 같은 에너지 E₂의 縮退 상태니까, 섞어도 여전히 E₂의 고유함수야.

실수 오비탈 만들기

$$\psi_{2p_x} = \frac{1}{\sqrt{2}}(\psi_{2,1,+1} - \psi_{2,1,-1}) \propto r\sin\theta\cos\phi\cdot f(r) = x\cdot f(r)$$
$$\psi_{2p_y} = \frac{i}{\sqrt{2}}(\psi_{2,1,+1} + \psi_{2,1,-1}) \propto r\sin\theta\sin\phi\cdot f(r) = y\cdot f(r)$$

오일러 공식: e^{+iφ} − e^{−iφ} = 2i sinφ, e^{+iφ} + e^{−iφ} = 2cosφ 로 복소수가 사라지는 거야!

✅ 왜 x, y, z 방향인가?

구면좌표 → 직교좌표: x = r sinθ cosφ, y = r sinθ sinφ, z = r cosθ

각 파동함수가 x, y, z 좌표 그 자체에 비례하니까 그 축 방향으로 뻗은 아령이 나와. 일반화학에서 외웠던 p_x, p_y, p_z가 Schrödinger 방정식 해의 실수 선형결합이었던 거야!

⚠️ p_x, p_y, p_z는 방정식의 직접 해가 아니야

직접 해는 m_l=0,±1인 복소수 함수야. p_x, p_y, p_z는 편의를 위해 실수로 변환한 거고, 에너지는 동일하게 유지돼.

🔴 유도형 (40%)

Q1. 환산질량(reduced mass)을 도입하는 이유와 유도 과정을 설명하라.
ANSWER DIRECTION

두 입자계의 운동에너지 p₁²/2m₁ + p₂²/2m₂를 질량중심 좌표 X와 상대 좌표 x로 변환하면 ½m(dX/dt)² + ½μ(dx/dt)² 로 분리됨을 보여. 1/μ = 1/m₁ + 1/m₂ 정의. 쿨롱 퍼텐셜이 상대 좌표만의 함수이므로 CM 운동은 자유입자로 분리 → 내부 운동 방정식만 남음.

Q2. V_eff(r) = −Ze²/4πε₀r + l(l+1)ℏ²/2μr²에서 두 번째 항(원심력 항)의 출처를 설명하라.
ANSWER DIRECTION

고전역학: 총 에너지를 동경 방향 운동에너지 + 접선 방향 운동에너지 + V(r)로 분리 → 접선 KE = J²/2μr²이 r 방정식에서 유효 퍼텐셜로 흡수됨. QM에서 J² → l(l+1)ℏ² (각운동량 연산자 고유값). l=0이면 0, l≥1이면 r=0 근처에 장벽 생성.

Q3. 주양자수 n이 양자화되는 수학적 이유를 Laguerre 다항식과 연결하여 설명하라.
ANSWER DIRECTION

radial 방정식의 급수해에서 r→∞ 발산 금지 조건 → 급수 절단 필요 → n−l−1 ≥ 0인 정수 n만 허용. 조화진동자(Hermite 급수 절단)와 동일한 메커니즘. 절단된 다항식이 연관 Laguerre 다항식 L^{2l+1}_{n−l−1}.

Q4. 수소원자에서 n²-fold 縮退가 생기는 이유를 설명하라.
ANSWER DIRECTION

E_n = −hcZ²R̃_N/n²이 n에만 의존하고 l, m_l에 무관 → 같은 n의 모든 오비탈이 같은 에너지. Σ(2l+1) = n² 계산. 다전자 원자에서는 l-dependent screening으로 이 추가 縮退가 깨짐.

🟡 원리·설명형 (30%)

Q5. s 오비탈의 radial distribution function P(r)이 r=0에서 0이고 r=a₀에서 최대인 이유를 설명하라.
ANSWER DIRECTION

P(0)=0: r²=0이라 구각 부피 = 4πr²dr = 0. |ψ(0)|² ≠ 0이어도 부피가 없으니 확률 없음. r*=a₀: r²의 증가(↑)와 e^{−2r/a₀}의 감소(↓) 경쟁. dP/dr=0에서 r*=a₀/Z.

Q6. p_x, p_y, p_z가 Schrödinger 방정식의 직접 해가 아닌 이유와 linear combination의 정당화를 설명하라.
ANSWER DIRECTION

직접 해는 m_l=±1인 복소수 함수 e^{±iφ}. 같은 E의 고유함수 선형결합은 여전히 같은 E의 고유함수 (Ĥ(c₁ψ₁+c₂ψ₂)=E(c₁ψ₁+c₂ψ₂)). 오일러 공식으로 실수 변환 → p_x ∝ sinθcosφ = x/r, p_y ∝ sinθsinφ = y/r. 에너지 동일, 모양만 실수화.

Q7. l≠0인 오비탈에서 ψ(0)=0인 이유를 V_eff와 연결하여 설명하라.
ANSWER DIRECTION

V_eff의 원심력 항 l(l+1)ℏ²/2μr²이 r→0에서 +∞로 발산 → 에너지 장벽 형성 → 전자가 핵 근처 접근 불가. Radial WF에서 ρˡ 인자가 r→0 에서 0이 됨 (l≥1). R_{n,l}(0) = 0.

Q9. 중수소(²H) 바닥상태 에너지를 수소와 비교하여 구하라.

Q10. n=3 shell에서 가능한 모든 subshell과 orbital 수를 구하고 n²임을 확인하라.
