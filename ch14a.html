14A Electric Properties of Molecules

Electric Dipole Moment — 전기 쌍극자 모멘트

개념
왜 이게 필요한가?
분자 간 상호작용(응집상 형성, 약물-수용체 결합)은 결국 분자의 전하 분포에서 나온다. 가장 단순한 전하 분포의 척도가 전기 쌍극자 모멘트 μ다.

정의

+Q와 −Q의 두 전하가 거리 R만큼 떨어져 있을 때:

$$\mu = QR$$
Magnitude of the electric dipole moment [Definition]
핵심
방향: 음전하(−Q) → 양전하(+Q)로 향하는 벡터량
SI 단위: C·m (쿨롱·미터)
실용 단위: Debye (D), \(\;1\,\text{D} = 3.33564 \times 10^{-30}\,\text{C·m}\)

왜 Debye 단위를 따로 쓰냐면, C·m 단위로 표기하면 분자 수준 쌍극자가 10⁻³⁰ 단위라 너무 불편하기 때문이다. 작은 분자들은 대략 1 D 수준이다.

단위 감각
전자 하나(e = 1.602×10⁻¹⁹ C)가 100 pm 떨어져 있으면 μ ≈ 4.8 D.
실제 분자에서 HCl ≈ 1.08 D → 전자 1개 전하의 약 22%만 분리된 효과.

Permanent vs Induced Dipole

Permanent dipole

  • 전기음성도 차이로 인한 부분 전하
  • 항상 존재 (전기장 불필요)
  • 극성 분자 (polar molecule)
  • 예: H₂O (1.85 D), HCl (1.08 D)

Induced dipole

  • 외부 전기장이 전자 구름을 왜곡
  • 전기장 있을 때만 존재
  • 비극성 분자에서도 생성
  • 예: CCl₄, H₂ (μ = 0이지만 α≠0)

대칭과 쌍극자 — 벡터 합산

주의
"이종핵 결합이 있다 ≠ 극성 분자"
분자 대칭이 개별 결합 쌍극자를 상쇄시킬 수 있다.

CO₂: O=C=O 선형 → 두 C=O 쌍극자 정반대 방향 → μ = 0
O₃: 굽은 구조 → 상쇄 안 됨 → μ ≠ 0
CCl₄: 정사면체 대칭 → 4개 결합 쌍극자 완전 상쇄 → μ = 0

벡터 합산 공식 — 다이클로로벤젠 이성질체

두 쌍극자 μ₁, μ₂가 각도 θ를 이룰 때 합력:

$$\mu_\text{res} \approx \left(\mu_1^2 + \mu_2^2 + 2\mu_1\mu_2\cos\theta\right)^{1/2}$$

μ₁ = μ₂ = μ인 경우 (클로로벤젠 이성질체), 반각 공식 \(1+\cos\theta = 2\cos^2\tfrac{\theta}{2}\)를 쓰면:

$$\mu_\text{res} \approx 2\mu\cos\tfrac{\theta}{2}$$
같은 크기의 두 쌍극자일 때
이성질체θ (두 Cl 사이)μ_res / μ₁μ_calc (D)μ_obs (D)
para (b)180°2cos90° = 000
ortho (c)60°2cos30° = √32.72.25
meta (d)120°2cos60° = 11.61.48
결론
ortho/meta 비율: cos30°/cos60° = (√3/2)/(1/2) = √3 ≈ 1.73
실험값: 2.25/1.48 ≈ 1.52 — 벤젠 고리 자체 전자 분포를 무시한 근사이므로 완벽하지 않다.

다원자 분자의 일반화

원자가 여러 개일 때 각 방향 성분을 따로 합산:

$$\mu_x = \sum_J Q_J x_J \qquad \mu = \left(\mu_x^2 + \mu_y^2 + \mu_z^2\right)^{1/2}$$
General form — Molecular dipole moment

Multipoles — 쌍극자를 넘어서

동기
CCl₄처럼 dipole = 0인 분자는 어떻게 전기적으로 특징짓나?
→ 더 고차 모멘트(quadrupole, octupole)가 필요하다.

계층 구조

이름n조건예시
Monopole 1 점전하 Na⁺, Cl⁻
Dipole 2 알짜 전하 = 0, dipole ≠ 0 HCl, H₂O
Quadrupole 3 알짜 전하 = 0, dipole = 0, quadrupole ≠ 0 CO₂, H₂
Octupole 4 위 전부 0, octupole ≠ 0 CH₄ (정사면체)
핵심 정의
n-pole: "n-pole moment는 있지만 그보다 낮은 차수 moment는 없는" 전하 배열.

CH₄: H(δ+), C(δ−)로 이종 원소 결합이 있지만, 정사면체 대칭으로 dipole = 0, quadrupole = 0 → 최저차 moment는 octupole이다.

왜 중요한가 — 거리 의존성

수식
고차 multipole일수록 상호작용이 거리에 따라 더 빠르게 감쇠한다:

  • monopole–monopole: \(\propto 1/r\)
  • monopole–dipole: \(\propto 1/r^2\)
  • dipole–dipole: \(\propto 1/r^3\)
  • dipole–quadrupole: \(\propto 1/r^4\)
결론
CCl₄처럼 완전히 대칭인 분자라도 quadrupole, octupole moment를 통해 다른 분자와 상호작용한다. 다만 그 상호작용은 짧은 거리에서만 유의미하다.

Polarizabilities — 분극능 α

직관
전자 구름은 핵에 묶여 있지만 완벽하게 고정된 건 아니다. 외부 전기장 ε이 걸리면 전자 구름이 한쪽으로 쏠리면서 유도 쌍극자가 생성된다. α는 "이 변형이 얼마나 잘 일어나냐"의 척도다.

정의

$$\mu^* = \alpha \mathcal{E}$$
Polarizability [Definition] — 선형 근사

강한 전기장에서는 고차 항이 중요해진다:

$$\mu^* = \alpha\mathcal{E} + \tfrac{1}{2}\beta\mathcal{E}^2 + \cdots$$
Hyperpolarizability β 포함 — 비선형 광학에서 중요

Polarizability volume α′

SI 단위의 α가 불편하므로 체적 단위로 표현:

$$\alpha' = \frac{\alpha}{4\pi\varepsilon_0}$$
Polarizability volume [Definition]
핵심
α′의 단위: m³. 수치는 10⁻³⁰ m³ ≈ 1 Å³ — 실제 분자 부피와 비슷한 크기!
직관: 전자 구름이 크게 퍼진 분자일수록 잘 변형된다 → α′ ∝ 분자 크기.

교수님 Q&A — HOMO-LUMO gap과 레이저 흡수

Q1. HOMO-LUMO gap과 α의 관계는?
양자역학적 설명 (2차 섭동이론)
외부 전기장은 바닥 상태 오비탈에 들뜬 상태 오비탈 성격을 섞어 넣는 효과를 낸다. 에너지 분모가 작을수록 더 잘 섞인다: $$\alpha \propto \frac{1}{E_\text{LUMO} - E_\text{HOMO}}$$ → HOMO-LUMO gap이 작을수록 α가 크다.
예: 공액 π계가 길어질수록 gap ↓ → α ↑ (벤젠 < 나프탈렌 < 안트라센)
Q2. α가 커질수록 흡수하는 레이저 파장은?
α ↑ → HOMO-LUMO gap ↓ → 전자 전이에 필요한 에너지 ↓
\(E = hc/\lambda\) → E ↓이면 λ ↑

→ α가 클수록 더 긴 파장(낮은 에너지)의 빛을 흡수한다. (적색편이)
β-카로틴(당근 색소)이 주황색으로 보이는 이유: 공액 이중결합이 11개 → gap 작음 → 가시광 흡수.
Q3. 벤젠의 α는 어느 방향으로 더 큰가?
벤젠은 평면 육각형. π 전자가 고리를 따라 비편재화(delocalized)되어 있다.

면 내(in-plane) α > 면 수직(out-of-plane) α

이유: 면 내에서는 π 전자가 고리 전체를 따라 자유롭게 이동하여 전기장에 반응 가능. 수직 방향은 전자가 움직일 수 있는 공간이 제한적이다.
→ 벤젠은 이방성 분극능(anisotropic polarizability)을 가진다.
Raman 분광의 depolarization ratio로 측정 가능.

Polarization — 거시적 분극

스케일 전환
μ, α는 분자 하나의 성질. P (polarization)는 샘플 전체의 전기 쌍극자 모멘트 밀도다.

정의

$$P = \langle\mu\rangle \mathcal{N}$$
Polarization [Definition] — 𝒩: number density

외부 전기장에 따른 ⟨μ⟩ 변화

조건⟨μ_z⟩이유
전기장 없음 \(\langle\mu\rangle = 0\) 열운동으로 분자 방향이 완전 랜덤 → 평균 상쇄
약한 전기장 \(\langle\mu_z\rangle = \dfrac{\mu^2\mathcal{E}}{3kT}\) Boltzmann 통계 + Taylor 전개 (με ≪ kT 극한)
강한 전기장 \(\langle\mu_z\rangle = \mu\) 모든 분자 완전 정렬 → 포화(saturation)
약한 전기장 식 유도 배경
Boltzmann 분포에서 방향 θ를 가질 확률 ∝ \(e^{\mu\mathcal{E}\cos\theta / kT}\).
\(\mu\mathcal{E} \ll kT\)인 약한 장 한계에서 지수 함수를 Taylor 전개하면
\(\langle\cos\theta\rangle \approx \mu\mathcal{E}/3kT\)가 나온다.
→ μ²/kT: 쌍극자가 클수록, 온도가 낮을수록 정렬이 잘 됨.

외부 전기장의 주파수가 올라가면 분극에 기여하는 성분이 하나씩 꺼진다:

Orientation polarization

  • Permanent dipole이 전기장 방향으로 회전·정렬
  • 분자 전체가 돌아야 함 → 느림
  • 저주파(마이크로파)까지만 기여
  • 기여: μ²/3kT 항

Distortion polarization

  • 전기장이 전자 구름/핵 위치를 물리적으로 변형
  • Electronic: 매우 빠름 → 가시광까지 기여
  • Ionic/nuclear: 중간 속도 → IR까지 기여
  • 기여: α 항
결론
용액에서 P가 작아지는 이유: 주위 분자들의 충돌과 점성이 분자 회전(orientation)을 방해하기 때문이다. 고주파에서는 orientation 기여가 사라지고 distortion(전자)만 남는다.

Molar Polarization & Relative Permittivity

상대 유전율 εᵣ — 왜 중요한가

진공에서의 쿨롱 퍼텐셜:

$$V = \frac{Q_1 Q_2}{4\pi\varepsilon_0 r}$$

매질 속에서:

$$V = \frac{Q_1 Q_2}{4\pi\varepsilon r} = \frac{Q_1 Q_2}{4\pi\varepsilon_0\varepsilon_r r}$$
$$\varepsilon_r = \frac{\varepsilon}{\varepsilon_0}$$
Relative permittivity (유전상수) [Definition]
핵심
εᵣ의 물리적 의미: 매질 속 분자들이 분극되면서 외부 전기장을 부분적으로 상쇄 → 쿨롱 상호작용이 εᵣ배 약해진다.

물(H₂O): εᵣ = 78 @ 25°C
→ 이온 간 쿨롱 상호작용이 진공 대비 78분의 1로 약해짐
→ NaCl이 물에 쉽게 해리되는 물리적 이유!

Molar Polarization P_m

$$P_m = \frac{N_A}{3\varepsilon_0}\left(\alpha + \frac{\mu^2}{3kT}\right)$$
Molar polarization [Definition]
항물리적 의미온도 의존성
\(N_A\alpha / 3\varepsilon_0\) 전자 구름 변형(distortion) 기여 온도 무관
\(N_A\mu^2 / 9\varepsilon_0 kT\) Permanent dipole 정렬(orientation) 기여 ∝ 1/T

Debye 방정식 — εᵣ ↔ P_m 연결

$$\frac{\varepsilon_r - 1}{\varepsilon_r + 2} = \frac{\rho P_m}{M}$$
Debye equation
실험적 쓸모 — μ와 α를 동시에 뽑는 법
P_m 정의를 대입하면: $$P_m = \underbrace{\frac{N_A\alpha}{3\varepsilon_0}}_{\text{y절편}} + \underbrace{\frac{N_A\mu^2}{9\varepsilon_0 k}}_{\text{기울기}} \cdot \frac{1}{T}$$
전략: 온도를 여러 개 바꾸며 εᵣ 측정 → P_m 계산 → P_m vs 1/T 직선 그래프
→ 기울기에서 μ 추출, y절편에서 α 추출

Clausius-Mossotti 방정식 — 비극성 분자용

μ = 0이면 orientation 항이 사라진다:

$$\frac{\varepsilon_r - 1}{\varepsilon_r + 2} = \frac{\rho N_A \alpha}{3M\varepsilon_0}$$
Clausius-Mossotti equation (μ = 0인 경우)
결론 — 두 방정식 비교
방정식적용 대상구하는 것필요한 측정
Debye 극성 분자 μ + α 동시에 εᵣ를 여러 온도에서 측정
Clausius-Mossotti 비극성 분자 (μ=0) α만 εᵣ 한 번만 측정
핵심: "εᵣ을 재면 분자 내부 전기 성질을 알 수 있다"

출제 경향
유도형 40% / 원리·설명형 30% / 계산형 30%

🔵 유도형 (40%)

유도 같은 크기 μ₁ = μ₂ = μ인 두 쌍극자가 각도 θ를 이룰 때, 합성 쌍극자 μ_res = 2μcos(θ/2)임을 유도하라.
일반 벡터 합성: $$\mu_\text{res} = \left(\mu_1^2 + \mu_2^2 + 2\mu_1\mu_2\cos\theta\right)^{1/2}$$ μ₁ = μ₂ = μ 대입: $$= \mu\left(2 + 2\cos\theta\right)^{1/2} = \mu\left(2(1+\cos\theta)\right)^{1/2}$$ 반각 공식 \(1 + \cos\theta = 2\cos^2(\theta/2)\) 적용: $$= \mu\left(4\cos^2\tfrac{\theta}{2}\right)^{1/2} = 2\mu\cos\tfrac{\theta}{2}$$
유도 약한 전기장 하에서 극성 분자의 평균 쌍극자 모멘트가 ⟨μ_z⟩ = μ²ε/3kT가 됨을 설명하라.
방향 θ를 가질 Boltzmann 확률: $$w(\theta) \propto e^{\mu\mathcal{E}\cos\theta / kT}$$ 약한 장 \(\mu\mathcal{E} \ll kT\) 한계에서 Taylor 전개: $$e^x \approx 1 + x \qquad (x = \mu\mathcal{E}\cos\theta/kT \ll 1)$$ 구면 평균: $$\langle\cos\theta\rangle = \frac{\int_0^\pi \cos\theta \cdot (1 + \frac{\mu\mathcal{E}\cos\theta}{kT})\sin\theta\, d\theta}{\int_0^\pi (1 + \frac{\mu\mathcal{E}\cos\theta}{kT})\sin\theta\, d\theta}$$ \(\int_0^\pi \cos\theta\sin\theta\,d\theta = 0\), \(\int_0^\pi \cos^2\theta\sin\theta\,d\theta = 2/3\), \(\int_0^\pi \sin\theta\,d\theta = 2\) 이용: $$\langle\cos\theta\rangle = \frac{\mu\mathcal{E}/kT \cdot 2/3}{2} = \frac{\mu\mathcal{E}}{3kT}$$ 따라서 \(\langle\mu_z\rangle = \mu\langle\cos\theta\rangle = \dfrac{\mu^2\mathcal{E}}{3kT}\).
유도 Debye 방정식에서 P_m vs 1/T 그래프의 기울기와 절편으로부터 μ와 α를 어떻게 구하는지 유도하라.
Debye 방정식: $$\frac{\varepsilon_r-1}{\varepsilon_r+2} = \frac{\rho P_m}{M}$$ 따라서 측정으로부터: $$P_m = \frac{M}{\rho}\cdot\frac{\varepsilon_r-1}{\varepsilon_r+2}$$ Molar polarization 정의 대입: $$P_m = \frac{N_A}{3\varepsilon_0}\left(\alpha + \frac{\mu^2}{3kT}\right) = \frac{N_A\alpha}{3\varepsilon_0} + \frac{N_A\mu^2}{9\varepsilon_0 k}\cdot\frac{1}{T}$$ P_m vs 1/T 직선에서:
  • 기울기 \(= \dfrac{N_A\mu^2}{9\varepsilon_0 k}\) → \(\mu = \sqrt{\dfrac{9\varepsilon_0 k \times \text{slope}}{N_A}}\)
  • y절편 \(= \dfrac{N_A\alpha}{3\varepsilon_0}\) → \(\alpha = \dfrac{3\varepsilon_0 \times \text{intercept}}{N_A}\)

🟡 원리·설명형 (30%)

설명 CO₂는 이종핵 원자를 포함하지만 전기 쌍극자 모멘트가 0이다. 이유를 설명하라.
CO₂는 O=C=O 선형 구조다. C=O 결합의 쌍극자는 각각 C→O 방향이지만 두 결합이 정반대 방향을 향하므로 벡터 합이 완벽하게 상쇄된다.

핵심: 극성 분자의 조건은 "이종핵 결합이 있다"가 아니라 "결합 쌍극자들의 벡터 합이 0이 아니다"이다.
설명 HOMO-LUMO gap이 작은 분자일수록 분극능 α가 크고, 더 긴 파장의 빛을 흡수하는 이유를 설명하라.
α와 HOMO-LUMO gap:
2차 섭동이론에 의하면, 외부 전기장은 바닥 상태에 들뜬 상태 성격을 혼합시킨다. 혼합 정도는 에너지 분모(gap)에 반비례하므로: $$\alpha \propto \frac{1}{E_\text{LUMO} - E_\text{HOMO}}$$ gap이 작을수록 전자 구름이 더 쉽게 변형 → α 큼.

흡수 파장:
gap이 작다 = 전자 전이에 필요한 에너지가 작다. \(E=hc/\lambda\)에서 E가 작으면 λ가 크다. 따라서 α가 클수록 더 긴 파장을 흡수한다.
설명 고주파 전기장에서 물(H₂O)의 유효 분극이 줄어드는 이유를 orientation polarization과 distortion polarization을 구분하여 설명하라.
Orientation polarization: H₂O의 permanent dipole이 전기장 방향으로 회전·정렬되는 기여. 분자 전체가 회전해야 하므로 느리다. 마이크로파 이상의 주파수에서는 분자가 전기장 방향 변화를 따라가지 못해 이 기여가 사라진다.

Distortion polarization: 전기장이 전자 구름 및 핵 위치를 변형시키는 기여. 전자는 매우 빠르게 반응하여 가시광/UV 주파수까지 따라갈 수 있다. 핵(ionic) 진동은 IR 주파수까지 따라간다.

따라서 고주파에서는 orientation 기여가 꺼지고 전자적 distortion 기여만 남아 전체 P가 감소한다.
설명 물의 상대 유전율(εᵣ = 78)이 NaCl 해리에 미치는 영향을 설명하라.
진공에서 두 이온 간 쿨롱 에너지: $$V = \frac{Q_1 Q_2}{4\pi\varepsilon_0 r}$$ 물 속에서는: $$V_\text{water} = \frac{Q_1 Q_2}{4\pi\varepsilon_0\varepsilon_r r} = \frac{V}{78}$$ Na⁺와 Cl⁻ 사이의 인력이 진공 대비 78분의 1로 약해진다. 이 약해진 인력이 열운동(kT)에 의해 쉽게 극복되므로 NaCl이 물에서 자발적으로 해리된다.

🟢 계산형 (30%)

계산 ortho-dichlorobenzene(μ_obs = 2.25 D)과 meta-dichlorobenzene(μ_obs = 1.48 D)의 비율이 √3에 가까움을 보여라. 클로로벤젠의 μ₁ = 1.57 D를 이용하라.
공식 \(\mu_\text{res} = 2\mu_1\cos(\theta/2)\) 이용:

Ortho (θ = 60°): \(\mu_\text{calc} = 2\times1.57\times\cos30° = 3.14\times\frac{\sqrt{3}}{2} \approx 2.72\) D
Meta (θ = 120°): \(\mu_\text{calc} = 2\times1.57\times\cos60° = 3.14\times0.5 = 1.57\) D

계산값 비율: \(2.72/1.57 = \sqrt{3} \approx 1.73\)
실험값 비율: \(2.25/1.48 \approx 1.52\)

계산값과 실험값이 비슷하지만 완전히 일치하지 않는 이유: 벤젠 고리 자체의 전자 분포 및 Cl 원자의 인접 효과를 무시한 근사이기 때문이다.
계산 H₂O의 분극능 부피 α′ = 1.48×10⁻³⁰ m³일 때, 1.0×10⁵ V m⁻¹의 전기장에서 유도 쌍극자 모멘트 μ*를 μD 단위로 구하라.
\(\mu^* = \alpha\mathcal{E} = 4\pi\varepsilon_0\alpha'\mathcal{E}\) (\(\alpha = 4\pi\varepsilon_0\alpha'\)이므로) $$\mu^* = 4\pi\times(8.854\times10^{-12}\,\text{J}^{-1}\text{C}^2\text{m}^{-1})\times(1.48\times10^{-30}\,\text{m}^3)\times(1.0\times10^5\,\text{V\,m}^{-1})$$ 단위: J⁻¹C²m⁻¹ × m³ × Jm⁻¹C⁻¹ = C·m $$= 31.6\times10^{-35}\,\text{C·m} = 4.9\times10^{-6}\,\text{D} = 4.9\,\mu\text{D}$$ 영구 쌍극자(1.85 D)에 비해 극히 작다 → 일상적인 전기장에서 유도 쌍극자는 무시할 수 있다.
계산 아마이드 기에서 N(−0.36e, 132 pm, 0), C(+0.45e, 0, 0), O(+0.18e, 182 pm, −87 pm), O(−0.38e, −62 pm, 107 pm) 좌표(pm)가 주어질 때 μ_x와 μ_y를 C·m로 구하라.
\(\mu_x = \sum_J Q_J x_J\) 계산:
$$\mu_x = (-0.36e)(132) + (+0.45e)(0) + (+0.18e)(182) + (-0.38e)(-62)\quad [\text{단위: }e\cdot\text{pm}]$$ $$= -47.5 + 0 + 32.8 + 23.6 = 8.8\,e\cdot\text{pm}$$ $$= 8.8\times(1.602\times10^{-19}\,\text{C})\times(10^{-12}\,\text{m}) = 1.4\times10^{-30}\,\text{C·m}$$
\(\mu_y = \sum_J Q_J y_J\):
$$\mu_y = (-0.36e)(0) + (+0.45e)(0) + (+0.18e)(-87) + (-0.38e)(107)$$ $$= 0 + 0 - 15.7 - 40.7 = -56\,e\cdot\text{pm} = -19.0\times10^{-30}\,\text{C·m}$$
