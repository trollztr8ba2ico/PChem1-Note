↓

⚠️ 왜 ψ*ψ에 연산자 작용하면 안 되나?

d/dx(ψ*ψ) = (dψ*/dx)ψ + ψ*(dψ/dx)
곱의 미분 때문에 ψ*까지 미분돼버림. ψ*는 가중치 역할만 해야 하는데 물리량 추출에 간섭함.

Hermiticity 정의
실수 조건 → 수식화 → 정의 이름 붙이기

복소수 기본 규칙 (전체에서 사용)

복소수 연산 공리
(z*)* = z켤레의 켤레 = 자기자신
(z₁z₂)* = z₁*z₂*곱의 켤레 = 각각 켤레
(z₁+z₂)* = z₁*+z₂*합의 켤레 = 각각 켤레
(∫f dτ)* = ∫f* dτ켤레를 적분 안으로
z = z* ⟺ z는 실수허수부가 없다는 것과 동치
z·z* = |z|² ≥ 0항상 양수 실수

Hermiticity 도출 과정

목표
⟨Ω⟩ = ⟨Ω⟩* (측정값 실수 조건)
⟨Ω⟩ = ∫ψ* Ω̂ψ dτ Expectation value 정의 (A)
⟨Ω⟩* = (∫ψ* Ω̂ψ dτ)* 켤레 취하기
= ∫(ψ* Ω̂ψ)* dτ 켤레 → 적분 안으로
= ∫(ψ*)*(Ω̂ψ)* dτ (z₁z₂)* = z₁*z₂*
= ∫ψ(Ω̂ψ)* dτ (z*)* = z
⟨Ω⟩ = ⟨Ω⟩* 이 되려면
∫ψ*(Ω̂ψ) dτ = ∫ψ(Ω̂ψ)* dτ 이어야 함.
임의의 두 상태로 일반화 (단일 ψ면 조건이 너무 약함):
∫ψᵢ*Ω̂ψⱼ dτ = {∫ψⱼ*Ω̂ψᵢ dτ}*
→ 이게 Hermiticity 정의

왜 두 개의 다른 ψ가 나오나

단일 ψ로만 정의하면 조건이 너무 약해서 Hermitian이라 불려도 모든 상황에서 eigenvalue 실수를 보장하지 못함.

임의의 두 ψᵢ, ψⱼ에 대해 성립해야 진짜로 강력한 조건이 됨.

또한 i≠j인 경우가 나중에 Orthogonality 증명에서 바로 쓰임.

💡 Hermitian operator 정의
Hermiticity를 만족하는 Ω̂ → Hermitian operator
동치 표현: Ω̂† = Ω̂ (self-adjoint, † = 켤레+전치)

단, Ω̂* = Ω̂ 는 단순화. p̂ₓ처럼 복소 연산자는 켤레만으로 부족해서 † 필요.
x̂, p̂ₓ Hermitian 검증
실제로 Hermiticity 정의식을 만족하는지 확인

① x̂ Hermitian 증명

목표 ∫ψᵢ* xψⱼ dτ = {∫ψⱼ* xψᵢ dτ}* x̂ψ = xψ (정의)
오른쪽 {∫ψⱼ* xψᵢ dτ}*
= ∫(ψⱼ* xψᵢ)* dτ 켤레 → 적분 안으로
= ∫(ψⱼ*)* x* ψᵢ* dτ (z₁z₂)* = z₁*z₂*
= ∫ψⱼ xψᵢ* dτ (z*)* = z, x는 실수 → x* = x
= ∫ψᵢ* xψⱼ dτ ✅ 순서 바꾸기 (스칼라 곱)
핵심 이유
x는 위치 좌표 = 물리적으로 항상 실수 → x* = x. 미분 없으니 순서 바꾸기만으로 충분.

② p̂ₓ Hermitian 증명

목표 ∫ψᵢ*(ℏ/i)(dψⱼ/dx)dx = {∫ψⱼ*(ℏ/i)(dψᵢ/dx)dx}*
왼쪽 (ℏ/i)∫ψᵢ*(dψⱼ/dx)dx
부분적분 f=ψᵢ*, g'=dψⱼ/dx → fg|±∞ - ∫f'g ∫fg' = fg| - ∫f'g
= (ℏ/i)[ψᵢ*ψⱼ]₋∞^∞ - (ℏ/i)∫(dψᵢ*/dx)ψⱼ dx
= 0 - (ℏ/i)∫(dψᵢ*/dx)ψⱼ dx 경계항=0 (ψ→0 at ±∞)
= {∫ψⱼ*(ℏ/i)(dψᵢ/dx)dx}* ✅ 켤레 전개 후 확인

왜 경계항이 0인가?

정규화 조건: ∫|ψ|²dx = 1 이 되려면 ψ는 ±∞에서 반드시 0으로 수렴해야 함. 발산하면 적분이 1이 될 수 없음. 그러므로 [ψᵢ*ψⱼ]₋∞^∞ = 0×0 - 0×0 = 0.

핵심 이유
미분연산자라서 x̂처럼 단순히 순서 바꾸기로 안 됨. 부분적분으로 미분 대상을 ψⱼ에서 ψᵢ*로 옮겨야 Hermiticity 꼴이 완성됨.

연산자 형태x× (곱하기)(ℏ/i)(d/dx) (미분)
증명 핵심x* = x (실수)부분적분 + 경계항=0

Orthogonality
Hermitian의 두 번째 결과 — Eigenfunction들이 직교한다

함수의 내적이란?

벡터 내적: (a,b) = Σaᵢbᵢ → 각 성분끼리 곱해서 더한 것

함수 = 각 x값에서의 함숫값을 성분으로 가진 무한차원 벡터

함수 내적: (f,g) = ∫f*(x)g(x)dx → 연속이라 합이 적분이 됨

왜 f*를 곱하냐?
복소수 벡터에서 자기내적 양수 보장 조건: (a,a) ≥ 0
* 없으면: z·z = z² → 음수 가능 ❌
* 붙이면: z*·z = |z|² ≥ 0 ✅

켤레 대칭성 (a,b)* = (b,a)도 여기서 자동으로 따라옴 (공리가 아니라 결과).

Orthogonality 정의 & 증명

∫ψᵢ*ψⱼ dτ = 0   (i≠j)    ← 직교 정의
가정
Ω̂가 Hermitian, Ω̂ψᵢ = ωᵢψᵢ, Ω̂ψⱼ = ωⱼψⱼ, ωᵢ ≠ ωⱼ
식 1 ∫ψⱼ*Ω̂ψᵢ dτ = ωᵢ∫ψⱼ*ψᵢ dτ ψⱼ* 곱하고 적분
식 2 ∫ψᵢ*Ω̂ψⱼ dτ = ωⱼ∫ψᵢ*ψⱼ dτ ψᵢ* 곱하고 적분
Hermiticity 식2 왼쪽 = {식1}* Hermiticity 정의 적용
= ωⱼ∫ψᵢ*ψⱼ dτ = ωᵢ*{∫ψⱼ*ψᵢ dτ}* (z₁z₂)* = z₁*z₂*
= = ωᵢ∫ψᵢ*ψⱼ dτ ωᵢ 실수→ωᵢ*=ωᵢ, (∫f)* = ∫f*, (z*)* = z
정리 (ωᵢ−ωⱼ)∫ψᵢ*ψⱼ dτ = 0
결론 ωᵢ≠ωⱼ → ∫ψᵢ*ψⱼ dτ = 0 ✅ 직교 증명 완료

왜 직교가 중요한가?

직교 안 하면?

ψ = Σcₖψₖ에서 cₖ가 유일하게 결정 안 됨 → 확률 예측 불가 → 양자역학이 작동 안 함.

직교하면?

Basis 형성 → cₖ 유일하게 결정 → |cₖ|² = 확률 확정 → Superposition 가능.

💡 오비탈과 연결
수소원자 Ĥ도 Hermitian → 오비탈(eigenfunction)들이 서로 직교.
1s, 2s, 2p 모양이 다른 이유: 서로 내적했을 때 0이 나와야 하니까 각자 다른 모양이어야 함.
normalized + orthogonal = orthonormal → δₘₙ으로 표현

cₖ를 어떻게 구하나?

출발 ψ = Σₖ cₖψₖ
ψₘ* 곱하고 적분 ∫ψₘ*ψ dx = Σₖ cₖ∫ψₘ*ψₖ dx

결론 cₘ = ∫ψₘ*ψ dx 직교성이 없으면 불가능

cos kx 예시

ψ = 2Acoskx 에 p̂ₓ 작용 → −2A(ℏk/i)sinkx

결과가 sinkx → 원래 coskx와 다른 함수 → eigenvalue equation 불성립 → eigenfunction 아님

분해 2Acoskx = Ae^(ikx) + Ae^(-ikx) 오일러 공식
각각 작용 p̂ₓ(Ae^(ikx)) = +ℏk · Ae^(ikx) eigenvalue +ℏk
p̂ₓ(Ae^(-ikx)) = −ℏk · Ae^(-ikx) eigenvalue −ℏk
eigenfunctioneigenvaluecₖ|cₖ|² (확률)
e^(ikx)+ℏk (→ 방향)A|A|² = 1/2

💡 cₖ vs |cₖ|²

Commutator
불확정성 원리의 수학적 완성 — [x̂, p̂] = iℏ

왜 Commutator가 나오나?

두 Hermitian operator Ω̂₁, Ω̂₂가 공통 eigenfunction basis를 가진다 ⟺ Ω̂₁Ω̂₂ = Ω̂₂Ω̂₁

공통 basis가 있다 = 두 물리량을 동시에 확정값으로 측정 가능.

교환법칙이 성립하지 않으면? → 공통 basis 없음 → 동시 확정 불가 → 불확정성 원리.

[Ω̂₁, Ω̂₂] = Ω̂₁Ω̂₂ − Ω̂₂Ω̂₁    (Commutator 정의)
= 0 이면 "commute" → 동시 측정 가능

[x̂, p̂ₓ] 계산

x̂p̂ψ = x × (ℏ/i)(dψ/dx)
p̂x̂ψ = (ℏ/i)d(xψ)/dx = (ℏ/i)(ψ + x dψ/dx) 곱의 미분
① − ② = −(ℏ/i)ψ = iℏψ −1/i = i
결론 [x̂, p̂ₓ] = iℏ ≠ 0 commute 안 함 → 불확정성 필연
⚠️ 불확정성 원리의 수학적 완성
일반화된 불확정성 원리:
ΔΩ₁ · ΔΩ₂ ≥ ½|⟨[Ω̂₁, Ω̂₂]⟩|

x̂, p̂ₓ에 적용: Δp · Δq ≥ ½|⟨iℏ⟩| = ½ℏ ✅

HINT → ⟨Ω⟩ = ∫ψ*Ω̂ψ dτ 출발 → ⟨Ω⟩* 계산 (켤레→적분 안으로, 곱의 켤레, 켤레의 켤레 순서) → ⟨Ω⟩ = ⟨Ω⟩* 조건 → 일반화 → Hermiticity 정의. "실수 원함"은 동기, 정의 자체에 실수 없음 강조.
유도형 p̂ₓ Hermitian 증명
운동량 연산자 p̂ₓ = (ℏ/i)(d/dx)가 Hermitian임을 부분적분을 이용하여 증명하시오.
HINT → ∫ψᵢ*(ℏ/i)(dψⱼ/dx)dx → 부분적분 f=ψᵢ*, g'=dψⱼ/dx → 경계항=0 (ψ→0 at ±∞) → −(ℏ/i)∫(dψᵢ*/dx)ψⱼ dx → 켤레 형태로 정리 → Hermiticity 만족.
유도형 Eigenfunction 직교 증명
Hermitian operator의 서로 다른 eigenvalue에 해당하는 두 eigenfunction이 직교함을 증명하시오.
HINT → 두 eigenvalue eq 설정 → 각각 상대방 ψ* 곱하고 적분 → Hermiticity 적용 → 복소수 규칙으로 전개 (ωᵢ 실수이므로 ωᵢ* = ωᵢ) → (ωᵢ−ωⱼ)∫ψᵢ*ψⱼ = 0 → ωᵢ≠ωⱼ이면 적분=0.
유도형 [x̂, p̂ₓ] 계산
[x̂, p̂ₓ] = iℏ 임을 임의의 파동함수 ψ에 작용시켜 증명하고, 이로부터 Heisenberg 불확정성 원리가 도출되는 이유를 설명하시오.
HINT → x̂p̂ψ − p̂x̂ψ 각각 전개 → p̂x̂ψ에서 곱의 미분 주의 → 빼면 −(ℏ/i)ψ = iℏψ → [x̂,p̂]=iℏ≠0 → 공통 eigenfunction basis 없음 → 동시 확정 불가 → 일반화 불확정성 원리.

원리형 Hermiticity 정의의 논리적 필연성
Hermiticity가 "임의로 만든 정의"가 아니라 "측정값 실수 조건에서 강제된 조건"임을 설명하고, 이것이 순환논리가 아닌 이유를 동기·정의·정리의 구분을 이용해 설명하시오.
HINT → 동기: "실수 원함" / 정의: Hermiticity 수식 (실수라는 말 없음, 순수 수학 조건) / 정리: 그 정의로부터 eigenvalue 실수 증명. 정의 자체에 결론이 없으므로 순환 아님.
원리형 직교성이 양자역학에서 필수인 이유
Hermitian operator의 eigenfunction들이 직교하지 않으면 양자역학의 확률 해석이 불가능해지는 이유를 Superposition과 cₖ의 유일성을 이용해 설명하시오.
HINT → ψ = Σcₖψₖ에서 cₖ = ∫ψₘ*ψ dx 유도할 때 δₘₖ 필요 → 직교해야 m≠k 항이 사라져 cₖ 유일 결정 → |cₖ|² = 확률 확정. 직교 안 하면 cₖ 무한히 많음 → 확률 예측 불가.
원리형 Expectation value vs Eigenvalue
Expectation value와 Eigenvalue의 관계를 설명하고, 파동함수가 Superposition 상태일 때와 eigenfunction일 때 측정값이 어떻게 달라지는지 비교하시오.
HINT → Eigenvalue = Expectation value의 특수한 경우 (ψ가 eigenfunction이면 ω로 특수화) / Superposition: 매번 다른 값, 평균 = Σ|cₖ|²ωₖ / Eigenfunction: 항상 같은 값 ω / 확률은 확정, 결과는 비확정.

계산형 Superposition 분해 + 확률
ψ(x) = (1/√2)e^(ikx) + (i/√2)e^(-ikx) 일 때, (a) 각 운동량 eigenvalue, (b) 각 eigenvalue가 나올 확률, (c) 평균 운동량 ⟨p⟩를 구하시오.
HINT → c₁ = 1/√2, c₂ = i/√2 / |c₁|² = 1/2, |c₂|² = |i|²/2 = 1/2 / ⟨p⟩ = (1/2)(+ℏk) + (1/2)(−ℏk) = 0. 정규화 확인: |c₁|²+|c₂|² = 1.
계산형 Eigenfunction 판별 + Eigenvalue
다음 중 운동량 연산자 p̂ₓ의 eigenfunction인 것을 판별하고, eigenfunction이면 eigenvalue를 구하시오.
(a) ψ = Ae^(3ikx)    (b) ψ = Acos(kx)    (c) ψ = Ae^(-2kx)
HINT → p̂ₓψ = (ℏ/i)(dψ/dx) 적용 후 (상수)×ψ 꼴 나오면 eigenfunction / (a) 3ℏk ✅ / (b) sin 나옴 ❌ / (c) −2ℏki → eigenvalue 복소수 → Hermitian operator에서 불가 ❌.

(a) [x̂², p̂ₓ]    (b) [x̂, p̂ₓ²]
