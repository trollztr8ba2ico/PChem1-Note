7E — 조화진동자

Vibrational Motion

🌱도입 — 왜 조화진동자인가?

핵심 세팅

실제 분자에서 두 원자는 결합을 용수철처럼 진동한다. 퍼텐셜 에너지 \(V = \frac{1}{2}k_f x^2\) — 포물선 모양이 그 모델이다.

퍼텐셜 에너지 3가지 비교

중력전기력용수철 (★조화진동자)
힘\(F=\frac{GMm}{r^2}\)\(F=-\frac{q_1q_2}{4\pi\varepsilon_0 r^2}\)\(F=-k_f x\)
퍼텐셜\(V=-\frac{GMm}{r}\)\(V=\frac{q_1q_2}{4\pi\varepsilon_0 r}\)\(V=\frac{1}{2}k_f x^2\)
형태1/r 감소1/r 감소포물선 (x² 비례)
핵심 관계식

힘은 퍼텐셜의 음의 기울기: \(\displaystyle F(x) = -\frac{dV(x)}{dx}\)

PIB vs 조화진동자 — 결정적 차이

PIB (입자 상자)

퍼텐셜: 상자 안 \(V=0\), 벽 \(V=\infty\)

경계조건: \(\psi(0)=\psi(L)=0\) (딱 잘림)

슈뢰딩거: \(-\frac{\hbar^2}{2m}\psi'' = E\psi\)

조화진동자

퍼텐셜: \(V=\frac{1}{2}k_f x^2\) (포물선, 전 영역)

경계조건: \(\psi\to 0\) as \(x\to\pm\infty\)

슈뢰딩거: \(-\frac{\hbar^2}{2m}\psi'' + \frac{1}{2}k_f x^2\psi = E\psi\)

직관 비유

PIB: 감옥 방 안에 공 던지기 — 벽에서 튕김.

조화진동자: 그릇 안에서 공 굴리기 — 중앙으로 항상 복원력.

ω의 출처 — 고전역학

용수철에 달린 질량 m 입자의 고전 운동 방정식:

$$m\ddot{x} = -k_f x \quad\Rightarrow\quad x(t)=A\cos(\omega t+\phi),\quad \omega = \sqrt{\frac{k_f}{m}}$$

ω는 새로 정의한 게 아니라 고전 용수철 진동수. 퍼텐셜을 ω로 표현하면:

$$V = \frac{1}{2}k_f x^2 = \frac{1}{2}m\omega^2 x^2$$
조화진동자 슈뢰딩거 방정식 (ω 표현)
$$-\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2} + \frac{1}{2}m\omega^2 x^2\psi = E\psi$$

📐풀이 전개 — Power Series

전체 흐름
슈뢰딩거 방정식 세팅
↓ y = x/α 치환 → 무차원화
↓ y→∞ 점근 거동 분석 → e^(−y²/2) 추출
↓ ψ = u(y)e^(−y²/2) 대입 → Hermite 방정식
↓ u(y) = Σaₙyⁿ 급수 전개 → 점화식
↓ 발산 금지 → 급수 절단 → E 양자화

1단계: 치환 — α의 의미

$$y = \frac{x}{\alpha} = \sqrt{\frac{m\omega}{\hbar}}\,x, \qquad \alpha = \sqrt{\frac{\hbar}{m\omega}} = \left(\frac{\hbar^2}{mk_f}\right)^{1/4}$$
왜 이 스케일?

운동에너지 항 \(\frac{\hbar^2}{2m}\cdot\frac{1}{x^2}\)과 퍼텐셜 항 \(\frac{1}{2}k_f x^2\)이 같아지는 위치 스케일이 α.

\(\frac{\hbar^2}{m} \sim k_f x^4 \;\Rightarrow\; x \sim \left(\frac{\hbar^2}{mk_f}\right)^{1/4} = \alpha\)

무차원화하면 물리 상수가 사라져서 순수한 수학 문제가 됨 → Hermite 방정식과 연결.

Chain rule으로 미분 치환:

$$\frac{d}{dx} = \frac{1}{\alpha}\frac{d}{dy}, \qquad \frac{d^2}{dx^2} = \frac{1}{\alpha^2}\frac{d^2}{dy^2}$$

대입 후 ℏω/2 로 정규화하면:

$$\boxed{\frac{d^2\psi}{dy^2} + \left(\frac{2E}{\hbar\omega} - y^2\right)\psi = 0}$$

2단계: y→∞ 점근 거동

y가 매우 크면 \(\frac{2E}{\hbar\omega}\)는 무시 가능:

$$\frac{d^2\psi}{dy^2} \approx y^2\psi$$

\(\psi \sim e^{-y^2/2}\) 검증: \(\frac{d^2}{dy^2}e^{-y^2/2} = (y^2-1)e^{-y^2/2} \approx y^2 e^{-y^2/2}\;\checkmark\)

왜 e^(+y²/2)는 버리나?

\(e^{+y^2/2}\)는 y→∞에서 발산 → 파동함수는 무한대에서 0이어야 하므로 물리적으로 불가.

3단계: ψ = u(y)e^(−y²/2) 대입

$$\frac{d^2\psi}{dy^2} = \left(u'' - 2yu' + y^2u - u\right)e^{-y^2/2}$$

원래 방정식에 대입, \(e^{-y^2/2}\) 약분, \(y^2u\) 항 소거:

$$\boxed{u'' - 2yu' + \left(\frac{2E}{\hbar\omega}-1\right)u = 0} \quad\text{← Hermite 방정식}$$

4단계: Power Series 전개

$$u(y) = \sum_{n=0}^{\infty}a_n y^n, \quad f'' = \sum_{n=0}^{\infty}(n+2)(n+1)a_{n+2}y^n, \quad f' = \sum_{n=0}^{\infty}(n+1)a_{n+1}y^n$$

Hermite 방정식에 대입, \(y^n\) 계수 비교:

$$\boxed{a_{n+2} = \frac{2n+1 - \dfrac{2E}{\hbar\omega}}{(n+1)(n+2)}\,a_n}$$

5단계: 발산 금지 → 급수 절단

왜 급수를 끊어야 하나?

n→∞일 때 \(\frac{a_{n+2}}{a_n}\approx\frac{2}{n}\). 이는 \(e^{y^2} = \sum\frac{y^{2k}}{k!}\)의 계수비 \(\frac{b_{k+1}}{b_k}=\frac{1}{k}=\frac{2}{2k}=\frac{2}{n}\)와 동일.

급수가 무한히 계속되면 \(u(y)\sim e^{y^2}\) → \(\psi = ue^{-y^2/2}\sim e^{+y^2/2}\to\infty\) 발산!

n=v 에서 \(a_{v+2}=0\)이 되려면 분자=0:

$$2v+1-\frac{2E}{\hbar\omega}=0 \quad\Rightarrow\quad \boxed{E_v = \left(v+\frac{1}{2}\right)\hbar\omega}$$

⚡에너지 양자화

에너지 준위
$$E_v = \left(v+\frac{1}{2}\right)\hbar\omega, \quad v=0,1,2,\ldots, \quad \omega=\sqrt{\frac{k_f}{m}}$$

간격이 일정한 이유

직관

포물선 퍼텐셜은 올라갈수록 더 넓어지는 구조. 위로 갈수록 고전적 허용 영역이 넓어지는 효과와 퍼텐셜 기울기가 가파르지는 효과가 정확히 상쇄 → 간격 균등.

ZPE (영점에너지)

$$E_0 = \frac{1}{2}\hbar\omega \neq 0$$
왜 ZPE가 0이 될 수 없나? — 불확정성 원리

만약 E=0이라면: 운동에너지=0 → p=0 확정, 퍼텐셜=0 → x=0 확정.

\(\Delta x = 0,\;\Delta p = 0 \;\Rightarrow\; \Delta x\cdot\Delta p = 0 < \frac{\hbar}{2}\) ← 위반!

그러므로 불확정성 원리가 최솟값 \(\frac{1}{2}\hbar\omega\)를 강제한다.

실제 분자 — 간격이 일정하지 않은 이유

비조화성 (Anharmonicity)

조화진동자는 완벽한 포물선 가정. 실제 분자 퍼텐셜(Morse 퍼텐셜)은 높은 에너지에서 포물선보다 완만해짐.

완만한 벽 = 고전적 허용 영역 더 넓음 → 에너지 준위 간격 감소 → v 커질수록 간격 좁아짐 → 해리 에너지 D에서 수렴.

대응 원리

m↑, k_f↑ → ω↑ → ℏω↑이지만 거시적 물체에서는 에너지 간격이 총 에너지에 비해 무시할 만큼 작음 → 연속 에너지로 보임 → 고전역학과 일치.

〰️파동함수 & Hermite 함수

최종 파동함수
$$\psi_v(x) = N_v\,H_v(y)\,e^{-y^2/2}, \qquad y=\frac{x}{\alpha}=\sqrt{\frac{m\omega}{\hbar}}\,x$$

Hermite 다항식 — Rodrigues 공식

$$H_n(x) = (-1)^n e^{x^2}\frac{d^n}{dx^n}e^{-x^2}$$
v\(H_v(y)\)노드홀짝성\(\psi_v\) 특징
0\(1\)0개우함수순수 가우시안, 중앙 최대
1\(2y\)1개기함수x=0에서 노드, 양쪽 봉우리

Hermite Function

$$h_n(x) = e^{-x^2/2}H_n(x)$$

이것이 미분방정식 \(\frac{d^2f}{dx^2} - x^2f + \lambda f = 0\)의 고유함수로, 조화진동자 슈뢰딩거 방정식과 본질적으로 같은 형태.

가우시안의 역할 — "봉투"

Hermite vs Gaussian 경쟁

\(H_v(y)\): v가 커질수록 \(x^v\)항이 커져서 퍼지려 함.

\(e^{-y^2/2}\): x→±∞에서 항상 0으로 눌러버림.

결과: v↑하면 파동함수가 더 넓은 범위로 spread되지만 반드시 0으로 수렴.

선택 규칙 (Selection Rule)

$$\Delta v = \pm 1 \text{ (조화진동자)}, \quad \Delta v = \pm 1, \pm 2, \ldots \text{ (비조화: overtone)}$$
왜 Δv = ±1만 허용? — 홀짝성 논리

전이 확률 \(\propto \langle\psi_{v'}|x|\psi_v\rangle = \int\psi_{v'}\cdot x\cdot\psi_v\,dx\)

x는 기함수. 적분이 0이 아니려면 피적분함수가 우함수여야 함.

v=0→v=1: 우×기×기 = 우 → ≠0 허용

v=0→v=2: 우×기×우 = 기 → =0 금지 (완벽한 조화진동자에서)

실제 분자는 비조화성으로 v=0→v=2 (overtone) 약하게 허용.

v↑에 따른 확률밀도 변화 — 대응 원리

v확률 분포고전과의 관계
0중앙(x=0) 집중고전과 반대 (고전은 turning point)
커질수록가장자리 봉우리 강해짐점점 고전 분포에 수렴
v→∞turning point 근처 최대대응 원리 — 고전 분포와 일치

정규화 상수

$$N_v = \frac{1}{\sqrt{\alpha}}\left(\frac{1}{2^v\,v!\,\sqrt{\pi}}\right)^{1/2}$$

Hermite 직교정규화 공식 \(\int_{-\infty}^{\infty}H_v^2 e^{-y^2}dy = 2^v v!\sqrt{\pi}\) 이용.

🔗환산질량 & IR 분광법

왜 환산질량이 필요한가?

문제 설정

A-B 이원자 분자에서 두 원자가 모두 움직임 → 변수 2개 (x₁, x₂) → 복잡.

질량중심 X와 상대좌표 x = x₁−x₂ 로 바꾸면 에너지가 두 부분으로 분리됨.

유도: 두 입자 → 한 입자

새 좌표 정의:

$$m=m_1+m_2,\quad X=\frac{m_1}{m}x_1+\frac{m_2}{m}x_2,\quad x=x_1-x_2$$

역변환:

$$x_1 = X+\frac{m_2}{m}x,\quad x_2 = X-\frac{m_1}{m}x$$

운동에너지 계산 — 교차항 소거:

$$\frac{p_1^2}{2m_1}+\frac{p_2^2}{2m_2} = \frac{1}{2}m\left(\frac{dX}{dt}\right)^2 + \frac{1}{2}\mu\left(\frac{dx}{dt}\right)^2 = \frac{P^2}{2m}+\frac{p^2}{2\mu}$$
전체 에너지 분리
$$E = \underbrace{\frac{P^2}{2m}}_{\text{질량중심 자유운동}} + \underbrace{\frac{p^2}{2\mu}+V(x)}_{\text{상대진동 = 조화진동자, 질량 }\mu}$$

진동만 관심 있으면 P²/2m 항 무시 → 질량 μ인 단일 입자 조화진동자!

환산질량
$$\mu = \frac{m_A m_B}{m_A+m_B}$$

\(m_A\gg m_B\)이면 \(\mu\to m_B\) — 무거운 쪽이 고정된 것처럼 행동.

왜 퍼텐셜이 상대거리에만 의존하나? 공간 균일성 원리 — 분자가 우주 어디에 있든 결합 에너지는 같아야 함. 따라서 V = V(x₁−x₂) = V(x).

HCl 예제

$$\mu = \frac{(1.0078\,m_u)(34.9688\,m_u)}{(1.0078+34.9688)\,m_u} = 0.9796\,m_u \approx m_H$$
$$\omega = \left(\frac{k_f}{\mu}\right)^{1/2} = \left(\frac{516.3}{0.9796\times1.661\times10^{-27}}\right)^{1/2} = 5.634\times10^{14}\,\text{s}^{-1}$$
$$\Delta E = \hbar\omega = 5.941\times10^{-20}\,\text{J} \quad\Rightarrow\quad \nu=90\,\text{THz},\quad\lambda=3.3\,\mu\text{m}\;\text{(IR!)}$$

분자 에너지의 3층 구조

$$E_\text{tot} = E_\text{elec} + E_\text{vib} + E_\text{rot}$$
전이 종류영역파장/파수
① Electronic (전자 오비탈 변화)UV/Vis200~800 nm
② Vibrational (같은 오비탈, v 변화)IR2.5~25 μm / 400~4000 cm⁻¹
③ Rotational (회전 양자수만 변화)Microwave~1 mm
파수 (wavenumber) ṽ 왜 쓰나?

\(\tilde{\nu} = \frac{1}{\lambda} = \frac{\nu}{c}\) (단위: cm⁻¹)

\(E = hc\tilde{\nu}\) → 파수가 에너지에 비례. 파장은 에너지에 반비례라 불편.

O-H ~3500 cm⁻¹ (k_f 크고 μ 작음), C=O ~1700 cm⁻¹, C-C ~1000 cm⁻¹ — 전부 \(\omega=\sqrt{k_f/\mu}\) 하나로 설명.

📊Expectation Values

왜 필요한가?

양자역학에서 입자의 위치는 확정 불가 (Born 해석). 여러 번 측정의 평균값을 이론적으로 예측하는 게 expectation value.

$$\langle\Omega\rangle = \int_{-\infty}^{\infty}\psi_v^*\hat{\Omega}\psi_v\,dx$$

⟨x⟩ = 0 — 평균 변위

이유: 홀짝성

x는 기함수, \(|\psi_v|^2\)는 항상 우함수. 피적분함수 = 기함수 → \(\int_{-\infty}^{\infty}\text{기함수}\,dx = 0\)

물리적 의미: 진동하더라도 평균 위치는 항상 평형점 x=0.

⟨x²⟩ ≠ 0 — 평균 제곱 변위

$$\langle x^2\rangle = \left(v+\frac{1}{2}\right)\frac{\hbar}{(mk_f)^{1/2}}$$

v↑ → ⟨x²⟩↑ → 파동함수가 더 넓게 퍼짐과 일치. 불확정성 \(\Delta x = \sqrt{\langle x^2\rangle}\).

⟨V⟩ = ½Eᵥ — 평균 퍼텐셜에너지

$$\langle V\rangle = \frac{1}{2}k_f\langle x^2\rangle = \frac{1}{2}\left(v+\frac{1}{2}\right)\hbar\omega = \frac{1}{2}E_v$$

⟨Eₖ⟩ = ½Eᵥ — 평균 운동에너지

$$\langle E_k\rangle = E_v - \langle V\rangle = E_v - \frac{1}{2}E_v = \frac{1}{2}E_v$$
비리알 정리 (Virial Theorem)

\(\langle E_k\rangle = \langle V\rangle = \frac{1}{2}E_v\) — 운동에너지와 퍼텐셜에너지가 항상 반반.

V∝x² 일 때만 성립. ZPE에 적용: \(E_0 = \frac{1}{2}\hbar\omega = \underbrace{\frac{1}{4}\hbar\omega}_{\langle E_k\rangle} + \underbrace{\frac{1}{4}\hbar\omega}_{\langle V\rangle}\)

\(\langle p\rangle\)00

\(\langle E_k\rangle\)\(E_n\) (전부)\(\frac{1}{2}E_v\)

🚇터널링 & 고전적 금지 영역

Classical Turning Point

$$E_v = V(x_{tp}) = \frac{1}{2}k_f x_{tp}^2 \quad\Rightarrow\quad x_{tp} = \sqrt{\frac{2E_v}{k_f}} = \left[\frac{(2v+1)\hbar}{(mk_f)^{1/2}}\right]^{1/2}$$
고전 vs 양자

고전: |x| > x_tp 이면 입자가 존재 불가 (에너지 부족).

양자: ψ는 turning point 밖에서도 0이 아님 → 터널링!

v=0에서 터널링 확률 가장 높음. v→∞에서 고전 극한 수렴 (대응 원리).

예제: v=1, 고전 금지 영역에서의 확률

1
Turning point 찾기
$$E_1 = \frac{3}{2}\hbar\omega = \frac{1}{2}k_f x_{tp}^2 \quad\Rightarrow\quad |y_{tp}| = \frac{x_{tp}}{\alpha} = \sqrt{3}$$
2
확률 적분 세팅

금지 영역: y > √3 또는 y < −√3 (양쪽). |ψ₁|²는 우함수이므로:

$$P = 2\int_{\sqrt{3}}^{\infty}|\psi_1|^2\,dy = \frac{4}{\sqrt{\pi}}\int_{\sqrt{3}}^{\infty}y^2 e^{-y^2}\,dy$$
3
부분적분 — y²e^(−y²) 처리

u=y, dv=ye^(−y²)dy 로 놓으면:

시험 구성: 유도형 40% / 원리·설명형 30% / 계산형 30%

유도형 (40%)

Q1. 조화진동자의 에너지 양자화 Eᵥ = (v+½)ℏω 를 유도하라.
답 방향

① y = x/α 치환으로 슈뢰딩거 방정식 무차원화 → \(\psi'' + (\frac{2E}{\hbar\omega}-y^2)\psi=0\)

② y→∞ 점근 거동 → \(e^{-y^2/2}\) 추출, ψ = u(y)e^(−y²/2) 놓기

③ Hermite 방정식 \(u''-2yu'+(\frac{2E}{\hbar\omega}-1)u=0\) 도출

④ u = Σaₙyⁿ 전개 → 점화식 \(a_{n+2} = \frac{2n+1-2E/\hbar\omega}{(n+1)(n+2)}a_n\)

⑤ n→∞에서 비율 ~ 2/n = e^(y²) 계수비 → 발산 → 급수 절단 조건 → E = (v+½)ℏω

Q2. 왜 무차원 변수 y = x/α 로 치환하는가? α의 물리적 의미는?
답 방향

α는 운동에너지 항과 퍼텐셜 에너지 항이 같아지는 길이 스케일: \(\frac{\hbar^2}{m}\sim k_f x^4 \Rightarrow x\sim\alpha\)

치환 목적: 물리 상수 제거 → 순수 수학 문제(Hermite 방정식)로 변환.

\(\alpha = \sqrt{\hbar/m\omega} = (\hbar^2/mk_f)^{1/4}\)

Q3. ZPE(영점에너지)가 0이 될 수 없는 이유를 불확정성 원리로 설명하라.
답 방향

E=0이면 운동에너지=0 → p=0 확정, 퍼텐셜=0 → x=0 확정.

Δx=0, Δp=0 → ΔxΔp=0 < ℏ/2 → 불확정성 원리 위반.

따라서 최솟값 E₀ = ½ℏω가 필연적으로 존재.

Q4. 환산질량을 이용해 두 입자 진동 문제를 한 입자 문제로 변환하는 과정을 유도하라.
답 방향

① 질량중심 X, 상대좌표 x = x₁−x₂ 정의

② x₁, x₂를 X, x로 역표현

③ 운동량 p₁, p₂ 계산 → 운동에너지 전개 시 교차항 소거 확인

④ E = P²/2m + p²/2μ + V(x) 분리, μ = m₁m₂/(m₁+m₂)

⑤ 퍼텐셜이 상대거리에만 의존하는 이유: 공간 균일성 원리

원리·설명형 (30%)

Q5. 조화진동자에서 에너지 간격이 일정한 이유, 그리고 실제 분자에서는 일정하지 않은 이유.
답 방향

일정한 이유: 포물선 퍼텐셜에서 위로 갈수록 넓어지는 효과와 기울기 증가 효과가 정확히 상쇄. Eᵥ₊₁−Eᵥ = ℏω (v 무관).

실제 분자: Morse 퍼텐셜은 높은 E에서 포물선보다 완만 → 허용 영역 더 넓음 → 간격 감소 → 해리 에너지 수렴.

Q6. 선택 규칙 Δv = ±1의 이유를 홀짝성으로 설명하라.
답 방향

전이 확률 ∝ ⟨ψᵥ'|x|ψᵥ⟩. x는 기함수, |ψ|²는 우함수.

Δv=±1: 피적분함수 = 우함수 → ≠0 허용.

Δv=±2: 피적분함수 = 기함수 → =0 금지.

실제 비조화 분자에서는 overtone(Δv=±2,±3,...) 약하게 허용.

Q7. IR 분광법에서 결합 종류에 따라 흡수 파수가 다른 이유를 ω = √(k_f/μ)로 설명하라.
답 방향

ΔE = ℏω = ℏ√(k_f/μ) → 흡수 파수 ṽ = ΔE/hc.

O-H: k_f 크고(강한 결합) μ 작음(H가 가벼움) → ω↑ → ~3500 cm⁻¹

C=O: k_f 크고 μ 중간 → ~1700 cm⁻¹

C-C: k_f 작고(단일결합) μ 큼 → ω↓ → ~1000 cm⁻¹

계산형 (30%)

Q8. HCl (k_f=516.3 N/m, μ=0.9796 mᵤ)의 ω와 ΔE를 계산하고 해당 스펙트럼 영역을 밝혀라.
답 방향
$$\omega = \sqrt{\frac{516.3}{0.9796\times1.661\times10^{-27}}} = 5.634\times10^{14}\,\text{s}^{-1}$$
$$\Delta E = \hbar\omega = 1.055\times10^{-34}\times5.634\times10^{14} = 5.94\times10^{-20}\,\text{J}$$

λ = c/ν = 3.3 μm → IR 영역

Q9. v=1인 조화진동자가 고전적으로 금지된 영역에서 발견될 확률을 구하라. (erf(1.7)=0.9838)
답 방향

① E₁ = 3ℏω/2, turning point: |y_tp| = √3 ≈ 1.7

② P = 2∫_{√3}^{∞}|ψ₁|²dy = (4/√π)∫_{√3}^{∞}y²e^(−y²)dy

③ 부분적분: ∫_z^∞ y²e^(−y²)dy = z/2 · e^(−z²) + √π/4 · (1−erf(z))

④ z=1.7 대입: P ≈ (4/√π)(0.850×0.0556 + 0.4431×0.0162) ≈ 0.123 = 12.3%

Q10. ⟨V⟩ = ½Eᵥ, ⟨Eₖ⟩ = ½Eᵥ 임을 논리적으로 설명하고, ZPE에 적용하라.
답 방향

⟨V⟩ = ½k_f⟨x²⟩ = ½k_f(v+½)ℏ/(mk_f)^{1/2} = ½(v+½)ℏω = ½Eᵥ

⟨Eₖ⟩ = Eᵥ − ⟨V⟩ = Eᵥ − ½Eᵥ = ½Eᵥ (비리알 정리)

ZPE: E₀ = ½ℏω = ¼ℏω(⟨Eₖ⟩) + ¼ℏω(⟨V⟩) — 불확정성 원리의 정량적 결과.
