§0 변성암을 어떻게 분류하는가 ★★★

핵심 분류 기준

변성암은 ① 조직(texture)과 ② 조성(composition: 광물학적 또는 화학적) 두 축으로 분류한다.

  • 화성암이 지역명·고유명이 난립해 복잡한 것과 달리, 변성암 이름은 놀랄 만큼 단순하고 유연하다.
  • 강조하고 싶은 조직·광물 특징이 있으면 접두 수식어(prefix modifier)를 붙인다 (§4 참조).
분류 큰 그림

가장 먼저 갈리는 갈래는 엽리(foliation)의 유무다.

엽리상(foliated) → 입도·엽리 발달 정도로 세분 (slate → phyllite → schist → gneiss)
비엽리상(non-foliated) → granofels / hornfels

여기에 조성·원암이 특정되면 고유 암석명(marble, quartzite, amphibolite…)을 따로 붙인다.

전제 이 분류는 고변형(high-strain) 변성암을 제외한 일반 변성암에 적용된다. 단층암·압쇄암 등 고변형 암석은 별도로 다룬다(10-1 §2 단층대 참조).

§1 엽리상 변성암 (Foliated) ★★★

1-1. 면·선 구조 용어

기본 정의
  • Foliation(엽리) — 모든 면(planar)상 조직 요소.
  • Lineation(선구조) — 모든 선(linear)상 조직 요소.

두 용어는 성인(genetic) 의미가 없다 — 어떻게 만들어졌는지가 아니라 모양만 기술하는 용어.

용어정의입도 / 가시성대응 암석
Cleavage
(벽개·쪼개짐)		규칙적·근평행·조밀한 면을 따라 쪼개지는 성질. (넓게는 판상 규산염이 너무 세립이라 개별로 안 보이는 모든 엽리)육안으로 개별 광물 안 보임Slate
Schistosity
(편리)		변성으로 생긴 비등방 광물(또는 집합체)의 선호 방향 배열. 보통 면상이나 선상도 가능.육안으로 보임(조립)Schist
Gneissose
(편마구조)		편리가 빈약하거나, 변성으로 층으로 분리(segregation)된 구조. 보통 조립.조립, 명암 층상 분리Gneiss
암기 팁 입도가 커질수록 cleavage(안 보임) → schistosity(보임) → gneissose(층 분리)로 등급이 올라간다. 이게 그대로 slate→phyllite→schist→gneiss 누진과 대응.

1-2. 엽리상 암석 종류 (누진 순서)

핵심 누진 계열

Slate → Phyllite → Schist → Gneiss

변성도(입도)가 올라가면서 광물이 굵어지고 엽리 성격이 cleavage → schistosity → 층상 분리로 바뀐다. 원암은 흔히 이질암(pelite, 셰일).

용어 주의 엄밀히는 slate·phyllite도 모두 schist의 일종이다. 다만 관용상 schist는 "엽리 광물이 육안으로 쉽게 보이는" 것만 가리킨다.
Figure 22.1 a·b · 그림 읽기

Slate (점판암) vs Phyllite (천매암)

Slate(우측, 어두움): 치밀·극세립, 벽개 잘 발달. 갓 쪼갠 면이 무광(dull).

Phyllite(앞쪽, 밝음): 극세립 판상 규산염(sericite/phengite·chlorite)이 면에 비단 광택(satiny sheen)을 줌. 개별 광물은 거의 안 보임. 엽리+선구조 동반이 흔함.

식별 포인트 = 광택. 무광이면 slate, 은은한 비단광택이면 phyllite.

Figure 22.1c · 그림 읽기

Garnet–Muscovite Schist (편암)

Schist: 편리(schistosity)를 보이는 변성암. 엽리 광물이 육안으로 쉽게 식별될 만큼 조립.

사진: 은백색 백운모(muscovite)가 반짝이고, 어두운 큰 알갱이는 석류석 반정질변정(garnet porphyroblast). → 광물명을 접두로 붙여 "garnet muscovite schist"로 명명.

Figure 22.1d · 그림 읽기

Quartzo-feldspathic Gneiss (편마암)

Gneiss: 편마구조를 보이는 암석. 전형적으로 층상(banded) — 밝은 규장질(felsic) 층과 어두운 고철질 층이 교대.

선구조를 가질 수도 있으나, 반드시 규장질 농집층 vs 고철질 농집층의 분리(segregation)를 보여야 gneiss라 부른다. → 단순 배열이 아니라 "층 분리"가 핵심.

출제 예상 — §1
  1. Slate와 phyllite를 손표본에서 구분하는 결정적 차이는? 답 방향: 쪼갠 면의 광택 — slate는 무광(dull), phyllite는 세립 판상규산염에 의한 비단 광택(satiny sheen).
  2. cleavage·schistosity·gneissose structure를 입도(가시성)와 묶어 설명하시오. 답 방향: cleavage=세립·개별광물 안 보임 / schistosity=조립·육안 식별 / gneissose=조립+felsic·mafic 층 분리.
  3. "엄밀히는 slate도 schist다"라는 말의 의미는? 답 방향: schist의 광의 정의(편리를 가진 변성암)에는 slate·phyllite 포함. 관용상은 엽리광물이 육안으로 보이는 것만 schist.
  4. gneiss라 부르려면 반드시 보여야 하는 조직 특징은? 답 방향: felsic-rich / dark-mineral-rich 농집층의 분리(segregation), 즉 banding. 선구조만으로는 부족.

§2 비엽리상 변성암 (Non-foliated) ★★

핵심 정의
  • Granofels — 등방(isotropic), 즉 선호 방향이 없는 모든 변성암을 아우르는 포괄적 용어.
  • Hornfels(혼펠스) — granofels의 한 종류. 전형적으로 매우 세립·치밀하며 접촉변성대(contact aureole)에 산출. 단단하고 깨질 때 쪼개져 부서짐(splinter).
연결 hornfels는 10-1의 접촉변성 산물 — 셰일이 aureole에서 hornfels로, 석회암은 marble/skarn, 사암은 quartzite로 간다.
출제 예상 — §2
  1. granofels와 hornfels의 관계 및 hornfels의 산출 환경·물리적 성질을 쓰시오. 답 방향: hornfels ⊂ granofels(등방). 접촉변성대 산출, 세립·치밀·단단, splintery fracture.

출제 예상 — §3
  1. 고철질 원암에서 변성도·압력이 올라가며 만들어지는 암석을 순서대로 쓰고 환경을 연결하시오. 답 방향: greenschist(저변성) → amphibolite(중고변성) → blueschist(고압저온) → eclogite(초고압). cf. eclogite=omphacite+pyrope.
  2. marble과 skarn의 원암은 같으나 무엇이 다른가? 답 방향: 둘 다 탄산염 원암. skarn은 접촉변성에 더해 규산 metasomatism으로 calc-silicate(grossular 등) 생성. 동의어 tactite.
  3. granulite의 진단적 광물학적 특징은? 답 방향: OH-free 광물 우세, 백운모 부재, 사방휘석·사장석 흔함 → 고온(고변성도) 지시.
  4. migmatite가 변성-화성 경계에 놓이는 이유는? 답 방향: melanosome(편마질)+leucosome(규장질) 공존 = 부분용융 산물. subsolidus 한계를 넘는 점이대.
  5. greenschist와 greenstone의 차이는? 답 방향: 동일 광물조합(chlorite·actinolite·epidote·albite), 엽리 있으면 greenschist / 없으면 greenstone.

§4 추가 수식어 (Modifying Terms) ★★

4-1. 반정질변정 · 반점 · 안구상

조직 수식어
  • Porphyroblastic — 일부 변성광물이 나머지보다 훨씬 크게 성장. 그 개별 결정이 porphyroblast(반정질변정).
  • Spotted(반점상) — 저변성도 접촉변성에서 반정질변정이 타원형 "반점"으로 나타남. hornfels/phyllite 위에 접촉변성이 덧씌워지면 spotted hornfels / spotted phyllite.
  • Augen(안구상) — 편마암에서 전단으로 만들어진 눈 모양 큰 알갱이(흔히 장석). 독일어 "눈(auge)"의 복수. → augen gneiss.
Figure 23.14b · 그림 읽기

Spotted Phyllite (반점 천매암)

광역변성으로 만들어진 phyllite 위에 접촉변성이 덧씌워져(overprint) 타원형 반점(반정질변정)이 흩어져 있음.

읽는 법: 바탕 엽리 = 광역변성, 반점 = 후기 접촉변성 → 두 변성 사건의 중첩 지시. (스케일 바 1 cm)

Figure 23.18 · 그림 읽기

Augen Gneiss (안구상 편마암)

밝은 분홍~갈색의 눈 모양(렌즈상) 큰 장석 결정이 어두운 기질에 박혀 있음. 기존 대형 결정이 전단(shear)으로 변형되며 만들어짐.

읽는 법: augen의 존재 = 강한 전단 변형을 받은 편마암 지시.

4-2. 일반 수식어 · 원암 접두어

사용 원칙
  • 입도·색·화학(aluminous·calcareous·mafic·felsic 등) 수식어는 특징이 "이례적"일 때만 붙인다.
  • 당연한 조합은 군더더기: calcareous marble, mafic greenschist, fine-grained slate 등 (이미 정의상 그러함).
Ortho- / Para-
  • Ortho- = 화성암 기원, Para- = 퇴적암 기원.
  • 의심을 해소할 때만 사용. 예: 규장질 편마암은 불순 아르코스(퇴적) 또는 화강암류(화성) 둘 다에서 올 수 있음 → 광물·화학·야외 단서로 구분되면 orthogneiss / paragneiss / orthoamphibolite로 명명.
암기 팁 Ortho = 불(火, 화성), Para = 퇴적. "오르간(organ)은 교회=정통=화성"처럼 자기만의 연상으로 묶어두면 안 헷갈림.
출제 예상 — §4
  1. spotted phyllite가 지시하는 변성 이력을 설명하시오. 답 방향: 광역변성(엽리)+후기 접촉변성(반점=porphyroblast) 중첩.
  2. augen gneiss의 augen은 무엇이며 무엇을 지시하는가? 답 방향: 전단으로 변형된 눈 모양 대형 결정(흔히 장석) → 강한 전단변형 지시.
  3. orthogneiss와 paragneiss의 차이는? 언제 이 접두어를 쓰는가? 답 방향: ortho=화성 기원, para=퇴적 기원. 원암 구분이 가능한 단서가 있어 의심을 해소할 때만 사용.
  4. "fine-grained slate"가 부적절한 표현인 이유는? 답 방향: slate는 정의상 극세립 → 군더더기(redundant). 수식어는 이례적일 때만.

§5 한눈 정리 · 시험 포인트 ★★★

분류 흐름 한 줄 요약

엽리 있나? → 있으면 입도순 slate→phyllite→schist→gneiss / 없으면 granofels(접촉=hornfels)
조성·원암 특정되나? → marble·quartzite·greenschist·amphibolite·blueschist·eclogite·serpentinite·skarn·granulite·migmatite
강조할 조직 있나? → porphyroblastic·spotted·augen / 이례적이면 color·grain·chemical 수식어 / 원암 확실하면 ortho-·para-

시험 유형이 장에서 나올 형태
암석명 추론입도+엽리 기술 → slate/phyllite/schist/gneiss 중 지정
원암(protolith) 추론특정 암석명 → 원암 연결 (§3 표)
변성상·환경고철질 4총사(greenschist→amphibolite→blueschist→eclogite) 환경 배열
조직 해석spotted=중첩변성 / augen=전단 / banding=gneiss
