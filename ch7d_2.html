2D / 3D 상자 — 변수분리

핵심 한 줄: 2D/3D는 새 물리가 아니라 변수분리로 1D PIB를 방향 수만큼 복제한 것. ψ는 곱(×), E는 합(+).

1. 2D 세팅 — 운동에너지 항이 방향마다

1D에서 딱 하나 바뀐 것: 운동에너지 항이 x·y 두 개. 사각형 안(V=0)에 갇힌 입자.

$$-\frac{\hbar^2}{2m}\left(\frac{\partial^2\psi}{\partial x^2}+\frac{\partial^2\psi}{\partial y^2}\right)=E\psi$$
개념 ψ가 이제 두 변수의 함수 \(\psi(x,y)\) → 미분이 편미분(∂)으로 바뀌고, 방정식이 편미분방정식(PDE)이 됨. 1D처럼 sin/cos 바로 대입이 안 통해서 변수분리가 필요.

2. 변수분리 (이 파트의 심장)

① 가정: \(\psi(x,y)=X(x)\,Y(y)\) — x만의 함수 × y만의 함수의 곱.

② 편미분 정리 (x로 미분 시 Y는 상수 취급):

$$\frac{\partial^2\psi}{\partial x^2}=Y\frac{d^2X}{dx^2},\qquad \frac{\partial^2\psi}{\partial y^2}=X\frac{d^2Y}{dy^2}$$

편미분 ∂가 한쪽 함수만 남기고 상미분 d로 강등됨 → 이미 ODE로 가는 길.

③ 대입 후 XY로 나누기:

$$\frac{1}{X}\frac{d^2X}{dx^2}+\frac{1}{Y}\frac{d^2Y}{dy^2}=-\frac{2mE}{\hbar^2}$$
왜 분리되는가 (핵심 논리) 첫 항은 x만의 함수, 둘째 항은 y만의 함수, 그 합이 상수다. x를 바꿔도 합이 일정하려면 각 항이 각자 상수일 수밖에 없다. → PDE 하나가 ODE 두 개로 쪼개짐.
$$-\frac{\hbar^2}{2m}\frac{d^2X}{dx^2}=E_X X,\qquad -\frac{\hbar^2}{2m}\frac{d^2Y}{dy^2}=E_Y Y,\qquad E=E_X+E_Y$$

3. 2D 결과 (1D를 두 번 복사)

각 ODE는 1D PIB와 완전히 동일 → 답도 그대로 베껴서 곱하기:

$$\psi_{n_1,n_2}(x,y)=\frac{2}{\sqrt{L_1 L_2}}\sin\!\frac{n_1\pi x}{L_1}\sin\!\frac{n_2\pi y}{L_2}$$ $$E_{n_1,n_2}=\left(\frac{n_1^2}{L_1^2}+\frac{n_2^2}{L_2^2}\right)\frac{h^2}{8m}$$
노드 직관 (1,1) 내부 노드 없음 · (1,2) 가로 노드선 1개 · (2,1) 세로 노드선 1개 · (2,2) 4분면. 양자수 = 그 방향 노드 수 + 1이라는 1D 직관이 방향마다 유지.

4. 3D 확장 (패턴 한 번 더)

$$\psi_{n_1 n_2 n_3}=\left(\frac{8}{L_1 L_2 L_3}\right)^{1/2}\!\sin\!\frac{n_1\pi x}{L_1}\sin\!\frac{n_2\pi y}{L_2}\sin\!\frac{n_3\pi z}{L_3}$$ $$E_{n_1,n_2,n_3}=\left(\frac{n_1^2}{L_1^2}+\frac{n_2^2}{L_2^2}+\frac{n_3^2}{L_3^2}\right)\frac{h^2}{8m}$$

규격화 상수: 방향마다 (2/L)½가 곱해지는 패턴 → 외울 필요 없음.

슈뢰딩거 4단계 프레임워크 — 2D 버전

2D는 1단계에 변수분리 한 줄이 추가될 뿐, 2~4단계는 방향마다 1D를 반복.

1단계 — 일반해 (변수분리 선행)

(1-a) 가정 \(\psi=XY\) → (1-b) PDE를 ODE 2개로 분해 → (1-c) 각 ODE에 1D 일반해 대입:

$$X=C_1\sin k_1 x+D_1\cos k_1 x,\quad Y=C_2\sin k_2 y+D_2\cos k_2 y$$ $$k_1^2=\frac{2mE_X}{\hbar^2},\quad k_2^2=\frac{2mE_Y}{\hbar^2}$$

2단계 — 경계조건 → 양자화

각 방향에 1D 경계조건을 독립적으로 적용 (x벽과 y벽은 무관):

  • x: \(X(0)=0\Rightarrow D_1=0\); \(X(L_1)=0\Rightarrow k_1=n_1\pi/L_1\)
  • y: \(D_2=0\); \(k_2=n_2\pi/L_2\)
$$E_{n_1,n_2}=\left(\frac{n_1^2}{L_1^2}+\frac{n_2^2}{L_2^2}\right)\frac{h^2}{8m}$$
縮退의 씨앗 양자수가 독립적으로 2개(n₁, n₂) 등장. 독립이라 서로 다른 조합이 같은 에너지 합을 만들 수 있음 → 다음 탭 degeneracy.

3단계 — 정규화

ψ=XY라 2D 적분이 1D 적분 두 개의 곱으로 분해:

$$\iint|XY|^2\,dx\,dy=\Big(\!\int_0^{L_1}\!|X|^2dx\Big)\Big(\!\int_0^{L_2}\!|Y|^2dy\Big)=1$$ $$C_1=\Big(\tfrac{2}{L_1}\Big)^{1/2},\ C_2=\Big(\tfrac{2}{L_2}\Big)^{1/2}\Rightarrow \frac{2}{\sqrt{L_1 L_2}}$$

4단계 — 최종 ψ

$$\psi_{n_1,n_2}=\frac{2}{\sqrt{L_1 L_2}}\sin\!\frac{n_1\pi x}{L_1}\sin\!\frac{n_2\pi y}{L_2}\quad(\text{밖에선 }0)$$
단계1D2D 추가/변화
1sin/cos 바로변수분리 ψ=XY 먼저 → 방향별 sin/cos
2경계 → n, E방향별 독립 → n₁,n₂ / E는 합
3∫|ψ|²=1 → C적분이 곱으로 분해 → 상수도 곱
4ψ_nψ_{n₁,n₂} = X·Y (곱)

縮退 (Degeneracy)

서로 다른 파동함수가 같은 에너지를 갖는 것. 근원은 계의 대칭.

정사각형 (L₁=L₂=L)

$$E_{n_1,n_2}=(n_1^2+n_2^2)\frac{h^2}{8mL^2}$$

에너지가 제곱합 \(n_1^2+n_2^2\)에만 의존 → n₁, n₂를 맞바꿔도 같은 값.

상태ψE
(1,2)(2/L) sin(πx/L) sin(2πy/L)5h²/8mL²
(2,1)(2/L) sin(2πx/L) sin(πy/L)5h²/8mL²

ψ는 다른 함수(가로 노드 vs 세로 노드)인데 E는 같음 → 2-fold degenerate.

縮退의 근원 = 대칭 정사각형은 x↔y가 구별 불가(90° 회전 대칭) → (1,2)와 (2,1)은 라벨만 다른 셈 → 에너지 같음. 직사각형(L₁≠L₂)이면 대칭이 깨져 縮退도 풀림(lifted).

실제 사례 — 벤젠 π 분자궤도 (고리 모델)

벤젠 π 전자는 직선 상자가 아니라 고리 둘레를 도는 입자 → 양자수가 상자의 n이 아니라 고리의 \(m_l\). 에너지 \(E\propto m_l^2\)이라 +m_l과 −m_l이 같은 에너지.

양자 터널링 (Quantum Tunneling)

유한 높이 배리어를 E<V인 입자가 뚫고 나가는 현상. 고전적으로 금지된 영역을 침투.

3개 구역과 해의 형태

구역조건ψ형태
1 (x<0)V=0Ae^{ikx}+Be^{-ikx}진동
2 (0<x<L)E<VCe^{κx}+De^{-κx}지수 감쇠
3 (x>L)V=0A'e^{ikx}진동
$$\hbar k=(2mE)^{1/2},\qquad \hbar\kappa=\{2m(V-E)\}^{1/2}$$
핵심 ① — 왜 구역 2만 지수해? 슈뢰딩거 방정식을 \(\psi''=\dfrac{2m}{\hbar^2}(V-E)\psi\) 로 정리하면 (V−E)의 부호가 모든 걸 결정:
  • 구역 1,3 (E>V): \(\psi''=-k^2\psi\) → 진동 (sin/cos)
  • 구역 2 (E<V): \(\psi''=+\kappa^2\psi\) → 지수 (e^{±κx}), 출렁이지 못하고 죽어감
앞서 배운 curvature ↔ E 직관이 그대로 작동.
핵심 ② — κ의 의미 $$\kappa=\frac{\sqrt{2m(V-E)}}{\hbar}\quad[\text{m}^{-1}]$$ 배리어 안에서 ψ가 죽는 속도(감쇠율). 1/κ = 침투 깊이. m↑, (V−E)↑ 이면 κ↑ → 더 빨리 죽음 → 터널링 어려움. 모든 의존성의 뿌리.

각 항의 물리적 의미

항의미방향
A e^{ikx}입사파 (incident)+운동량 →
B e^{-ikx}반사파 (reflected)−운동량 ←
C e^{κx}+D e^{-κx}배리어 내부 (진폭 지수 변화)진동 아님
A' e^{ikx}투과파 (transmitted)+운동량 →

구역 3에 반사항(e^{-ikx})이 없는 이유: 배리어를 뚫은 뒤엔 막는 게 없어 되돌아올 이유가 없음.

투과 확률 (Transmission Probability) · Q3

T 정의와 경계조건 (핵심 ③)

$$T=\frac{|A'|^2}{|A|^2}\quad(\text{투과파 세기}/\text{입사파 세기})$$

A'와 A를 잇는 도구가 경계조건: 경계(x=0, x=L)에서 ① ψ 연속, ② dψ/dx 연속.

무한상자와의 핵심 대비
무한 상자 (V=∞)유한 배리어
벽에서 ψψ=0 강제ψ≠0, 침투
기울기 ψ'불연속 허용연속 필수
V가 유한 → ψ'' 유한 → ψ'가 갑자기 꺾일 수 없음. 경계 2개 × 조건 2개 = 식 4개로 비율을 풀면 T.

T 완전식

$$T=\left\{1+\frac{(e^{\kappa L}-e^{-\kappa L})^2}{16\varepsilon(1-\varepsilon)}\right\}^{-1},\quad \varepsilon=\frac{E}{V}$$
  • E ≪ V: T ≈ 0
  • E → V: T 증가
  • E > V여도 T < 1: 고전적으로 넘어가야 하는데 양자에선 반사도 일어남
  • E ≫ V: T ≈ 1 (고전 극한)
핵심 ④ — 두꺼운 배리어 근사 (κL≫1) \(e^{\kappa L}\gg e^{-\kappa L}\)이라 작은 항·앞의 1 무시: $$T\approx 16\varepsilon(1-\varepsilon)\,e^{-2\kappa L}$$ 이 \(e^{-2\kappa L}\)이 터널링의 상징. m·L·(V−E) 클수록 지수적으로 감소. 가벼운 입자(전자)라야 잘 뚫음 → STM, 핵융합, 효소 H 터널링.

Q3 — V=2.00 eV, L=100 pm, 전자 E=1.95 eV

값 정리: ε=1.95/2.00=0.975, V−E=0.05 eV=8.01×10⁻²¹ J, L=1.00×10⁻¹⁰ m

$$\kappa=\frac{\sqrt{2m(V-E)}}{\hbar}=\frac{\sqrt{2(9.109\times10^{-31})(8.01\times10^{-21})}}{1.0546\times10^{-34}}=1.15\times10^{9}\,\text{m}^{-1}$$ $$\kappa L=1.15\times10^{9}\times1.00\times10^{-10}=0.115$$
함정 — 근사식 쓰지 말 것 κL ≈ 0.115 로 1보다 한참 작음 → 근사식(κL≫1 조건) 부적합. 완전식으로 가야 함. (근사식 잘못 쓰면 0.31, 완전식은 0.88 — 완전히 어긋남.)

완전식 대입:

$$e^{\kappa L}-e^{-\kappa L}=1.121-0.892=0.230,\quad (\cdots)^2=0.0527$$ $$16\varepsilon(1-\varepsilon)=16(0.975)(0.025)=0.390$$ $$T=\left(1+\frac{0.0527}{0.390}\right)^{-1}=\frac{1}{1.135}\approx 0.88$$
답 \(T\approx 0.88\) (약 88%). ε이 1에 가깝고, 배리어 얇고, 가벼운 전자라 잘 뚫는 게 타당.
