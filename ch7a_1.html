01

파동함수와 핵심 파라미터

슬라이드 3–5
일반 파동함수
ψ(x, t) = A cos(kx − ωt + φ)

파동을 수학으로 완전히 기술하는 함수. x와 t를 넣으면 그 시점·위치의 파동 크기가 나온다.

각 파라미터 의미
기호이름의미
A진폭최대 변위. 세기 ∝ A²
k = 2π/λ파동수1m당 몇 라디안 진행 — 거리를 파동 주기 기준 라디안으로 환산
ω = 2πν각진동수1초당 몇 라디안 진행 — 시간을 파동 주기 기준 라디안으로 환산
φ위상출발 각도. 0~2π. 두 파동 비교 시 핵심
왜 kx − ωt?

−부호 → +x 방향 진행. 시간 증가할수록 같은 위상을 유지하려면 x도 커져야 하기 때문.

+부호면 −x 방향 진행.

핵심 관계식
c = λν
ν̃ = 1/λ (cm⁻¹)
v = ω/k = λν

03

형광 · 인광 · 백화현상

양자 현상
현상전이스핀속도특징
형광S₁ → S₀허용 (↑↓ → ↑↓)빠름 ns빛 끄면 즉시 꺼짐
인광T₁ → S₀금지 → perturbation으로 약간 허용느림 ms~s빛 끄고도 지속
백화——비가역크로모포어 산화 파괴 → 무색
S, T 표기법

S = Singlet (스핀 ↑↓ 반대)

T = Triplet (스핀 ↑↑ 같은 방향)

숫자 = 에너지 순서. 0=바닥, 1=첫 들뜬 상태

에너지: S₀ < T₁ < S₁

Intersystem Crossing

S₁에서 전자 스핀이 뒤집혀 T₁이 되는 과정.

T₁ 수명이 길어서 O₂와 반응 확률 높음 → 백화의 원인.

T₁→S₀ 금지 전이를 spin-orbit coupling (perturbation)이 약간 허용.

04

레이저 원리

응용
핵심 키워드: 광자 방출 → 유도방출 → 증폭
전자 들뜬 상태 → 광자 1개 방출 → 옆 들뜬 전자 유도 → 동일 광자 추가 방출 → 연쇄 증폭

방출 광자는 방향·파장·위상(phase)이 모두 동일 — 일반 빛과의 핵심 차이.

ΔE 클수록 → population inversion 유지 쉬움 → 증폭에 유리.

레이저 경로가 보이는 이유: 공기 중 먼지가 빛을 산란 → 일부가 눈 방향으로 도달. 진공에서는 경로 안 보임.

05

편광 · CD분광법 · Polarimetry

실험 연결
선형편광 (Linear)

E장이 한 방향으로만 진동.

응용: 선글라스(수평 반사광 차단 → 수직만 통과), 편광현미경(박편 복굴절 관찰)

원형편광 (Circular)

E장이 진행하면서 회전. Ex, Ey 진폭 같고 위상차 90°.

위상차 90° → 반시계(Left-handed)

위상차 270° → 시계(Right-handed)

선형 → 원형 편광 변환: λ/4 판

fast axis(x)와 slow axis(y)로 빛을 다른 속도로 통과 → 경로 차이 λ/4 → 위상차 90° 발생 → 원형편광 완성.

Polarimetry — 선광도 측정

선형편광을 카이랄 샘플에 통과 → 편광면 회전각 α 측정.

원리: 카이랄 분자가 좌/우 원형편광을 다른 속도로 통과시킴 → 위상차 → 편광면 회전 (원형 복굴절).

[α] = α / (c × l)

[α]: 비선광도 (분자 고유값). α: 측정 회전각. c: 농도(g/mL). l: 셀 길이(dm)

CD 분광법 — 흡수 차이 측정

좌/우 원형편광 흡수량 차이 ΔA = A_L − A_R 측정.

카이랄 분자: ΔA ≠ 0 / Racemic mixture: ΔA = 0 (상쇄)

Enantiomeric Excess (ee) 계산
ee = |[α]mixture / [α]pure| × 100%
R% = (100 + ee) / 2    S% = (100 − ee) / 2

예) [α]pure = +30, [α]mixture = +18 → ee = 60% → R = 80%, S = 20%

필기 수정사항

정정
수정 1
백화현상: "다른 색을 나타낸다" ❌ → 무색이 된다 ✓. 크로모포어 파괴 = 흡수 자체 불가 = 색 사라짐.
수정 2
레이저: "전자 방출" ❌ → 광자 방출 ✓. 전자가 에너지 준위 내려오면서 광자를 방출.
수정 3
가시광선 범위: 300nm ❌ → 420nm~700nm ✓. 300nm는 UV 영역.
수정 4
편광: "보색 흡수 안 한다" ❌ → 원래 흡수하던 파장을 흡수하지 않게 된다 ✓.
