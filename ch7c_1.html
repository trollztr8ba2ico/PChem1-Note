⚠️ 왜 양자역학만 이래?
양자역학에서는 입자가 여러 상태에 동시에 퍼져있어 (7B에서 본 파동함수처럼).
"위치가 뭐야?"라고 물어보면 숫자 하나를 확정할 수 없음.
그래서 등장한 해결책이 "숫자 대신, ψ에서 정보를 뽑아내는 행위 자체를 수학으로 표현하자" — 그게 연산자.
🔗 불확정성과의 연결 (예고)

→ 이게 나중에 Heisenberg 불확정성 원리로 수학적으로 완성됨.

Correspondence Principle — 고전 물리량을 연산자로 번역하는 규칙
Correspondence Principle

고전역학의 물리변수 → 양자역학 연산자로 대응. 논리로 유도하는 게 아니라 경험으로 결정되지만, 사실 de Broglie + 파동함수 구조에서 논리적으로 강제되는 것.

규칙 두 개로 전부 해결:

x 포함 → x× (곱하기 연산자)
p 포함 → (ℏ/i)(∂/∂x)

운동량 연산자 — 왜 (ℏ/i)(d/dx)인가?

① de Broglie: p = ℏk, 자유입자 파동함수 ψ = Ae^(ikx)
↓
② 요구사항: "p를 eigenvalue로 뱉는 연산자를 역으로 찾자"
↓
③ (ℏ/i)(d/dx)e^(ikx) = (ℏ/i)·ik·e^(ikx) = ℏk·ψ = p·ψ ✅
↓
④ 유일한 답: p̂ₓ = (ℏ/i)(d/dx)
💡 핵심
F=ma처럼 그냥 받아들이는 게 아니라, de Broglie + e^(ikx) 구조에서 논리적으로 강제된 것. 훨씬 필연성이 있음.

4가지 연산자 정리

물리량 연산자 형태 이유
위치 x x̂ = x× 곱하기 x가 포함, p 없음
운동량 pₓ p̂ₓ = (ℏ/i)(∂/∂x) 1차 미분 p = ℏk 역으로 찾음

Eigenfunction vs Superposition
뭔가 계산하기 전에 항상 먼저 물어봐야 할 가장 중요한 구분
🔑 핵심 질문
지금 ψ가 eigenfunction이야, superposition이야?
이 구분이 7C 전체를 관통하는 가장 중요한 판별 기준.
Ĥψ = Eψ 성립? → YES면 eigenfunction / NO면 superposition

✅ Eigenfunction

• Ĥψ = Eψ 성립
• E가 확정된 숫자로 나옴
• 슈뢰딩거 방정식을 "풀었다"는 것
• 곡률 → Ek 확정값 해석 가능
• 예: ψ = Ae^(ikx)

❌ Superposition

• Ĥψ = Eψ 불성립
• E 불확정
• 여러 eigenfunction이 섞인 상태
• Expectation value로 다뤄야 함
• 예: ψ = 2Acoskx = e^(ikx)+e^(-ikx)

Eigenvalue equation 구조

Eigenvalue equation의 의미

슈뢰딩거 방정식을 푼다 = Hamiltonian의 eigenvalue와 eigenfunction을 찾는다.

Ω̂ψ = ωψ
(operator)(eigenfunction) = (eigenvalue) × (eigenfunction)

ω = eigenvalue (측정 시 실제로 얻는 값) / ψ = eigenfunction (측정 가능 상태)

Superposition과 벡터공간 (선대 연결)

함수도 벡터처럼 취급

3D 벡터: v = a₁x̂ + a₂ŷ + a₃ẑ — basis로 임의의 벡터를 분해

파동함수도 마찬가지: Hermitian 연산자의 고유함수들 {ψ₁, ψ₂, ...}이 basis를 이룸

ψ = c₁ψ₁ + c₂ψ₂ + c₃ψ₃ + ···

• cos kx = e^(ikx) + e^(-ikx) 로 쪼갠 것 = 함수공간에서의 벡터 분해
• cₖ = 그 상태가 얼마나 섞여있나
• |cₖ|² = 측정 시 그 eigenvalue가 나올 확률

🎯 시험 포인트
주어진 ψ에 operator 작용 → 깔끔하게 (상수)×(같은ψ) 형태가 나오면 eigenfunction, 아니면 superposition.
판별 즉시 해석 방향이 달라짐.
Curvature of ψ
정확한 제목: "ψ가 eigenfunction일 때, 이계미분 연산자의 물리적 의미는?"
⚠️ 전제 조건 필수
"곡률 크다 = Ek 크다"는 해석은 ψ가 eigenfunction일 때만 성립.
superposition ψ에서 곡률을 봐도 Ek 확정값으로 연결할 수 없음.

d²/dx²의 물리적 의미

2차 미분 = 곡률

2차 미분이 크다 = 함수가 급격하게 구부러져 있다 = 곡률이 크다.

ψ 모양d²/dx²운동에너지 Ek
뾰족하고 좁음크다높음
완만하고 넓음작다낮음

k²이 곡률의 eigenvalue인 이유

① e^(ikx)는 미분하면 자기자신이 나오는 함수 → 자연스러운 eigenfunction (7B 복소수·오일러 공식 배운 이유)
↓
② d²/dx² (Ae^(ikx)) = (ik)²·Ae^(ikx) = −k²ψ → eigenvalue = −k² (실수 ✅)
↓
③ k = 2π/λ → k 크다 = λ 짧다 = 파동 빽빽 = 곡률 크다
↓
④ k²은 곡률에 관한 eigenvalue

Ek를 결정하는 모든 요소

Êₖ(Ae^(ikx)) = −(ℏ²/2m)(−k²)ψ = (ℏ²k²/2m)ψ

Ek = ℏ²k²/2m = (ℏk)²/2m = p²/2m
요소역할
곡률 (d²/dx²)k² 결정
p = ℏk곡률을 운동량으로 번역
질량 m같은 p여도 Ek 스케일 결정
💡 전체 연결 고리
곡률(d²/dx²) → k² 결정 → p = ℏk 결정 → Ek = p²/2m 결정 (m도 여기 들어옴)

Ek = 얼마나 가벼우냐(1/m) × 파동함수가 얼마나 구부러져 있냐(k²)
📌 부호 주의
d²/dx²의 eigenvalue는 −k² (마이너스). 앞에 −ℏ²/2m이 곱해지므로 (−)×(−) = (+)로 Ek는 항상 양수. ✅
불확정성 원리 — 직관 편
Wave packet과 간섭으로 이해하는 Δp↔Δq 트레이드오프
🔑 두 가지 뾰족함 구분 (핵심)
혼동하면 안 되는 두 맥락:

1. Curvature 맥락: 단일 eigenfunction ψ가 뾰족 → Ek값 자체가 크다
2. Wave packet 맥락: 여러 k를 섞어 만든 뾰족한 ψ → Ek 불확정성이 크다

A=B 특수해 (cos kx) — 불확정성의 첫 예시

7B에서 본 경계조건 케이스

ψ = 2Acoskx = Ae^(ikx) + Ae^(−ikx)

• k값 딱 두 개: +k, −k
• 운동량: ±ℏk 둘 중 하나 → 불확정 (중간 수준)
• 위치: cos²kx 형태로 넓게 퍼짐
→ "운동량이 불확정할 수 있구나"의 첫 예시

Wave packet — 불확정성의 극단적 증명

위치를 완전히 확정하면?
ψ = Σₖ e^(ikx) (k를 무한히 섞음)

왜 k를 많이 섞을수록 뾰족해지나?

보강간섭: x=0에서 k값이 뭐든 e^(ik·0) = 1 → 전부 더해져서 엄청 커짐
상쇄간섭: x≠0에서 k가 다양할수록 위상이 사방으로 퍼져 더하면 0에 수렴

k 범위x≠0 상쇄ψ 모양
±1불완전넓게 퍼짐
±3더 잘 됨좁아짐
±10거의 완전매우 뾰족
±∞완전delta function (한 점)
⚠️ 이 때 운동량은?
k를 많이 섞는다 = 운동량 종류(p = ℏk)를 많이 섞는다 = Δp가 엄청 커진다
위치 확정(Δq → 0)하려면 반드시 Δp → ∞ 를 감수해야 함.
💡 정리
A=B 특수해: 불확정성의 입문 예시 (k 2개, 운동량 ±ℏk 중 하나)
Wave packet: 불확정성의 극단적 증명 (k 무한개, 운동량 완전 불확정)

공통 원인: ψ.zip 구조 자체가 위치↔운동량 트레이드오프로 설계되어 있음
Δp · Δq ≥ ½ℏ
(Heisenberg 불확정성 원리 — Commutator 탭에서 수학적 완성)
Commutator
불확정성 원리의 수학적 완성 — [x̂, p̂] = iℏ
Commutator 정의
[Ω̂₁, Ω̂₂] = Ω̂₁Ω̂₂ − Ω̂₂Ω̂₁

두 연산자가 commute (교환 가능) ⟺ commutator = 0 ⟺ 공통 eigenfunction basis 존재 ⟺ 두 물리량 동시에 정확히 측정 가능

[x̂, p̂] 계산

① x̂p̂ψ = x × (ℏ/i)(dψ/dx)
↓
② p̂x̂ψ = (ℏ/i) d(xψ)/dx = (ℏ/i)(ψ + x dψ/dx)
↓
③ x̂p̂ψ − p̂x̂ψ = −(ℏ/i)ψ = iℏψ
↓
④ [x̂, p̂] = iℏ ≠ 0
⚠️ 결론
x̂와 p̂는 commute하지 않는다 → 공통 eigenfunction basis 없음 → 위치와 운동량을 동시에 정확히 측정 불가능.
이게 불확정성 원리의 수학적 필연성. 자연의 우연이 아니라 연산자 구조에서 나오는 것.
💡 7B → 7C 연결 완성
7B: "어? 위치랑 운동량이 동시에 확정이 안 되네?" (경계조건 예시로 직관)
7C: "[x̂, p̂] = iℏ ≠ 0 이기 때문에 수학적으로 필연이야" (완성)

일반화된 불확정성 원리

ΔΩ₁ · ΔΩ₂ ≥ ½|⟨[Ω̂₁, Ω̂₂]⟩|

x, p의 경우: Δp·Δq ≥ ½|⟨iℏ⟩| = ½ℏ ✅
Complementary Observables

Non-commuting operators를 가진 물리량들을 complementary observables라고 함.

대표 쌍: (위치 x, 운동량 p) / (에너지 E, 시간 t)

Commute하는 연산자 쌍은 동시에 확정값 측정 가능.

출제 예상 문제
유도형 40% / 원리·설명형 30% / 계산형 30%

유도형 40%

유도형 운동량 연산자 유도
운동량 연산자 p̂ₓ = (ℏ/i)(d/dx)가 되는 이유를 de Broglie 관계식과 자유입자 파동함수 ψ = Ae^(ikx)를 이용하여 유도하시오.
HINT → p = ℏk 출발 → "p를 eigenvalue로 뱉는 연산자" 역으로 찾기 → (ℏ/i)(d/dx)e^(ikx) = ℏk·e^(ikx) 검증. i² = −1 부호 주의.
유도형 운동에너지 연산자 유도
운동에너지 연산자 Êₖ = −(ℏ²/2m)(d²/dx²)를 운동량 연산자로부터 유도하고, eigenfunction Ae^(ikx)에 작용하여 Ek = p²/2m 임을 보이시오.
HINT → Ek = p²/2m → p̂²/2m 대입 → (ℏ/i)² = −ℏ² 계산 → e^(ikx)에 적용 → (−ℏ²/2m)(−k²) = ℏ²k²/2m. 부호 두 번 뒤집히는 것 주의.
유도형 Commutator 계산
[x̂, p̂ₓ] = iℏ 임을 임의의 파동함수 ψ에 작용시켜 증명하시오.
HINT → x̂p̂ψ − p̂x̂ψ 각각 전개 → p̂x̂ψ = (ℏ/i)d(xψ)/dx = (ℏ/i)(ψ + x dψ/dx) 곱의 미분 규칙 → 빼면 (ℏ/i)·(−1)·ψ = iℏψ.

원리·설명형 30%

원리형 Eigenfunction vs Superposition 구분
ψ = Ae^(ikx)와 ψ = 2Acoskx에 운동량 연산자를 작용시켰을 때의 결과를 비교하고, 각 파동함수에서 운동량의 물리적 의미가 어떻게 다른지 설명하시오.
HINT → e^(ikx): eigenvalue ℏk로 확정 / coskx: e^(ikx)+e^(-ikx) 분해 → ±ℏk 두 값으로 superposition → 운동량 불확정. Eigenfunction 판별이 핵심.
원리형 Curvature와 Ek의 관계
파동함수의 곡률(curvature)이 운동에너지와 어떻게 연결되는지 설명하고, 이 해석이 성립하기 위한 전제조건을 명시하시오.
HINT → d²/dx² = 곡률 / 전제조건: ψ가 eigenfunction이어야 함 / 곡률 → k² → p = ℏk → Ek = p²/2m. Superposition일 때는 이 해석 불가.
원리형 불확정성 원리의 물리적 기원
Heisenberg 불확정성 원리 Δp·Δq ≥ ½ℏ가 단순한 측정 오류가 아니라 자연의 근본적 성질임을 wave packet과 commutator를 각각 이용하여 설명하시오.
HINT → Wave packet: 위치 뾰족하게 만들수록 k(=p/ℏ) 종류 무한히 필요 → Δp 발산 / Commutator: [x̂,p̂] = iℏ ≠ 0 → 공통 eigenfunction 불가 → 수학적 필연.

계산형 30%

계산형 Eigenfunction 판별 계산
ψ(x) = Ae^(ikx) + Be^(−ikx)에서 (a) B=0, (b) A=0일 때 각각의 선형 운동량을 구하시오.
HINT → p̂ψ = (ℏ/i)(dψ/dx) 적용 → (a) B=0: p = +ℏk (eigenfunction, +x방향) / (b) A=0: p = −ℏk (eigenfunction, −x방향).
계산형 Ek 계산
파동함수 ψ = Asin(3πx/L)의 운동에너지 eigenvalue를 구하시오. (단, ψ는 eigenfunction임)
HINT → d²/dx²[sin(3πx/L)] = −(3π/L)²sin(3πx/L) → k = 3π/L → Ek = ℏ²k²/2m = 9π²ℏ²/2mL².
계산형 V̂ 연산자 적용
조화진동자의 Hamiltonian Ĥ = −(ℏ²/2m)(d²/dx²) + ½kfx²를 ψ = Ae^(−ax²)에 적용하여 eigenvalue equation이 성립하는지 확인하고, 성립한다면 E를 구하시오.
HINT → d/dx[e^(−ax²)] = −2ax·e^(−ax²) → d²/dx²[e^(−ax²)] = (4a²x²−2a)e^(−ax²) → Ĥψ에 대입 → x² 항이 상쇄되어야 eigenfunction → a = (mkf/ℏ²)^(1/2)/2 조건에서 성립.
