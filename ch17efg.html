Elementary Reactions

대부분의 반응은 더 단순한 elementary steps의 연속으로 일어나. Elementary reaction에서만 molecularity = order가 보장돼.

종류예Rate lawOrder
UnimolecularA → P\(v = k_r[A]\)1차
BimolecularA + B → P\(v = k_r[A][B]\)2차
⚠️ 주의
전체 반응의 rate law는 화학량론 계수에서 직접 쓸 수 없어. Elementary step에서만 가능.

Steady-State Approximation

🔬 물리적 직관
중간체 I가 생성되는 속도 ≈ 소모되는 속도. I가 생성되자마자 소비되어 쌓이지 못하는 상태. 깔때기에 물이 들어오는 속도 = 나가는 속도 → 수위(농도) 일정.

시스템: A →(k_a)→ I →(k_b)→ P

조건: k_a ≪ k_b

이 조건이 없으면 SSA가 성립 안 해. k_b가 작으면 I가 빠르게 쌓이니까.

유도

1
ODE 세우기 ODE
$$\frac{d[A]}{dt} = -k_a[A], \quad \frac{d[I]}{dt} = k_a[A] - k_b[I], \quad \frac{d[P]}{dt} = k_b[I]$$
2
SSA 적용: [I]를 [A]로 표현 SSA
$$\frac{d[I]}{dt} \approx 0 \implies k_a[A] = k_b[I] \implies [I] = \frac{k_a}{k_b}[A]$$
3
생성물 속도 Result
$$\frac{d[P]}{dt} = k_b[I] = k_b \cdot \frac{k_a}{k_b}[A] = k_a[A] = k_a[A]_0 e^{-k_a t}$$
4
[P] 적분 Integration
$$[P] = k_a[A]_0 \int_0^t e^{-k_a t'} dt' = (1 - e^{-k_a t})[A]_0$$
✅ 결론
SSA에서 [P]는 마치 A → P인 직접 1차 반응처럼 보여. 중간체 I의 존재가 숨겨진 거야. 이게 많은 복잡한 메커니즘이 겉으로는 단순한 rate law를 보이는 이유.
⚠️ SSA 성립 조건
k_b ≫ k_a일 때만 유효. k_b가 작으면 I가 쌓여서 d[I]/dt ≈ 0 가정이 깨짐. 정확한 해(consecutive reaction 공식)와 비교하면 k_b/k_a가 클수록 SSA가 더 정확.

Pre-equilibrium

🔬 아이디어
A + B ⇌ I (빠른 평형, k_a, k_a') 먼저 설립된 후 I → P (느린 단계, k_b). 조건: k_b ≪ k_a, k_a'. 중간체 [I]를 평형 상수로 표현 가능.

스킴: A + B ⇌ I → P

1
Pre-equilibrium 조건: [I]를 K로 표현 Pre-eq
$$K = \frac{[I]}{[A][B]} = \frac{k_a}{k_{a'}} \implies [I] = K[A][B]$$
2
전체 rate Result
$$v = k_b[I] = k_b K[A][B] = \frac{k_a k_b}{k_{a'}}[A][B]$$
✅ 결론
전체 rate law는 2차(\([A][B]\))처럼 보이지만, rate constant는 세 elementary constants의 조합. 실험으로 측정한 k_obs = k_a k_b / k_a'.

Kinetic vs Thermodynamic Control

🔬 상황
A + B → P₁ (k_{r,1}) 과 A + B → P₂ (k_{r,2}) 두 경로가 경쟁할 때, 어떤 생성물이 우세한가?

Kinetic Control (초기, 비가역적)

$$\frac{[P_2]}{[P_1]} = \frac{k_{r,2}}{k_{r,1}}$$
활성화 에너지가 낮은 경로 우세

반응 초기, 평형 도달 전. 더 빠른 경로(E_a 낮은 쪽)의 생성물이 우세. 반응이 비가역적이거나 시간이 짧을 때.

Thermodynamic Control (충분한 시간, 평형)

$$\frac{[P_2]}{[P_1]} = \frac{K_2}{K_1} = e^{-(\Delta G^\circ_{P_2} - \Delta G^\circ_{P_1})/RT}$$
더 안정한 생성물 우세

충분히 반응을 진행시키면 Gibbs 에너지가 낮은(더 안정한) 생성물이 우세.

⚠️ 핵심 포인트
두 컨트롤이 다른 생성물을 선호할 수 있어! 빠른 경로(kinetic product)가 열역학적으로 덜 안정할 수 있음. 온도↑ → 반응 가역성↑ → thermodynamic control로 이동. 유기화학에서 1,2- vs 1,4-addition이 대표적 예시.
Kinetic controlThermodynamic control
조건낮은 온도, 짧은 시간높은 온도, 긴 반응 시간
결정 인자활성화 에너지 (ΔG‡)생성물 안정성 (ΔG°)
가역성비가역적가역적 (평형 도달)

실험 관찰 패턴

📊 [S]₀ 변화에 따른 반응 속도
  • [S]₀ 낮을 때: v ∝ [S]₀ → 1차 거동
  • [S]₀ 높을 때: v → v_max (포화, 0차 거동)
  • [E]₀ ↑: v_max 비례 증가

이 hyperbolic 거동을 설명하는 메커니즘이 Michaelis-Menten.

Michaelis-Menten 메커니즘 유도

메커니즘

$$E + S \underset{k_a'}{\stackrel{k_a}{\rightleftharpoons}} ES \xrightarrow{k_b} P + E$$
1
관측 대상: v = k_b[ES] 목표

P가 만들어지는 속도. 문제는 [ES]를 모른다 → [E]₀, [S]₀로 표현 필요.

2
ES에 SSA 적용 SSA
$$\frac{d[ES]}{dt} = k_a[E][S] - k_a'[ES] - k_b[ES] \approx 0$$ $$[ES] = \frac{k_a[E][S]}{k_a' + k_b} = \frac{[E][S]}{K_M}, \quad K_M = \frac{k_a' + k_b}{k_a}$$
3
효소 보존: [E]₀ = [E] + [ES] → [E] = [E]₀ − [ES] 대입 Conservation
$$[ES] = \frac{([E]_0 - [ES])[S]}{K_M} \implies [ES](K_M + [S]) = [E]_0[S]$$ $$[ES] = \frac{[E]_0[S]}{K_M + [S]}$$
4
[S] ≈ [S]₀ 근사 (기질이 효소보다 훨씬 많음) 후 최종 식 MM 식
$$\boxed{v = \frac{k_b[E]_0}{1 + K_M/[S]_0} = \frac{v_{max}}{1 + K_M/[S]_0}}, \quad v_{max} = k_b[E]_0$$

K_M의 물리적 의미

📐 K_M 정의
v = v_max/2 가 되는 [S]₀ 값. K_M이 작을수록 낮은 기질 농도에서 효소가 포화됨 = 기질에 대한 affinity가 높다.

K_M = (k_a' + k_b)/k_a. 만약 k_b ≪ k_a'이면 K_M ≈ k_a'/k_a = 1/K_binding. 즉 결합 상수의 역수.

극한 분석

조건근사결과해석
[S]₀ ≪ K_M분모 ≈ K_M/[S]₀\(v \approx \frac{k_b}{K_M}[S]_0[E]_0\)1차 in [S]₀, 효소 항상 비어있음
[S]₀ ≫ K_M분모 ≈ 1\(v \approx k_b[E]_0 = v_{max}\)0차 in [S]₀, 효소 완전 포화

Lineweaver-Burk Plot & 촉매 효율

Lineweaver-Burk 직선화

MM 식의 역수를 취하면 직선 관계 도출:

$$\frac{1}{v} = \frac{1}{v_{max}} + \frac{K_M}{v_{max}} \cdot \frac{1}{[S]_0}$$
y = b + mx 형태
그래프 요소값
기울기 (slope)\(K_M / v_{max}\)
y절편\(1/v_{max}\)
x절편\(-1/K_M\)
왜 직선화가 필요한가?
Hyperbola fitting보다 선형 회귀가 훨씬 안정적. 실험 데이터에서 K_M, v_max를 간단하게 결정. 단점: 저농도([S]₀ 낮은) 데이터에서 오차가 증폭됨. 요즘은 비선형 fitting도 많이 씀.

Turnover frequency & 촉매 효율

$$k_{cat} = k_b = \frac{v_{max}}{[E]_0} \qquad \text{(Turnover frequency)}$$

단위 시간당 효소 하나의 활성부위가 처리하는 기질 수.

$$\eta = \frac{k_{cat}}{K_M} = \frac{k_a k_b}{k_a' + k_b} \qquad \text{(Catalytic efficiency)}$$
📐 효율 상한선 — Diffusion limit
k_b ≫ k_a' 극한에서: $$\eta \to \frac{k_a k_b}{k_b} = k_a$$ k_a는 E+S → ES 결합 속도상수 = 확산 속도에 해당. 효소가 완벽하면 기질이 확산으로 도달하는 속도만큼만 처리 가능. Catalase: η = 4.0 × 10⁸ dm³ mol⁻¹ s⁻¹ → "catalytic perfection".
✅ 왜 k_cat 대신 η를 쓰나?
k_cat이 높아도 K_M이 크면(affinity 낮으면) 실제로는 비효율적. η = k_cat/K_M은 속도와 affinity를 동시에 반영하는 진짜 효율 지표.

왜 ISC (S* → T*)는 forbidden인데 일어나나?

⚠️ Selection Rule
전자기 복사 전이에서 ΔS = 0만 허용. S* → T*는 ΔS = 1 → 금지.

그러나 ISC는 빛 흡수/방출이 아닌 비복사 과정. Spin-orbit coupling (SOC)이 스핀 상태를 혼합시켜 금지 전이를 부분적으로 허용. SOC ∝ Z⁴ → 무거운 원소(heavy atom)가 있으면 ISC가 빨라짐.

🔗 FRET 연결
Singlet-singlet energy transfer (S* + S → S + S*)가 Förster Resonance Energy Transfer(FRET)의 물리적 메커니즘. Donor S*의 여기 에너지가 dipole-dipole coupling으로 acceptor S에 전달. 이남기 교수님 smFRET 연구의 물화 기반.

Primary Quantum Yield & φ_{F,0} 유도

Quantum yield 정의

$$\phi = \frac{\text{number of events}}{\text{number of photons absorbed}} = \frac{v}{I_{abs}}$$
✅ 보존 법칙
들뜬 상태는 어딘가로 반드시 가야 함: $$\sum_i \phi_i = 1, \quad \phi_i = \frac{v_i}{\sum_j v_j}$$ 예: \(\phi_F + \phi_{IC} + \phi_P + \phi_r = 1\)

φ_{F,0} 유도 — excited singlet state의 decay

화학 반응 없이 흡수 + 형광 + IC + ISC만 있을 때:

1
각 과정의 속도 정의 Rate laws
$$v_{abs} = I_{abs}, \quad v_F = k_F[S^*], \quad v_{IC} = k_{IC}[S^*], \quad v_{ISC} = k_{ISC}[S^*]$$
2
S*에 SSA 적용 SSA
$$\frac{d[S^*]}{dt} = I_{abs} - (k_F + k_{ISC} + k_{IC})[S^*] \approx 0$$ $$\therefore I_{abs} = (k_F + k_{ISC} + k_{IC})[S^*]$$
3
형광 quantum yield Result
$$\phi_{F,0} = \frac{v_F}{I_{abs}} = \frac{k_F[S^*]}{(k_F + k_{ISC} + k_{IC})[S^*]} = \boxed{\frac{k_F}{k_F + k_{ISC} + k_{IC}}}$$
4
관찰 수명 τ₀ (빛 끈 후 지수 감쇠) Lifetime
$$[S^*](t) = [S^*]_0 e^{-t/\tau_0}, \quad \tau_0 = \frac{1}{k_F + k_{ISC} + k_{IC}}$$
5
φ_{F,0}과 τ₀의 핵심 관계 Key relation
$$\tau_0 = \frac{\phi_{F,0}}{k_F} \implies k_F = \frac{\phi_{F,0}}{\tau_0}$$
✅ 실험적 파워
τ₀는 펄스 레이저로 측정 (형광 지수감쇠). φ_{F,0}은 형광 강도 측정. 두 개를 측정하면 k_F를 결정 가능. 나아가 τ₀에서 k_F + k_ISC + k_IC의 합, φ_{F,0}에서 비율 → 개별 rate constant 분리 가능.

Quenching & Stern-Volmer 방정식

Quenching이란?

🔬 정의
외부 종 Q가 S*와 상호작용하여 들뜬 상태 수명을 단축. 에너지 또는 전자 전달, 충돌 비활성화 등의 메커니즘. $$S^* + Q \to S + Q, \quad v_Q = k_Q[Q][S^*]$$

세 가지 quenching 메커니즘

메커니즘식의미
Collisional deactivationS* + Q → S + Q충돌로 에너지 소산
Resonance energy transferS* + Q → S + Q*에너지 Q로 전달 (FRET!)
Electron transferS* + Q → S⁺/⁻ + Q⁻/⁺전자 주고받기

Stern-Volmer 방정식 유도

1
quenching 항 추가된 SSA SSA + Q
$$\frac{d[S^*]}{dt} = I_{abs} - (k_F + k_{ISC} + k_{IC} + k_Q[Q])[S^*] \approx 0$$
2
Q 존재 시 형광 quantum yield With Q
$$\phi_F = \frac{k_F}{k_F + k_{ISC} + k_{IC} + k_Q[Q]}$$
3
비율 φ_{F,0}/φ_F 계산 Ratio
$$\frac{\phi_{F,0}}{\phi_F} = \frac{k_F + k_{ISC} + k_{IC} + k_Q[Q]}{k_F + k_{ISC} + k_{IC}} = 1 + \frac{k_Q[Q]}{k_F + k_{ISC} + k_{IC}}$$
4
τ₀ = 1/(k_F + k_ISC + k_IC) 대입 Stern-Volmer
$$\boxed{\frac{\phi_{F,0}}{\phi_F} = 1 + \tau_0 k_Q[Q]}$$

유도

d[P]/dt = k_b[I] = k_a[A]₀e^{−k_a t}

성립 조건: k_b ≫ k_a. k_b가 작으면 I가 쌓여 d[I]/dt ≈ 0 가정이 깨짐.
Pre-equilibrium과 SSA의 차이를 메커니즘, 조건, [I] 결정 방식 측면에서 비교하라. 원리
원리

SSA: k_b ≫ k_a, I가 생성 즉시 소비. [I]를 동적 균형(d[I]/dt=0)으로 결정. 중간체는 낮고 일정.

Pre-eq: k_b ≪ k_a, k_a'. 앞 단계가 빠른 평형 → [I] = K[A][B] = (k_a/k_a')[A][B]. 중간체는 열역학적 평형값.
Kinetic control과 thermodynamic control이 서로 다른 생성물을 선호할 수 있는 이유를 설명하라. 원리
원리

Kinetic: 활성화 에너지가 낮은 경로 우세 → 전이 상태 안정성이 기준. Thermodynamic: 생성물의 ΔG°가 낮은 쪽 우세 → 생성물 안정성이 기준.

Hammond 포스툴레이트에 따르면 발열 반응의 전이 상태는 반응물과 비슷하므로, 빠른 경로의 생성물이 항상 안정한 것은 아님. 예: 1,2-addition(kinetic) vs 1,4-addition(thermodynamic).

17F / 20H — Enzymes

Michaelis-Menten 메커니즘에서 SSA를 적용하여 v = v_max / (1 + K_M/[S]₀)를 유도하라. 유도
유도

E+S ⇌ ES → P+E. v = k_b[ES]. d[ES]/dt = k_a[E][S] − k_a'[ES] − k_b[ES] ≈ 0 → [ES] = k_a[E][S]/(k_a'+k_b) = [E][S]/K_M
[E]₀ = [E]+[ES] 이용 → [ES] = [E]₀[S]/(K_M+[S]) ≈ [E]₀/(1+K_M/[S]₀)
v = k_b[ES] = k_b[E]₀/(1+K_M/[S]₀) = v_max/(1+K_M/[S]₀). ∎
K_M의 물리적 의미를 설명하고, K_M ≈ 1/K_binding 이 되는 조건을 서술하라. 원리
원리

K_M: v = v_max/2가 되는 [S]₀. 작을수록 낮은 [S]에서 포화 → affinity 높음.

K_M = (k_a'+k_b)/k_a. k_b ≪ k_a'이면 K_M ≈ k_a'/k_a = 1/K_eq = 1/K_binding. 즉 ES 해리가 생성물 형성보다 훨씬 빠를 때만 K_M이 결합 상수의 역수가 됨.
Lineweaver-Burk plot에서 K_M과 v_max를 어떻게 구하는가? 유도 과정 포함. 계산
계산

v = v_max/(1+K_M/[S]₀)의 역수: 1/v = 1/v_max + (K_M/v_max)(1/[S]₀)
1/v vs 1/[S]₀ 직선: 기울기 = K_M/v_max, y절편 = 1/v_max, x절편 = −1/K_M
→ y절편 역수 = v_max, 기울기/y절편 = K_M.
촉매 효율 η = k_cat/K_M의 상한이 k_a인 이유를 유도로 설명하라. 유도
유도

η = k_cat/K_M = k_b / [(k_a'+k_b)/k_a] = k_a k_b / (k_a'+k_b)
k_b → ∞ 극한: η → k_a k_b / k_b = k_a
k_a는 E+S → ES 결합 속도상수 = 확산 제한 속도. 효소가 아무리 빨라도 기질이 도달하는 속도 이상으로는 처리 불가.

20G — Photochemical Kinetics

Fluorescence와 phosphorescence의 수명이 다른 이유를 스핀 selection rule과 ISC 메커니즘 관점에서 설명하라. 원리
원리

Fluorescence: S*→S₀, ΔS=0 (spin-allowed) → 빠른 방출 (k_F 큼, ns 수명).

Phosphorescence: T*→S₀, ΔS=1 (spin-forbidden). Spin-orbit coupling이 부분적으로 허용하지만 k_P가 매우 작아 T* 수명이 ms~s. SOC ∝ Z⁴이므로 무거운 원소 포함 시 더 빠름(heavy atom effect).
φ_{F,0} = k_F / (k_F + k_ISC + k_IC)를 SSA로 유도하고, τ₀ = φ_{F,0}/k_F 관계를 도출하라. 유도
유도

d[S*]/dt = I_abs − (k_F+k_ISC+k_IC)[S*] ≈ 0 → I_abs = (k_F+k_ISC+k_IC)[S*]
φ_{F,0} = v_F/I_abs = k_F[S*] / (k_F+k_ISC+k_IC)[S*] = k_F/(k_F+k_ISC+k_IC)

τ₀ = 1/(k_F+k_ISC+k_IC) = φ_{F,0}/k_F. ∴ k_F = φ_{F,0}/τ₀.
Stern-Volmer 방정식을 유도하고, φ_{F,0}/φ_F vs [Q] 그래프에서 τ₀와 k_Q를 어떻게 구하는지 설명하라. 유도
유도

quenching 포함 SSA: I_abs = (k_F+k_ISC+k_IC+k_Q[Q])[S*]
φ_F = k_F/(k_F+k_ISC+k_IC+k_Q[Q])
φ_{F,0}/φ_F = (분모with Q)/(분모 without Q) = 1 + k_Q[Q]/(k_F+k_ISC+k_IC) = 1 + τ₀k_Q[Q]

φ_{F,0}/φ_F vs [Q] 직선: 기울기 = τ₀k_Q, y절편 = 1. τ₀를 별도 측정 → k_Q = 기울기/τ₀.
어떤 형광 분자의 φ_{F,0} = 0.60, τ₀ = 8.0 ns이다. k_F와 k_{nr} (= k_ISC + k_IC)를 구하라. 계산
계산

τ₀ = 1/(k_F + k_nr) = 8.0 × 10⁻⁹ s → k_F + k_nr = 1.25 × 10⁸ s⁻¹
φ_{F,0} = k_F/(k_F + k_nr) = 0.60 → k_F = 0.60 × 1.25 × 10⁸ = 7.5 × 10⁷ s⁻¹
k_nr = 1.25 × 10⁸ − 7.5 × 10⁷ = 5.0 × 10⁷ s⁻¹
