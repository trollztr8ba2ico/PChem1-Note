Chemical Kinetics 17C · 20D — Mechanisms & Arrhenius

이 챕터의 로드맵

핵심 질문
17B에서 "k_r은 농도와 무관하고 온도에 의존한다"고만 했어. 이 챕터에서는 (1) 복잡한 반응 형태들의 적분 rate law 유도, (2) k_r의 온도 의존성이 정확히 어떤 수식을 따르는지를 다룬다.

파트 구성

파트주제핵심 결과
17C-1 가역 1차 반응 → 평형 \([A](t) = \frac{k_r' + k_r e^{-(k_r+k_r')t}}{k_r+k_r'}[A]_0\)
17C-2 Relaxation methods \(x = x_0 e^{-t/\tau},\quad \tau = 1/(k_r+k_r')\)
17C-3 연속(consecutive) 반응 \([B](t) = \frac{k_a[A]_0}{k_b-k_a}(e^{-k_a t}-e^{-k_b t})\)
17C-4 병렬(parallel) 반응 \([B_i](t)=\frac{k_i}{k_T}[A]_0(1-e^{-k_T t})\)
17C-5 2차 반응 Type 2 부분분수 적분 → 로그형
20D-1 Arrhenius 방정식 \(k_r = Ae^{-E_a/RT}\)
20D-2 Eyring 방정식 (TST) \(k_r = \frac{k_BT}{h}e^{-\Delta G^\ddagger/RT}\)
20D-3 Catalyst \(E_a \downarrow\), \(K\) 불변
유도 흐름 공통 패턴
모든 복잡한 반응의 유도는 ① ODE 세우기 → ② 치환/변수 정리 → ③ 변수분리 or 적분인자 → ④ 적분 → ⑤ 초기조건 대입 순서를 따른다. 패턴을 외우면 새로운 반응형도 풀 수 있다.

가역 1차 반응 → 평형 접근

왜 이걸 보는가?
17B는 비가역 반응만 다뤘다. 현실의 반응은 대부분 가역이고, 평형 상수 K가 kinetics로부터 어떻게 나오는지를 보여준다.

설정

$$A \underset{k_r'}{\stackrel{k_r}{\rightleftharpoons}} B, \qquad [A]_0 \text{ 주어짐},\quad [B]_0 = 0$$ $$\text{질량보존: } [A]+[B]=[A]_0 \quad \text{(항상 성립)}$$

미분방정식 → 일반해 유도

1
ODE 세우기: A는 forward로 사라지고 reverse로 생긴다. $$\frac{d[A]}{dt} = -k_r[A] + k_r'[B]$$
2
\([B] = [A]_0 - [A]\) 대입 질량보존 $$\frac{d[A]}{dt} = -k_r[A] + k_r'([A]_0 - [A]) = -(k_r+k_r')[A] + k_r'[A]_0$$
3
형태: \(\dot{y} = -\alpha y + \beta\) → 일반해 = 정상해 + 제차해 1차 선형 ODE
정상해 (\(\dot{y}=0\)): $$[A]_{eq} = \frac{k_r'[A]_0}{k_r+k_r'}$$ 제차해: \(Ce^{-(k_r+k_r')t}\) $$[A](t) = [A]_{eq} + Ce^{-(k_r+k_r')t}$$
4
초기조건 \([A](0)=[A]_0\) 대입: \(C = [A]_0 - [A]_{eq} = \frac{k_r[A]_0}{k_r+k_r'}\) 초기조건
5
최종 결과:
$$\boxed{[A](t) = \frac{k_r' + k_r e^{-(k_r+k_r')t}}{k_r+k_r'}[A]_0}$$

평형 농도 & K

\(t\to\infty\)에서 지수항 소멸:

$$[A]_{eq} = \frac{k_r'}{k_r+k_r'}[A]_0 \qquad [B]_{eq} = \frac{k_r}{k_r+k_r'}[A]_0$$
$$K = \frac{[B]_{eq}}{[A]_{eq}} = \frac{k_r}{k_r'}$$
Another approach — 더 빠른 길
평형에서는 \(\frac{d[A]}{dt}=0\)이므로: $$-k_r[A]_{eq} + k_r'[B]_{eq} = 0 \implies k_r[A]_{eq} = k_r'[B]_{eq} \implies K = \frac{k_r}{k_r'}$$ 유도 없이 이 관계만 사용해도 되지만, 배경을 알아야 non-Arrhenius 거동도 이해할 수 있다.
일반화: 다단계 메커니즘
여러 단계를 거치는 반응에서 전체 K는 각 단계의 rate constant 비율의 곱: $$K = \frac{k_a}{k_a'} \times \frac{k_b}{k_b'} \times \cdots$$

Relaxation Methods

핵심 아이디어
이미 평형에 있는 계를 Temperature Jump (T-jump)로 살짝 흔든 뒤, 새로운 평형으로 돌아오는 과정을 관찰한다. "반응 시작 → 평형 도달"이 아니라 "평형 → perturbation → 새 평형" 방향.

핵심 유도 — 편차 변수 x 도입

1
T-jump 후 새 평형 농도에서의 편차를 \(x\)로 정의: 변수치환 $$[A] = [A]_{eq} + x, \qquad [B] = [B]_{eq} - x$$ (\([A]\)가 \(x\)만큼 초과이면 \([B]\)는 \(x\)만큼 부족)
2
미분방정식에 대입: $$\frac{d[A]}{dt} = \frac{dx}{dt} = -k_r([A]_{eq}+x) + k_r'([B]_{eq}-x)$$ $$= \underbrace{(-k_r[A]_{eq} + k_r'[B]_{eq})}_{=0 \text{ (평형조건)}} - (k_r+k_r')x$$
3
평형 조건 \(k_r[A]_{eq} = k_r'[B]_{eq}\) 덕분에 상수항 소거! 평형조건 $$\frac{dx}{dt} = -(k_r+k_r')x$$ → 순수한 지수 감쇠 ODE
4
즉시 풀 수 있음:
$$\boxed{x(t) = x_0\,e^{-(k_r+k_r')t} = x_0\,e^{-t/\tau}, \qquad \tau = \frac{1}{k_r+k_r'}}$$
왜 x 도입이 강력한가?
편차 변수를 쓰면 평형 조건이 상수항을 자동으로 소거해줘서 순수한 감쇠 방정식으로 변한다. 이 트릭은 임의의 선형화 가능한 반응계에 모두 적용된다.

실험적 파워

측정량주는 정보
\(\tau = 1/(k_r+k_r')\)\(k_r + k_r'\) 값
열역학 \(K = k_r/k_r'\)\(k_r/k_r'\) 비율
둘을 연립\(k_r\)과 \(k_r'\) 각각 분리 → 평형 측정만으론 불가!

1. First-order Consecutive Reactions

$$A \xrightarrow{k_a} B \xrightarrow{k_b} C, \qquad [A]_0,\;[B]_0=[C]_0=0$$

[A](t) — 가장 쉬운 부분

A는 그냥 비가역 1차:

$$[A](t) = [A]_0 e^{-k_a t}$$

[B](t) — 핵심 유도

1
B는 A에서 생기고(+) C로 사라진다(−): $$\frac{d[B]}{dt} = k_a[A] - k_b[B] = k_a[A]_0 e^{-k_a t} - k_b[B]$$
2
표준형으로 쓰면: 1차 선형 비제차 ODE $$\frac{d[B]}{dt} + k_b[B] = k_a[A]_0 e^{-k_a t}$$ 적분인자 \(e^{k_b t}\)를 곱한다: $$\frac{d}{dt}\!\left([B]e^{k_b t}\right) = k_a[A]_0\, e^{(k_b-k_a)t}$$
3
양변 적분: 적분인자법 $$[B]e^{k_b t} = \frac{k_a[A]_0}{k_b-k_a}e^{(k_b-k_a)t} + C$$
4
초기조건 \([B](0)=0\) 대입: \(C = -\frac{k_a[A]_0}{k_b-k_a}\) 초기조건
$$\boxed{[B](t) = \frac{k_a[A]_0}{k_b-k_a}\left(e^{-k_a t} - e^{-k_b t}\right)}$$
주의: k_a = k_b 경우
위 식은 \(k_a \neq k_b\)를 가정한다. \(k_a = k_b\)이면 분모가 0이 되어 별도 유도가 필요하다 (L'Hôpital 또는 처음부터 다시).

[C](t) — 질량보존 이용

$$[C](t) = [A]_0 - [A] - [B] = [A]_0\!\left[1 - \frac{k_b e^{-k_a t} - k_a e^{-k_b t}}{k_b - k_a}\right]$$

t_max — B의 최댓값 시점

1
\(\frac{d[B]}{dt}=0\) 조건: \(k_a e^{-k_a t} = k_b e^{-k_b t}\)
2
\(e^{(k_b-k_a)t} = k_b/k_a\) → 로그 취하면:
$$t_{max} = \frac{\ln(k_b/k_a)}{k_b - k_a}$$
실용적 의의
중간체 B(예: 합성 목표 물질)가 최대 농도에 달하는 시점 → 반응 정지 타이밍 최적화에 직접 사용된다.

2. First-order Parallel Reactions

$$A \xrightarrow{k_1} B_1, \quad A \xrightarrow{k_2} B_2, \quad A \xrightarrow{k_3} B_3, \quad \cdots$$

[A](t) 유도

1
사라지는 경로가 여러 개 → 모두 더한다: $$\frac{d[A]}{dt} = -(k_1+k_2+k_3+\cdots)[A] = -k_T[A], \quad k_T \equiv \sum_i k_i$$
2
변수분리 후 적분: 1차 반응
$$[A](t) = [A]_0 e^{-k_T t}, \qquad k_T = \sum_i k_i$$

각 생성물 [B_i](t)

1
\(B_i\)는 오직 경로 \(i\)에서만 생긴다: $$\frac{d[B_i]}{dt} = k_i[A] = k_i[A]_0 e^{-k_T t}$$
2
직접 적분 (\([B_i](0)=0\)):
$$\boxed{[B_i](t) = \frac{k_i}{k_T}[A]_0\!\left(1-e^{-k_T t}\right)}$$

Branching Ratio

\(t\to\infty\)에서 최종 수율:

$$\phi_i = \frac{[B_i](\infty)}{[A]_0} = \frac{k_i}{k_T} = \frac{k_i}{\sum_j k_j}$$
핵심
각 생성물의 최종 수율은 자기 경로의 rate constant가 전체 합에서 차지하는 비율이다. 빠른 경로일수록 많이 생성된다.

3. Second-order Reactions: A + B → P (Type 2)

$$v = k_r[A][B], \quad [A]_0 = a,\; [B]_0 = b \quad (a \neq b)$$

유도

1
A, B는 1:1로 반응 → 소비량 \(x\)로 통일: 변수치환 $$[A]=a-x,\quad [B]=b-x,\quad \frac{dx}{dt}=k_r(a-x)(b-x)$$
2
변수분리 후 부분분수 분해: 부분분수 $$\frac{1}{(a-x)(b-x)} = \frac{1}{b-a}\!\left(\frac{1}{a-x} - \frac{1}{b-x}\right)$$ 검증: \(\frac{A}{a-x}+\frac{B}{b-x}=\frac{1}{(a-x)(b-x)}\)에서 \(A=\frac{1}{b-a}\), \(B=-\frac{1}{b-a}\)
3
양변 적분: $$\frac{1}{b-a}\!\left[-\ln(a-x)+\ln(b-x)\right]_0^x = k_r t$$ $$\frac{1}{b-a}\!\left[\ln\frac{b-x}{a-x} - \ln\frac{b}{a}\right] = k_r t$$
4
\([A]=a-x\), \([B]=b-x\)로 되돌리면: 최종 정리
$$\boxed{\frac{1}{b-a}\ln\frac{[B]/[B]_0}{[A]/[A]_0} = k_r t}$$ $$\text{또는:}\quad \ln\frac{[B]/[B]_0}{[A]/[A]_0} = ([B]_0-[A]_0)\cdot k_r\cdot t$$

직선화

\(\ln\dfrac{[A]_0[B]}{[B]_0[A]}\)를 \(t\)에 대해 그리면 기울기 = \((b-a)k_r\) → \(k_r\) 결정 가능

주의: [A]₀ = [B]₀ 경우
\(a = b\)이면 부분분수가 성립하지 않는다. 이 경우는 Type 1 (\(v=k_r[A]^2\))과 동일한 형태로 풀린다: $$\frac{1}{[A]} - \frac{1}{[A]_0} = k_r t$$

반응 유형 비교 요약

반응 유형ODE 특징유도 핵심 기법결과 형태
가역 1차 상수항 있는 1차 선형 정상해 + 제차해 지수 감쇠 + 상수
Relaxation 편차 변수로 상수 소거 평형조건 이용 순수 지수 감쇠
Consecutive 비제차 1차 선형 적분인자 \(e^{k_b t}\) 두 지수의 차
Parallel 직접 분리 가능 경로별 적분 Branching ratio

20D: Arrhenius Equation

출발점
17B에서 \(k_r\)은 온도에 의존한다고만 했다. Arrhenius(1889)는 수많은 실험 데이터에서 \(\ln k_r\) vs \(1/T\)가 직선이 됨을 발견했다. 이 경험식이 Arrhenius 방정식이다.

Arrhenius 방정식

$$\ln k_r = \ln A - \frac{E_a}{RT} \qquad \Longleftrightarrow \qquad k_r = A\,e^{-E_a/RT}$$
파라미터이름의미
\(A\) Pre-exponential factor (frequency factor) 충돌 빈도 + 기하학적 배향 인자. \(k_BT/h\)와 연결됨 (Eyring)
\(E_a\) Activation energy (활성화 에너지) 반응이 일어나기 위해 넘어야 할 에너지 장벽 [J/mol]

두 온도에서 k_r 비교 — 실용 공식

1
\(T_1\)에서: \(\ln k_{r,1} = \ln A - \frac{E_a}{RT_1}\)
\(T_2\)에서: \(\ln k_{r,2} = \ln A - \frac{E_a}{RT_2}\)
2
두 식을 빼면 \(\ln A\) 소거: 대수 정리
$$\ln\frac{k_{r,2}}{k_{r,1}} = \frac{E_a}{R}\!\left(\frac{1}{T_1}-\frac{1}{T_2}\right) \tag{20D.2}$$
부호 확인 요령
\(T_2 > T_1\)이면 \(\frac{1}{T_1} > \frac{1}{T_2}\) → 우변 양수 → \(k_{r,2} > k_{r,1}\). 온도 올리면 반응 빨라진다는 직관과 일치. 시험에서 부호 실수 가장 많이 나오는 곳!

Physical Interpretation of E_a

상황k_r 거동예시
\(E_a\) 크다온도에 매우 민감 (그래프 가파름)대부분의 유기 반응
\(E_a = 0\)온도 무관 (\(k_r = A\))일부 라디칼 결합 반응
\(E_a < 0\)온도 올리면 느려짐효소 반응 고온 억제, radical recombination

Non-Arrhenius & E_a의 일반 정의

복잡한 반응(효소, 라디칼 연쇄, 저온 양자 터널링)에서는 \(\ln k_r\) vs \(1/T\) 그래프가 직선이 아닐 수 있다. 이 경우에도 임의의 온도에서 국소 활성화 에너지를 정의할 수 있다:

$$E_a = RT^2\frac{d\ln k_r}{dT} \quad \text{(정의)}$$
유도 배경
Arrhenius 식이 성립한다고 가정하고 \(T\)로 미분: $$\frac{d\ln k_r}{dT} = \frac{d}{dT}\!\left(\ln A - \frac{E_a}{RT}\right) = \frac{E_a}{RT^2}$$ 따라서 \(E_a = RT^2\frac{d\ln k_r}{dT}\). Arrhenius가 성립하면 이 \(E_a\)는 상수, non-Arrhenius이면 \(T\)의 함수.

Boltzmann 분포와 e^{-E_a/RT}의 기원

Arrhenius 식의 지수 인자가 왜 \(e^{-E_a/RT}\) 형태인지를 통계역학으로 정당화할 수 있다.

1
에너지 준위가 \(\varepsilon\) 간격으로 균등하게 분포할 때 Boltzmann 분포: $$\frac{N_i}{N} = (1-e^{-\varepsilon\beta})e^{-i\varepsilon\beta}, \qquad \beta = \frac{1}{k_BT}$$
2
최솟값 에너지 \(\varepsilon_{min} = i_{min}\varepsilon\) 이상을 가진 분자의 비율: $$\frac{1}{N}\sum_{i=i_{min}}^{\infty}N_i = 1 - \frac{1}{N}\sum_{i=0}^{i_{min}-1}N_i$$
3
유한 등비급수 공식으로 아래 합 계산: 등비급수 $$\sum_{i=0}^{i_{min}-1}e^{-i\varepsilon\beta} = \frac{1-e^{-i_{min}\varepsilon\beta}}{1-e^{-\varepsilon\beta}} = q(1-e^{-i_{min}\varepsilon\beta})$$ 따라서: $$\frac{1}{N}\sum_{i=i_{min}}^{\infty}N_i = 1 - (1-e^{-i_{min}\varepsilon\beta}) = e^{-\varepsilon_{min}/k_BT}$$
4
몰 단위 전환: \(k_BT \to RT\), \(\varepsilon_{min} \to E_a\) 몰 단위
$$\text{에너지 }E_a \text{ 이상 분자 비율} = e^{-E_a/RT}$$
의미
이게 Arrhenius 식 \(e^{-E_a/RT}\)의 물리적 기원이다. 실험적 귀납이었던 Arrhenius 식이 Boltzmann 통계역학으로부터 정당화되는 순간. 온도를 올리면 이 비율이 지수적으로 증가 → 반응 속도 급증.

Catalyst 효과

정의
Catalyst = 반응을 가속시키지만 알짜 화학 변화를 겪지 않는 물질
• Heterogeneous: 다른 상 (고체 Pt + 기체 반응)
• Homogeneous: 같은 상 (산 촉매 + 수용액 반응)
핵심: 촉매가 바꾸지 않는 것
촉매는 \(E_a\)만 낮추고 평형 상수 K는 바꾸지 않는다. 왜냐하면 \(\Delta G_{rxn}\)이 불변이고 \(K = e^{-\Delta G_{rxn}/RT}\)이기 때문이다. Forward와 reverse 반응 모두 같은 비율로 빨라진다.

Eyring Equation — Transition State Theory

Arrhenius vs Eyring
Arrhenius는 실험적 귀납이었다. Transition State Theory (TST)는 통계역학으로부터 이를 유도하고, 파라미터에 열역학적 의미를 부여한다.

TST의 핵심 가정

Quasi-equilibrium 가정
반응물과 전이 상태(activated complex) \([AB]^\ddagger\) 사이에 준평형이 성립하고, \([AB]^\ddagger\)가 생성물로 분해되는 속도로 전체 반응 속도가 결정된다. $$A + B \rightleftharpoons [AB]^\ddagger \xrightarrow{\nu} \text{Products}$$

Eyring 방정식

$$k_r = \frac{k_B T}{h}\,e^{-\Delta G^\ddagger/RT}$$
기호의미
\(k_B\)Boltzmann 상수 \(= 1.381\times10^{-23}\) J/K
\(h\)Planck 상수 \(= 6.626\times10^{-34}\) J·s
\(\Delta G^\ddagger\)활성화 Gibbs 에너지 (\(= \Delta H^\ddagger - T\Delta S^\ddagger\))

Eyring Plot 유도 — 필기 내용

1
양변을 \(T\)로 나누고 \(\ln\) 취한다: $$\ln\frac{k_r}{T} = \ln\frac{k_B}{h} - \frac{\Delta G^\ddagger}{RT}$$
2
\(\Delta G^\ddagger = \Delta H^\ddagger - T\Delta S^\ddagger\) 대입: 열역학 관계 $$= \ln\frac{k_B}{h} - \frac{\Delta H^\ddagger - T\Delta S^\ddagger}{RT}$$
3
전개:
$$\ln\frac{k_r}{T} = \underbrace{\ln\frac{k_B}{h} + \frac{\Delta S^\ddagger}{R}}_{y\text{절편}} - \underbrace{\frac{\Delta H^\ddagger}{R}}_{기울기}\cdot\frac{1}{T}$$
Eyring Plot에서 읽는 정보
\(\ln(k_r/T)\) vs \(1/T\) 그래프:
• 기울기 \(= -\Delta H^\ddagger/R\) → \(\Delta H^\ddagger\) 결정 (활성화 엔탈피)
• \(y\)절편 \(= \ln(k_B/h) + \Delta S^\ddagger/R\) → \(\Delta S^\ddagger\) 결정 (활성화 엔트로피)

Arrhenius vs Eyring 비교

ArrheniusEyring (TST)
기원 실험적 귀납 (1889) 통계역학 유도 (1935)
파라미터 \(A\), \(E_a\) \(\Delta H^\ddagger\), \(\Delta S^\ddagger\)
Plot \(\ln k_r\) vs \(1/T\) \(\ln(k_r/T)\) vs \(1/T\)
기울기 \(-E_a/R\) \(-\Delta H^\ddagger/R\)
연결 \(E_a \approx \Delta H^\ddagger + RT\), \quad A \propto e^{\Delta S^\ddagger/R}\)
A의 물리적 의미 (Eyring으로 해석)
\(A\)가 크다 = \(\Delta S^\ddagger\)가 크다 = 전이 상태가 반응물보다 엔트로피가 높다 (느슨한 TS)
\(A\)가 작다 = \(\Delta S^\ddagger\)가 작다 = 분자들이 매우 특정한 방향/배향으로 충돌해야 함

이것이 교재의 "steric factor"(충돌 방향 인자)와 연결되는 부분이다.

전체 연결 지도

$$\underbrace{k_r = Ae^{-E_a/RT}}_{\text{Arrhenius (실험)}} \longleftrightarrow \underbrace{k_r = \frac{k_BT}{h}e^{-\Delta G^\ddagger/RT}}_{\text{Eyring (TST)}} \longleftarrow \underbrace{e^{-E_a/RT} = \text{fraction with }E \geq E_a}_{\text{Boltzmann (통계역학)}}$$
최종 연결
Boltzmann 통계역학이 Arrhenius의 지수 형태를 설명하고, Eyring TST가 전지수 인자 A에 열역학적 의미(\(\Delta S^\ddagger\))를 부여한다. 세 프레임워크가 하나의 그림으로 통합된다.

유도형 (Derivation)

유도 가역 1차 반응 \(A \rightleftharpoons B\)에서 \([A](t)\)를 유도하고, \(t\to\infty\)에서 \(K = k_r/k_r'\)가 됨을 보여라. ▶
핵심 흐름: 질량보존 \([B]=[A]_0-[A]\) 대입 → \(\frac{d[A]}{dt}=-(k_r+k_r')[A]+k_r'[A]_0\) → 정상해 \([A]_{eq}=k_r'[A]_0/(k_r+k_r')\) + 제차해 \(Ce^{-(k_r+k_r')t}\) → 초기조건 → \(C=k_r[A]_0/(k_r+k_r')\). 평형: \(t\to\infty\)에서 \([B]_{eq}/[A]_{eq} = k_r/k_r' = K\).
유도 Relaxation method에서 편차 변수 \(x = [A]-[A]_{eq}\)를 도입하여 \(x = x_0 e^{-t/\tau}\), \(\tau = 1/(k_r+k_r')\)를 유도하라. ▶
핵심 트릭: \([A]=[A]_{eq}+x\), \([B]=[B]_{eq}-x\) 대입 → 미분방정식에서 평형 조건 \(k_r[A]_{eq}=k_r'[B]_{eq}\) 때문에 상수항이 정확히 소거 → \(\dot{x}=-(k_r+k_r')x\) → 표준 1차 감쇠.
유도 연속 반응 \(A\xrightarrow{k_a}B\xrightarrow{k_b}C\)에서 \([B](t)\)를 유도하고, \(t_{max}\)를 구하라. ▶
\([B]\) 유도: \(\frac{d[B]}{dt}+k_b[B]=k_a[A]_0e^{-k_at}\) → 적분인자 \(e^{k_bt}\) 양변 곱 → \(\frac{d}{dt}([B]e^{k_bt})=k_a[A]_0e^{(k_b-k_a)t}\) → 적분 + 초기조건 \([B](0)=0\) → \([B]=\frac{k_a[A]_0}{k_b-k_a}(e^{-k_at}-e^{-k_bt})\).
\(t_{max}\): \(\frac{d[B]}{dt}=0\) → \(k_ae^{-k_at}=k_be^{-k_bt}\) → \(t_{max}=\frac{\ln(k_b/k_a)}{k_b-k_a}\).
유도 Eyring 방정식 \(k_r=(k_BT/h)e^{-\Delta G^\ddagger/RT}\)에서 \(\ln(k_r/T)\) vs \(1/T\) plot의 기울기와 절편을 유도하고, Arrhenius 파라미터와의 관계를 설명하라. ▶
양변 \(T\)로 나눠 \(\ln\) → \(\ln(k_r/T)=\ln(k_B/h)+\Delta S^\ddagger/R - (\Delta H^\ddagger/R)(1/T)\). 기울기 \(=-\Delta H^\ddagger/R\), 절편 \(=\ln(k_B/h)+\Delta S^\ddagger/R\). Arrhenius 연결: \(E_a\approx\Delta H^\ddagger+RT\), \(A=(k_BT/h)e^{\Delta S^\ddagger/R}\).

계산형 (Calculation)

계산 어떤 반응의 \(k_r(300\,\text{K})=2.0\times10^{-3}\,\text{s}^{-1}\)이고 \(E_a=75\,\text{kJ/mol}\)이다. \(k_r(330\,\text{K})\)를 구하라. ▶
20D.2 식 적용: $$\ln\frac{k_2}{k_1} = \frac{E_a}{R}\!\left(\frac{1}{T_1}-\frac{1}{T_2}\right) = \frac{75000}{8.314}\!\left(\frac{1}{300}-\frac{1}{330}\right)$$ $$= 9018 \times 3.03\times10^{-4} = 2.73$$ $$k_2 = 2.0\times10^{-3} \times e^{2.73} = 2.0\times10^{-3}\times15.3 \approx 3.1\times10^{-2}\,\text{s}^{-1}$$
계산 병렬 반응 \(A\xrightarrow{k_1}B_1\), \(A\xrightarrow{k_2}B_2\)에서 \(k_1=0.3\,\text{s}^{-1}\), \(k_2=0.7\,\text{s}^{-1}\). \(t=2\,\text{s}\)에서 \([B_1]/[A]_0\)를 구하고, 최종 branching ratio \(\phi_1\)을 계산하라. ▶
\(k_T = 0.3+0.7=1.0\,\text{s}^{-1}\)
\([B_1](t)=\frac{k_1}{k_T}[A]_0(1-e^{-k_Tt})=0.3[A]_0(1-e^{-2.0})=0.3[A]_0\times0.865=0.260[A]_0\)
최종 branching ratio: \(\phi_1=k_1/k_T=0.3/1.0=0.30\) (30%)
계산 가역 반응 \(A\rightleftharpoons B\)에서 \(k_r=0.4\,\text{s}^{-1}\), \(k_r'=0.1\,\text{s}^{-1}\). (a) relaxation time \(\tau\)를 구하고, (b) 평형 상수 K를 구하라. ▶
(a) \(\tau=1/(k_r+k_r')=1/(0.4+0.1)=2.0\,\text{s}\)
(b) \(K=k_r/k_r'=0.4/0.1=4\)

원리·설명형 (Conceptual)

설명 촉매가 반응 속도를 높이지만 평형 상수 K는 변화시키지 않는 이유를 열역학적으로 설명하라. ▶
촉매는 새로운 반응 경로를 제공하여 \(E_a\)를 낮추지만 반응물과 생성물의 에너지 준위 자체는 바꾸지 않는다. 따라서 \(\Delta G_{rxn}\)이 불변이고, \(K=e^{-\Delta G_{rxn}/RT}\)이므로 K도 불변이다. Forward와 reverse 반응의 \(E_a\)가 모두 같은 양만큼 낮아지기 때문에 두 속도 상수가 같은 비율로 증가하고 그 비율인 K는 그대로다.
설명 활성화 에너지가 음수(\(E_a < 0\))인 반응이 물리적으로 가능한지, 가능하다면 어떤 메커니즘에서 나타나는지 설명하라. ▶
가능하다. Eyring 관점에서 \(E_a < 0\)는 \(\Delta H^\ddagger < 0\)에 해당하는데, 이는 전이 상태가 반응물보다 엔탈피가 낮은 상황이다. 메커니즘적으로는: ① 라디칼 결합 반응처럼 장벽이 없는 exothermic 반응, ② 효소 반응에서 온도 증가 시 활성 자리 구조가 변해 기질 결합이 약해지는 경우, ③ 복잡한 다단계 반응에서 역반응이 온도에 더 강하게 반응하는 경우. 복합 rate law \(k_{eff}=k_a/(k_b+k_c)\)에서 나타날 수 있다.
설명 Relaxation method에서 \(\tau\) 하나를 측정하는 것만으로 가역 반응의 \(k_r\)과 \(k_r'\) 각각을 결정할 수 있는 이유를 설명하라. ▶
\(\tau\)로부터 \(k_r+k_r'\)을 얻고, 열역학적으로 측정한 \(K=k_r/k_r'\)로부터 비율을 얻는다. 두 식을 연립하면: \(k_r=(K/(K+1))\cdot(1/\tau)\), \(k_r'=(1/(K+1))\cdot(1/\tau)\). 즉 평형 측정(\(K\))과 kinetics 측정(\(\tau\))의 조합이 개별 rate constant를 결정하는 데 필요하다. 평형 측정만으로는 비율만 알 수 있고 절댓값은 알 수 없다.
설명 Arrhenius 식의 \(e^{-E_a/RT}\) 인자가 Boltzmann 통계역학으로부터 어떻게 나오는지 논하라. ▶
균등 간격 \(\varepsilon\) 에너지 준위에서 Boltzmann 분포를 이용해 에너지 \(\varepsilon_{min}\) 이상을 가진 분자의 비율을 계산한다. 유한 등비급수 공식으로 정리하면 \(\sum_{i=i_{min}}^{\infty}N_i/N = e^{-\varepsilon_{min}/k_BT}\). 몰 단위로 전환하면 \(e^{-E_a/RT}\). 즉 이 인자는 "반응 장벽을 넘기에 충분한 에너지를 가진 분자의 비율"이며, 온도 증가 시 이 비율이 지수적으로 증가해 반응이 빨라진다.
