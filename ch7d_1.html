PIB를 왜 하는가?

핵심 목적
슈뢰딩거 방정식을 처음으로 처음부터 끝까지 푸는 예제. 파동함수가 주어지는 게 아니라, 경계조건에서 파동함수가 탄생하는 과정을 처음 보는 것.

왜 하필 PIB인가?

현실적인 이유: 포텐셜 에너지 $V$를 가장 단순하게 설정한 게 PIB다. 복잡한 $V$ (수소원자, 조화진동자)로 가기 전에, 가장 쉬운 케이스에서 양자역학 논리 구조 전체를 훈련하는 것.

상자 안 (0 ≤ x ≤ L)

$V = 0$
방정식이 단순해짐 → 풀 수 있음

상자 밖 (x < 0, x > L)

$V = \infty$
파동함수 = 0으로 강제됨

PIB에서 배우는 것

개념의미
경계조건이 양자화를 만든다에너지가 불연속인 이유
$n$이 클수록 에너지가 크다운동량↑ = 에너지↑ (curvature 논리)
바닥상태 에너지 $\neq 0$불확정성 원리의 직접적 결과
파동함수 모양 → 확률밀도위치 정보 추출법 훈련
이 채팅에서 나온 핵심 직관
입자를 파동으로 기술한다는 게 핵심. 파동을 상자에 가두면 → 보강간섭 조건을 만족하는 파동만 살아남고 → 그 조건이 $n$을 만들어 에너지를 양자화시킨다. 기타 줄의 배음 구조와 완전히 같다.

Free Motion in 1D — 대조군

슬라이드 1의 역할
"경계조건이 없으면 어떻게 되냐"를 먼저 보여주는 대조군. 경계조건 없음 → $k$ 자유 → 에너지 연속, 양자화 없음.

슈뢰딩거 방정식 ($V=0$)

$$-\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2} = E\psi$$
Free Motion in 1D

일반해

$$\psi_k = Ae^{ikx} + Be^{-ikx}, \qquad E_k = \frac{k^2\hbar^2}{2m}$$

경계조건이 없으므로 모든 $k$ 값이 허용 → 에너지가 연속적.

B = 0 은 경계조건이 아니다

주의 — 자주 헷갈리는 부분
"$+x$ 방향으로 입자를 쐈다"는 건 경계조건이 아니라 물리적 상황 설정. "오른쪽으로만 간다" → 역방향 파 $Be^{-ikx}$ 없음 → $B=0$. 경계조건으로 결정된 게 아님.

에너지연속양자화

자유입자에서 운동량을 측정해서 $p=+\hbar k$를 얻으면 → $k$ 확정 → $E$ 확정. 근데 이건 "양자화"가 아니야. 양자화 = 허용되는 $k$ 값이 이산적으로 제한되는 것. 자유입자 측정은 연속적 $k$ 중 하나를 알게 된 것에 불과.

슈뢰딩거 방정식 풀이 — 4단계 프레임워크

핵심 프레임
이 4단계가 PIB뿐 아니라 조화진동자, 수소원자까지 모든 계에서 동일하게 적용된다. 형태만 달라지고 흐름은 같다.
1
일반해 형태 놓기 $V=0$ 상자 안에서 슈뢰딩거 방정식 → 2계 상수계수 ODE
$$\psi(x) = A\sin kx + B\cos kx \quad \text{(또는 } Ae^{ikx}+Be^{-ikx}\text{)}$$ $A, B, k$ 는 아직 미결정. Euler 공식으로 두 표현이 동치임에 주의.
2
경계조건 → $k$ 양자화 + $n$ 제한 + $E$ 확정

① $\psi(0) = 0$: $A\sin 0 + B\cos 0 = B = 0$ → $B$ 결정

② $\psi(L) = 0$: $A\sin kL = 0$, $A\neq 0$ 이므로 $\sin kL = 0$

$$kL = n\pi \Rightarrow k = \frac{n\pi}{L}, \quad n = 1,2,3,\ldots$$
왜 n=0 제외?
$n=0$ → $k=0$ → $\psi=0$ everywhere → 입자 존재 안 함 → 물리적으로 무의미
$k$ 결정되는 순간 에너지도 확정: $E_n = \hbar^2k^2/2m = n^2h^2/8mL^2$
3
정규화 → $C$ 결정 $$\int_0^L |\psi_n|^2 dx = C^2 \int_0^L \sin^2\!\frac{n\pi x}{L}dx = C^2 \cdot \frac{L}{2} = 1$$ 반각공식: $\sin^2\theta = \dfrac{1-\cos2\theta}{2}$ (부호 주의! $1\mathbf{-}\cos$) $$\therefore C = \sqrt{\frac{2}{L}}$$
4
최종 $\psi_n$ 정리 $$\psi_n(x) = \sqrt{\frac{2}{L}}\sin\frac{n\pi x}{L} \quad (0 \leq x \leq L)$$ $$E_n = \frac{n^2h^2}{8mL^2}, \quad n = 1,2,3,\ldots$$

앞으로 이 프레임이 쓰이는 계들

경계조건이 왜 필요한가?

핵심 원리
일반해는 미결정 상수를 포함하는 후보군. 방정식만으로는 해가 무한히 많다. 경계조건 = 물리적 상황이 수학에 주입되는 순간. 경계조건이 후보군을 필터링해서 허용된 $k$ (= 허용된 상태)만 남긴다.

파동함수의 물리적 성질

$n$은 무엇인가?

양자수 n의 본질
경계조건이 만들어낸 정수 라벨. 이 번호 하나가 그 입자의 상태 전부를 결정한다.

물리적 의미: 상자 안에 몇 개의 반파장이 들어가느냐 $$n=1: \; \frac{\lambda}{2}=L \qquad n=2: \; \lambda=L \qquad n=3: \; \frac{3\lambda}{2}=L$$ 기타 줄 배음과 완전히 같은 구조. 양 끝 고정(경계조건) → 허용된 진동수만 존재(양자화) → $n$으로 라벨링.

Curvature ↔ 에너지

슈뢰딩거 방정식에서: $-\dfrac{\hbar^2}{2m}\dfrac{d^2\psi}{dx^2} = E\psi$

$d^2\psi/dx^2$의 크기 = curvature. curvature가 클수록 $E$가 크다.

Zero-point Energy

고전역학

정지 가능 → $v=0$, $KE=0$ → $E=0$ 가능

양자역학

$n=0$ 없음 → 최솟값이 $E_1 = h^2/8mL^2 \neq 0$

Zero-point Energy — 두 가지 설명

설명 1: 불확정성 원리
상자에 가두면 $\Delta x \sim L$ (유한) → $\Delta p \geq \hbar/2L \neq 0$ → $KE \neq 0$
정지 = 운동량 확정(=0) + 위치 불확정 → 근데 위치를 상자로 이미 제한했으니 불가능
설명 2: Curvature 논리
벽에서 $\psi=0$이어야 하는데, smooth하고 continuous한 함수가 0에서 출발해서 0으로 돌아오려면 반드시 굽어야 한다 → curvature $\neq 0$ → $E \neq 0$
Zero-point Energy를 없애는 방법?
수식 $E_1 = h^2/8mL^2$에서:
• $L \to \infty$ (가둠 해제) → Free Motion으로 돌아감 → $E=0$ 가능
• $m \to \infty$ (무한히 무거운 입자) → 이론상 가능

온도로는 없앨 수 없다. Zero-point energy는 열적 에너지가 아니다. 0K에서도 존재 (헬륨이 0K에서 고체가 안 되는 이유).

선운동량이 왜 불확정인가? (시험 빈출)

핵심 — sin kx는 $\hat{p}_x$의 eigenfunction이 아니다
오일러 공식으로 분해하면: $$\psi_n = \sqrt{\frac{2}{L}}\sin\frac{n\pi x}{L} = \frac{1}{2i}\sqrt{\frac{2}{L}}\left(e^{+in\pi x/L} - e^{-in\pi x/L}\right)$$ • $e^{+in\pi x/L}$: 운동량 $+\frac{n\pi\hbar}{L}$ (오른쪽 이동)
• $e^{-in\pi x/L}$: 운동량 $-\frac{n\pi\hbar}{L}$ (왼쪽 이동)

두 상태의 superposition → 측정하면 각 50% 확률로 $\pm\frac{n\pi\hbar}{L}$
물리적 직관: 입자가 상자 안에서 좌우로 똑같이 튕기는 것의 양자역학적 기술
구조적 통찰
$\psi_n$은 정보의 저장소, operator는 거기서 원하는 정보를 꺼내는 도구.
슈뢰딩거 방정식 풀어서 $\psi_n$ 얻기 → 여기에 또 다른 operator 작용 → 다른 물리량 추출.
$\psi_n$ 구하는 게 사실상 끝. 나머지는 거기서 뽑아내는 것뿐.

확률 계산 — Q1 풀이

문제
$n=1$ 상태의 전자가 카본 나노튜브 ($x=0.1L \sim 0.2L$) 구간에서 발견될 확률을 구하라.

카본 나노튜브를 왜 PIB로 보는가?

PIB카본 나노튜브
상자 길이 $L$튜브 길이 $L$
$V=\infty$ 벽튜브 끝단 (전자 탈출 불가)
$V=0$ 내부$\pi$ 전자 자유 이동
1D 운동튜브 축 방향 이동

그래핀을 둥글게 말아 만든 나노튜브. 탄소마다 $p_z$ 오비탈이 겹쳐 $\pi$ 전자가 튜브 전체에 비편재화(delocalized) → PIB 조건 성립.

계산 과정

1
확률 적분 설정 $$P = \int_{0.1L}^{0.2L} |\psi_1|^2 dx = \frac{2}{L}\int_{0.1L}^{0.2L}\sin^2\frac{\pi x}{L}\,dx$$
2
반각공식 적용 $$\sin^2\theta = \frac{1-\cos2\theta}{2}$$ $$= \frac{1}{L}\int_{0.1L}^{0.2L}\left(1 - \cos\frac{2\pi x}{L}\right)dx$$
3
적분 실행 $$= \frac{1}{L}\left[x - \frac{L}{2\pi}\sin\frac{2\pi x}{L}\right]_{0.1L}^{0.2L}$$ $$= 0.1 - \frac{1}{2\pi}(\sin 72° - \sin 36°)$$ $$= 0.1 - \frac{1}{2\pi}(0.951 - 0.588) = 0.1 - 0.0578$$
4
결과 $$\boxed{P \approx 0.042 = 4.2\%}$$
왜 10%가 아니고 4.2%인가?
고전역학: 구간 $0.1L \sim 0.2L$은 전체의 10% → 확률 10%
양자역학: $n=1$ 파동함수는 중앙 $x=L/2$ 근처에 확률이 집중됨. 벽 근처($0.1L\sim0.2L$)는 확률밀도가 낮음.

→ 고전 ≠ 양자. 이게 Correspondence Principle의 반대편: $n$이 작을 때는 고전과 완전히 다르다.

심화 Q&A — 이 채팅에서 파고든 것들

Q1. 측정이 경계조건을 만든다고 볼 수 있나?

부분적으로만 맞음
맞는 부분: 자유입자에서 운동량 측정 → $k$ 확정 → $E$ 확정 → 위치 불확정. 불확정성 원리와 일치.

틀린 부분: 이건 "양자화"가 아님. 양자화 = 허용 $k$가 이산적으로 제한. 측정은 연속 $k$ 중 하나를 알게 된 것뿐.

진짜 연결고리: 공간적 제한(confinement) → 위치 $\Delta x \sim L$ → 불확정성 원리 → $\Delta p \geq \hbar/L$ → KE ≠ 0 → 영점에너지. 측정이 아니라 구속(confinement)이 핵심.

Q2. 에너지를 0으로 만들 수 있나? 절대온도 0K와 같은 질문인가?

둘 다 불가능, 근데 이유가 다르다
원인없애는 방법가능?
절대 0도 불가열역학 제3법칙무한한 냉각 단계❌
Zero-point energy불확정성 원리 + confinement$L\to\infty$ (가둠 해제)이론상 가능, 근데 그럼 PIB 아님

핵심: Zero-point energy는 열적 에너지가 아님. 온도를 아무리 낮춰도 존재. 헬륨이 0K에서도 액체인 이유가 이것 (zero-point motion이 커서 결정 못 만듦).

Q3. $n=1,2,3$을 대입하면 그 에너지를 가질 확률이 나오는가?

No — 두 가지 확률을 구분해야 한다
$n$ 대입해서 나오는 건 위치 확률밀도 $|\psi_n(x)|^2$. 에너지 측정 확률이 아님.

에너지 측정 확률은 superposition 상태 $\psi = \sum c_n\psi_n$에서 $|c_n|^2$으로 나옴.
순수 고유상태 $\psi_n$에서는 $c_n=1$ → 에너지는 항상 $E_n$으로 확정.

Q4. 상태 $n$은 뭔가?

경계조건이 만들어낸 정수 라벨
$n$ 하나가 정해지면 모든 게 딸려온다:
$$n \text{ 결정} \rightarrow \psi_n \text{ 확정} \rightarrow E_n \text{ 확정} \rightarrow |\psi_n|^2 \text{ 확정}$$ 수소원자에선 3D이므로 양자수 3개 필요: $(n, l, m)$ → $s, p, d$ 오비탈

Q5. 파동으로 기술한다는 게 왜 핵심인가?

이 채팅의 핵심 직관 정리
입자를 파동으로 기술 → sin/cos 함수꼴 → 경계조건 = 보강간섭 조건 → 이 조건 만족하는 파동만 생존 → $n$이라는 정수 탄생 → 에너지 양자화

이 직관이 조화진동자, 수소원자까지 그대로 연결된다.

유도형 (40%)

유도형 PIB 파동함수 $\psi_n$과 에너지 $E_n$을 처음부터 유도하라 ▼
4단계 프레임 전체 유도:
① $V=0$ → 슈뢰딩거 방정식 → 일반해 $\psi = A\sin kx + B\cos kx$
② $\psi(0)=0$ → $B=0$, $\psi(L)=0$ → $\sin kL=0$ → $k=n\pi/L$, $n\geq1$
③ 정규화 → $C = \sqrt{2/L}$
④ $E_n = \hbar^2k^2/2m = n^2h^2/8mL^2$
⭐ 이 유도는 백지에서 완벽하게 쓸 수 있어야 함. 특히 $n=0$ 제외 이유, $B=0$ 이유 서술 필수.
유도형 정규화 적분 $\int_0^L \sin^2(n\pi x/L)\,dx = L/2$ 를 유도하라 ▼
반각공식 $\sin^2\theta = (1-\cos2\theta)/2$ 적용
$$\int_0^L \sin^2\frac{n\pi x}{L}dx = \int_0^L \frac{1-\cos(2n\pi x/L)}{2}dx = \frac{L}{2} - \frac{L}{4n\pi}\left[\sin\frac{2n\pi x}{L}\right]_0^L$$ $\sin(2n\pi) = 0$ → 두 번째 항 소멸 → $= L/2$
반각공식 부호 실수 금지. $1-\cos$임.
유도형 인접 에너지 준위 간격 $E_{n+1}-E_n = (2n+1)h^2/8mL^2$을 유도하고, Correspondence Principle과 연결하라 ▼
$$E_{n+1}-E_n = \frac{(n+1)^2h^2}{8mL^2} - \frac{n^2h^2}{8mL^2} = \frac{[(n+1)^2-n^2]h^2}{8mL^2} = \frac{(2n+1)h^2}{8mL^2}$$ $L\to\infty$ 또는 $n\to\infty$: 간격 $\to 0$ → 에너지 연속 → 고전역학 복원 = Correspondence Principle
$(n+1)^2 - n^2 = 2n+1$ 전개 과정 서술 필수.

원리·설명형 (30%)

설명형 Zero-point energy의 물리적 기원을 두 가지 방법으로 설명하라 ▼
방법 1 — 불확정성 원리:
상자에 가두면 $\Delta x \sim L$ (유한) → $\Delta p \geq \hbar/2L \neq 0$ → 운동량 완전히 0 불가 → $KE \neq 0$

방법 2 — Curvature 논리:
$\psi$가 양쪽 벽에서 0이어야 하고 smooth/continuous 해야 하면, 반드시 굽어야 함 → curvature $\neq 0$ → $d^2\psi/dx^2 \neq 0$ → $E \neq 0$
두 가지 모두 쓰는 문제로 출제 가능. 방법 2는 curvature ↔ E 관계 (7C 내용) 연결.
설명형 PIB에서 선운동량이 well-defined 하지 않은 이유를 설명하라 ▼
$\psi_n = \sqrt{2/L}\sin(n\pi x/L)$은 $\hat{p}_x$의 eigenfunction이 아님.
오일러 공식: $\sin kx = (e^{ikx}-e^{-ikx})/2i$ → $+\hbar k$와 $-\hbar k$의 superposition
측정하면 각 50% 확률로 $\pm n\pi\hbar/L$ → 확정값 없음
$\langle p \rangle = 0$이지만 이건 평균이지 확정값이 아님
$\sin kx \neq$ eigenfunction of $\hat{p}_x$ 서술이 핵심. 오일러 분해 보여주면 고득점.
설명형 공액 분자가 길수록 가시광선을 흡수하는 이유를 PIB 모델로 설명하라 ▼
$\pi$ 전자 delocalized → 공액 분자를 1D box로 근사
$\Delta E = E_{n+1} - E_n = (2n+1)h^2/8mL^2$
$L$ 증가 → $\Delta E$ 감소 → $\lambda = hc/\Delta E$ 증가 → 가시광선 영역으로
벤젠(짧음) → UV 흡수 → 무색
β-Carotene(길음) → 가시광선 흡수 → 주황색
계산값 1240nm vs 실험값 497nm 차이의 이유: 분자 끝부분의 포텐셜이 실제로는 $V=\infty$가 아님 (crude model).

계산형 (30%)

계산형 $n=1$ 상태에서 $x=0.1L$~$0.2L$ 구간에 전자가 발견될 확률을 구하라 ▼
$$P = \frac{2}{L}\int_{0.1L}^{0.2L}\sin^2\frac{\pi x}{L}dx = \frac{1}{L}\int_{0.1L}^{0.2L}\!\left(1-\cos\frac{2\pi x}{L}\right)dx$$ $$= 0.1 - \frac{1}{2\pi}(\sin72°-\sin36°) = 0.1 - \frac{0.363}{6.283} \approx \mathbf{0.042}$$
반각공식 적용 후 적분. $\sin$ 값 수치 계산이 포인트. 결과 4.2% (고전 10%와 비교).
계산형 β-Carotene ($L=2.94$ nm, 탄소 22개)의 HOMO→LUMO 흡수 파장을 추정하라 ▼
전자 22개 → $n=11$까지 채워짐 (HOMO=$n=11$, LUMO=$n=12$)
$$\Delta E = (2\times11+1)\frac{h^2}{8m_eL^2} = 23\times\frac{(6.626\times10^{-34})^2}{8\times9.109\times10^{-31}\times(2.94\times10^{-9})^2} = 1.60\times10^{-19}\text{ J}$$ $$\lambda = \frac{hc}{\Delta E} = \frac{6.626\times10^{-34}\times3\times10^8}{1.60\times10^{-19}} \approx 1240\text{ nm}$$
전자 수 ÷ 2 = HOMO 양자수. $m$에는 전자 질량. 계산값≠실험값인 이유도 서술 가능하면 플러스.
계산형 길이 100 nm 상자에 있는 전자의 바닥상태 에너지를 계산하라 ▼
$$E_1 = \frac{h^2}{8m_eL^2} = \frac{(6.626\times10^{-34})^2}{8\times9.109\times10^{-31}\times(100\times10^{-9})^2} = 6.02\times10^{-24}\text{ J} = 6.02\text{ yJ}$$
단위 환산 주의: $L$을 nm → m으로. $1\text{ yJ} = 10^{-24}\text{ J}$.
