03 타당성 검증 (Plausibility)
슈뢰딩거 방정식이 왜 믿을만한가
슈뢰딩거 방정식은 유도된 것이 아니라 가정(postulate)이다. F=ma처럼. 단, de Broglie와 일치함을 보여 타당성을 확인할 수 있다.
ODE 형태로 변환
d²ψ/dx² = (2m/ℏ²)(V−E)ψ

이 형태가 중요한 이유: 2계 선형 ODE 표준형 d²f/dx² = af 와 같은 패턴.

a의 부호에 따라 해의 형태 결정:

조건a 부호해의 형태의미
E > V(V−E) < 0 → a < 0cos kx, sin kx진동 (물리적으로 유효)
E < V(V−E) > 0 → a > 0e^kx, e^{-kx}발산 → 보통 제외
검증 과정 (V=0 자유입자)
  1. ψ = coskx 를 슈뢰딩거 방정식에 대입
    coskx 두 번 미분 = −k²coskx
  2. 양변 cos kx 약분
    −k² = (2m/ℏ²)(V−E)  →  k = (2m(E−V)/ℏ²)1/2
  3. V=0이면 E−V = Eₖ = p²/2m 이므로
    Eₖ = k²ℏ²/2m  →  p = kℏ
  4. k = 2π/λ 대입
    p = (2π/λ) × (h/2π) = h/λ  ✓ de Broglie!
슈뢰딩거 방정식의 해가 자동으로 de Broglie를 만족 → 방정식이 타당하다는 간접 증거.
k의 물리적 의미

k = 2π/λ 이므로 k가 크면 λ 작음.

k² = 2m(E−V)/ℏ² 이고 E−V = Eₖ (운동에너지)이므로:

운동에너지 E−Vkλp
크다 (빠른 입자)크다작다크다
작다 (느린 입자)작다크다작다

→ 빠를수록 파장 짧아짐. de Broglie λ = h/p 와 완전히 일치.

04 수학 배경
복소수 · Euler's Formula · Taylor Series
복소수 기본
z = x + iy     (i = √−1)
이름식의미
켤레복소수z* = x − iy허수부 부호만 바꿈
절댓값 제곱|z|² = z*z = x² + y²항상 양수 → 확률밀도에 사용!
절댓값|z| = (x²+y²)1/2
Euler's Formula ← 시험 자주 나옴
eiφ = cosφ + i sinφ
e−iφ = cosφ − i sinφ

두 식을 더하고 빼면:

cosφ = (eiφ+e−iφ)/2
sinφ = (eiφ−e−iφ)/2i
이걸 알면 cos kx, sin kx를 eikx 형태로 쓸 수 있다 → 복소수 파동함수 표현 가능.
Taylor Series — Euler's Formula 증명
f(x) = f(a) + f'(a)/1!(x−a) + f''(a)/2!(x−a)² + ···

a=0으로 놓으면:

ex = 1 + x + x²/2! + x³/3! + ···
cosx = 1 − x²/2! + x⁴/4! − ···
sinx = x − x³/3! + x⁵/5! − ···

x 자리에 ix 넣으면:

eix = cosx + i sinx  ✓
실전 활용: ex ≈ 1+x (x 작을 때) — 7A 흑체복사 Rayleigh-Jeans 극한 때 썼던 바로 그것!
복소수 일반해 변환

Acoskx + Bsinkx 에 Euler 공식 대입하면:

A·(eikx+e−ikx)/2 + B·(eikx−e−ikx)/2i

= (A/2 + B/2i)eikx + (A/2 − B/2i)e−ikx

= Ceikx + De−ikx
Aeikx+Be−ikx 는 Acoskx+Bsinkx 와 수학적으로 같은 일반해. 상수 이름만 바뀐 것.

복소수 형태를 쓰는 이유: eikx = +x 방향 진행파, e−ikx = −x 방향 진행파 → 방향 구분이 편함.

06 정규화 (Normalization)
A값을 결정하는 방법
왜 정규화가 필요한가

ψ가 슈뢰딩거 방정식의 해이면 Nψ도 해야. (슈뢰딩거 방정식이 선형이라서)

즉 A 값을 방정식만으로는 결정할 수 없어. 추가 조건이 필요함.

추가 조건 = "입자가 공간 어딘가에 반드시 존재한다" → 확률 합 = 1
정규화 조건
N²∫−∞∞ψ*ψ dx = 1

N을 역으로 구하면:

N = 1 / (∫ψ*ψ dx)1/2

이 N이 바로 파동함수의 A (진폭 계수)를 결정하는 과정.

3D로 확장:

N²∫∫∫ψ*ψ dx dy dz = 1   또는   N²∫ψ*ψ dτ = 1

08 확률 계산
∫|ψ|²dx 실제로 어떻게 구하나
공식
P = ∫x₁x₂|ψ(x)|² dx

x₁에서 x₂ 구간에서 입자를 발견할 확률.

핵심 적분 기술 — 반각공식

sin² 또는 cos² 적분할 때 반드시 사용:

sin²θ = (1−cos2θ)/2
cos²θ = (1+cos2θ)/2
예제 — 나노튜브 전자 (교수님 Q1)

주어진 파동함수:

ψ(x) = √(2/L) · sin(2πx/L)

x = L/4 ~ L/2 사이 발견 확률:

  1. |ψ|² 계산
    |ψ|² = (2/L)·sin²(2πx/L)
  2. 반각공식 적용
    sin²(2πx/L) = [1 − cos(4πx/L)] / 2
  3. 적분
    P = (1/L)∫L/4L/2[1 − cos(4πx/L)] dx

    = (1/L)[x − (L/4π)sin(4πx/L)]L/4L/2
  4. 경계값 대입
    x=L/2: L/2 − (L/4π)·sin(2π) = L/2 − 0
    x=L/4: L/4 − (L/4π)·sin(π) = L/4 − 0
  5. 결과
    P = (1/L)(L/2 − L/4) = 1/4 = 25%

자유입자라고 하면 왜 V=0이야? ▶
퍼텐셜에너지 V = 입자가 어떤 힘의 영향을 받을 때 생기는 에너지. 전자가 핵 근처면 Coulomb 인력 → V ≠ 0. 자유입자(free particle)는 아무 힘도 안 받는 입자. 힘이 없으면 퍼텐셜도 없으니까 V = 0. 허공에 혼자 날아가는 전자를 상상하면 돼.
ODE가 뭐야? 미방 안 배웠는데. ▶
ODE = Ordinary Differential Equation (상미분방정식). 함수와 그 미분이 같이 들어있는 방정식. 지금 필요한 건 딱 하나: d²ψ/dx² = −k²ψ 의 해가 coskx, sinkx라는 것. 두 번 미분하면 −k²배가 나오는 함수가 뭐냐고 물어보는 것.
E > V일 때 진동 해라는 게 무슨 뜻? ▶
슈뢰딩거 정리하면 d²ψ/dx² = (2m/ℏ²)(V−E)ψ. E > V면 (V−E) < 0이라서 오른쪽이 −(양수)×ψ. "두 번 미분하면 자기 자신의 음수배"가 되는 함수 → cos, sin. E < V면 반대로 발산하는 지수 해가 나와서 물리적으로 보통 제외.
일반해에 상수 c를 추가해서 Acoskx + Bsinkx + c 해도 되는 거 아냐? 두 번 미분하면 사라지잖아. ▶
안 돼. 슈뢰딩거 방정식이 d²ψ/dx² = (2m/ℏ²)(V−E)ψ처럼 오른쪽에 ψ 자체가 있어. ψ = Acoskx + Bsinkx + c 대입하면 좌변: −k²(Acoskx+Bsinkx) (c 사라짐), 우변: (2m/ℏ²)(V−E)(Acoskx+Bsinkx+c) (c 안 사라짐). 등식 불성립 → c = 0이어야만 해.
k = (2m(E−V)/ℏ²)^1/2 이 식이 어디서 나왔어? ▶
슈뢰딩거 방정식에 ψ = coskx 대입해서 역으로 구한 거야. coskx 두 번 미분 = −k²coskx. 대입하면 −k² = (2m/ℏ²)(V−E). 정리하면 k² = 2m(E−V)/ℏ². ψ = coskx가 해가 되려면 k가 이 조건을 만족해야 한다는 뜻.
sin kx + cos kx 일반해 형태로 대입해도 k가 같이 나와? ▶
응. A coskx + B sinkx 전체를 대입하면 −k²(Acoskx+Bsinkx) = (2m/ℏ²)(V−E)(Acoskx+Bsinkx). 양변에 (Acoskx+Bsinkx) 공통으로 약분되면 −k² = (2m/ℏ²)(V−E). A, B 값에 무관하게 k는 동일하게 결정됨.
복소수 일반해 Ae^ikx + Be^-ikx 가 갑자기 튀어나왔는데, Acoskx+Bsinkx를 복소수로 바꾸면 다른 형태 아냐? ▶
직접 계산해보면: A·(e^ikx+e^-ikx)/2 + B·(e^ikx−e^-ikx)/2i = (A/2+B/2i)e^ikx + (A/2−B/2i)e^-ikx = Ce^ikx + De^-ikx. 상수 이름만 바뀐 것이라 수학적으로 완전히 같은 일반해야.
B=0으로만 만들었다고 운동량이 확정됐다는 말을 어떻게 해? ▶
B=0 자체가 이유가 아니라, B=0의 결과로 e^ikx 형태만 남기 때문. e^ikx는 +x 방향 진행파 → de Broglie에서 p = kℏ로 크기·방향 모두 확정. 반면 coskx(= e^ikx+e^-ikx의 합)는 +/− 방향이 섞여 있어서 운동량 불확정. 엄밀히는 운동량 연산자(다음 챕터)로 증명하지만, 교수님 방식으로는 "한 방향 진행파 → 운동량 확정"으로 이해하면 충분.
